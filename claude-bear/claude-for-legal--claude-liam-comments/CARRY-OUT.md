# CARRY-OUT — claude-for-legal--claude-liam-comments

**The line (written first, GATE C):**

> A skill like this doesn't know the law, and it doesn't decide anything —
> it only remembers the date you gave it. Filed, waived, or missed, that
> call is still yours to make.

**Test:** if someone repeats only this in a meeting next week, is it still
true? Yes — it compresses the one distinction the reel is built to land
(a skill tracks the calendar you give it; it never makes the filing
judgment for you), not the topic (comment-period tracking generally).

**The wrong guess it defeats:** that Claude already knows, on its own,
which regulatory comment periods are open and coming due — as if it were
watching the docket the way a person might watch a calendar. It isn't. The
anchor (a proposed rule opening its comment window on March 2nd, a
sixty-day clock) falsifies the guess directly: the skill only starts
counting once it's told the rule opened, and on day fifty-nine the log
shows exactly what it was given — filed, on time — nothing about whether
the comment itself was any good, and nothing about any rule it was never
told about.
