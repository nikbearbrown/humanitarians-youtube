# Claude, Comments.

Someone assumes Claude already knows, on its own, which regulatory comment
periods are open and coming due — the way a person might watch a calendar.
It doesn't. What it has is a skill: a folder called `comments`, whose
SKILL.md says three things — review open comment periods, log decisions,
track deadlines. Watch the anchor: a proposed rule opens its public
comment window on March 2nd, a sixty-day clock. The skill logs that date
the moment it's told, and starts counting. On day fifty-nine, the log
shows filed, on time — but that only means the date was kept. It doesn't
mean the comment itself was any good, and a rule with no logged decision
isn't necessarily missed; it might be tracked somewhere the skill never
saw. A skill like this doesn't know the law, and it doesn't decide
anything — it only remembers the date you gave it. Filed, waived, or
missed, that call is still yours to make.

## YOUR TURN

"Paste in a proposed rule with its comment deadline. Log this with the
deadline, and ask me before the deadline which way I want it recorded —
filed, not filed, or waived. Don't decide for me."

Why it's worth running: it surfaces the same distinction the reel is
built around — the skill's job is to hold the date and force the decision
back to you, not to make it.

## Deliberately not claimed

This reel redoes an existing reel about the same `comments` skill (an
Anthropic skill for tracking NPRM public-comment deadlines), re-registered
from Teardown to the Plain register. Unlike some sibling redos in this
family, the source sheet's facts were real and specific — not unfilled
placeholders — so this script lifts them directly: the skill's three jobs
(review open periods, log decisions, track deadlines), the filing states
(filed / not filed / waived), and the `--decide CMT-ID` flag. It never
claims Claude decides whether to file, and it never claims a live
connection to any government docket system — the skill logs what it is
told, nothing more.
