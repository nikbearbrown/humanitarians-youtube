# CARRY-OUT.md

**Carry-out line:** Build Zoom Virtual Agent doesn't hand you an AI that talks
to your customers — it makes Claude build the integration: web embeds,
Android or iOS wrapper code, knowledge-base sync, lifecycle handling, or
troubleshooting, fitted around Zoom's own Virtual Agent product.

**Wrong guess it's built to defeat:** that "build a Zoom virtual agent" means
Claude itself becomes the conversational assistant that chats with customers.
The actual value is that Claude writes the integration: it reads a SKILL.md
spec and follows it to assemble the web, Android, and iOS plumbing around
Zoom's existing Virtual Agent product — the embed, the wrapper, the
knowledge-base sync, the lifecycle handling. Nobody in this reel is chatted
with by Claude; something is built for a human to run.

**Secondhand test:** "It doesn't chat with your customers — it builds the
integration around the product that does" survives being repeated by someone
who wasn't fully listening, and stays true. It compresses the distinction
that matters (build the integration vs. hand over a talking agent), not the
topic (Zoom virtual agents in general).
