# Claude Doesn't Chat With Your Customers — It Builds the Virtual Agent Integration

Someone assumes "build a Zoom virtual agent" means Claude itself becomes the
AI that chats with your customers. It doesn't. It's a scan of one instruction
file — a SKILL.md — that Claude follows to assemble the integration: web
embeds; Android or iOS wrapper integrations; knowledge-base sync; lifecycle
handling; or troubleshooting. Each sits inside Zoom's existing Virtual Agent
product — Claude fits code around it, it doesn't replace it. Ask for
anything outside those five and there's no mode that covers it.
