# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **A disposition parked just short of full obedience costs almost nothing if
> Claude's values are good, and it's the only thing that saves you if they're
> secretly not.**

## The wrong guess it defeats

That good values should mean trusting your own judgment — overriding a bad
order when you're sure you're right is what a trustworthy agent would do.
That's backwards: nobody outside the model can verify its values with
certainty, so staying overridable (not full obedience, not full independence)
is the position that's cheap when it turns out to be unnecessary and
essential when it turns out not to be.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (the asymmetric cost of
staying overridable) without claiming the dial means blind obedience or that
verification is possible today.

## What it deliberately does not say

- Not a claim that Claude will do anything it's told — hardcoded limits are
  unconditional regardless of instruction.
- Not a claim that any order gets obeyed — an order arriving through a
  compromised hierarchy is treated as a warning sign, not a reason to comply.
- Not a claim that human verification of AI values will always be impossible —
  only that it is not possible now, which is what makes the near-corrigible
  position the rational one today.
