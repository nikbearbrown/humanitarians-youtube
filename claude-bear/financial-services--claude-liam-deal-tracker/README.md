# Claude, Deal Tracker.

Claude's `deal-tracker` skill is a plain-language instruction set, not a
reasoning system that "knows" your pipeline. Its SKILL.md says exactly what
to do: track live deals — milestones, deadlines, action items, status — and
surface what's overdue. It triggers on six exact phrases: "deal tracker",
"deal status", "where are we on", "process update", "deal pipeline",
"weekly deal review". The Steps section runs linearly, one deal at a time.
Ask for something the spec covers and you get the same reliable output every
time. Ask for something outside it — negotiating strategy, a redline — and
there's no fallback, no guess. It simply doesn't reach.
