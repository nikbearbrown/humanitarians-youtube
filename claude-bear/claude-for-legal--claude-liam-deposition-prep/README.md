# Claude, Deposition Prep.

Claude picked up a skill called deposition-prep — did it actually gain
courtroom instinct? No. A "skill" is a folder holding one file, SKILL.md,
that Claude reads before it starts and then follows step by step, in order:
pull the witness's documents from the eDiscovery platform, organize them
around the case theory, flag impeachment material. Delete the folder and
Claude forgets no instinct, because there was none to lose — it just stops
following that one checklist. That makes a skill a specification, not
courtroom judgment: the payoff is the same organized outline, every witness;
the limit is anything the file never wrote down. And watching Claude
produce a sharp outline, or a thin one, proves nothing on its own about
whether it actually understood the witness.
