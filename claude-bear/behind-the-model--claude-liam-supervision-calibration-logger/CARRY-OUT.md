**The line (written first, GATE C):**

> Supervision isn't one habit you either have or don't — it's the gap
> between how much you're trusting Claude and how long you actually
> checked, and that gap stays invisible until you log it.

**Test:** if someone repeats only this in a meeting next week, is it still
true? Yes — it compresses the one distinction the reel is built to land
(supervision as a measurable gap between usage level and verification
time, not a fixed personal trait), not the topic (AI oversight generally).

**The wrong guess it defeats:** that supervision is a single habit — you're
either a careful, double-checking person or you're not, and that trait
follows you across every task. It doesn't. Usage isn't flat: some
interactions are quick copy-paste edits, others hand Claude a real
decision. A flat habit can't track that difference — only a log that
records both the usage level and the actual verification time, task by
task, can. The mismatch between the two is invisible until someone writes
it down.
