# CARRY-OUT.md

**Carry-out line (BCRY narration):**
> An MCP app is just a server with an extra resource — the tool still
> returns data, and it's the resource that serves the widget's HTML. Get
> the type or the bundle wrong, and it fails blank, not loud.

**Wrong guess it defeats:** that the tool itself sends back the widget's
HTML (B00's hesitant-writer correction: "tool" → "resource" — the naive
framing asks how to make the tool serve the HTML; the corrected question
asks how to make a *resource* serve it, which is what the rest of the reel
shows: two-part registration splits the tool's data from the resource's
HTML, and the two most common ways to break that — wrong MIME type,
un-inlined bundle — both fail the exact same way: a blank rectangle with no
console error).

**Test:** if someone repeats only this sentence next week, it is still true
and still the distinction that matters — not a summary of the whole topic.
