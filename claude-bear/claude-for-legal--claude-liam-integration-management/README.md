# Post-Closing Integration: A Plan, or a Tracker?

The instinct the day an M&A deal closes is to write an integration plan — a
single document laying out what has to happen. But a plan captures one
moment; the day after closing, workstreams start moving in parallel — IT
systems, HR and benefits, finance consolidation, vendor contracts — and a
static document can't tell you six weeks later which ones are on schedule
and which have quietly stalled. What actually closes that gap is a phased
tracker: every workstream gets a task, an owner, a target phase (day-one,
day-thirty, day-one-hundred), and a status. Watch the anchor: a
vendor-contract workstream marked day-thirty on the org chart, with no
owner ever assigned, goes through the same four fields as everything else
and becomes visible instead of silently late. Being tracked doesn't mean a
workstream is on schedule, and a fully staffed tracker on day one doesn't
mean nothing else surfaces later.
