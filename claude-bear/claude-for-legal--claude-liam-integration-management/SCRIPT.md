## Deliberately not claimed

- **Not that a plan is useless.** The reel never says skip the plan — only
  that it has to be a living tracker, not a document written once at
  closing, or it stops reflecting reality within weeks.
- **Not a specific Claude product feature.** Because the source sheet's
  actual facts were never written beyond the one real phrase it did contain
  ("post-closing M&A integration tracker — phased workplan"), this script
  describes the generic mechanics of an integration-tracking practice
  rather than citing any particular tool's UI or output format.
- **No accusation that anyone was negligent.** An unowned workstream is
  presented as an ordinary gap in a fast-moving process, not a failure by
  any named person or team.

## Handoff prompt (BHTF, read aloud)

> "List the workstreams for a hypothetical post-closing integration — IT
> systems, HR and benefits, finance consolidation, vendor contracts. For
> each one, assign an owner and a target phase: day-one, day-thirty, or
> day-one-hundred. Mark today's status."

Why it's worth running: the exercise surfaces the same gap the reel is
built around — any row where "owner" comes up blank is a workstream a
one-time plan would never have caught.
