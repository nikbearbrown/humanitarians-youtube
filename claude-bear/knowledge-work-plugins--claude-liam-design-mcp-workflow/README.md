# One File, One Job, Every Time. — The design-mcp-workflow Skill (Zoom MCP vs. REST)

A Claude skill is a folder Claude reads before it works — a SKILL.md file
holding the full instruction set in plain language, nothing hidden. Claude
reads the file, then acts, running each step in a Steps section in order,
start to finish. This particular skill, design-mcp-workflow, has one job:
design a Zoom MCP workflow for Claude, for three named moments — deciding
whether Zoom's MCP tools fit a task, planning a tool-based AI workflow, or
separating MCP responsibilities from Zoom's REST API. Outside those three
moments, the file has nothing to say. Same input, same output, every time
you run it — a skill isn't a new general ability, it's one file doing one
job.
