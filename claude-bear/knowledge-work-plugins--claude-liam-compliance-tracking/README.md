# It Tracks. It Doesn't Certify. — The Compliance-Tracking Skill

A skill is a folder Claude reads before it works — one file, SKILL.md, in
plain language, no hidden logic. Inside is a Steps section: read the file,
execute each step in order, return the result, no branching unless a step
says so. The compliance-tracking skill is built for one job — track
compliance requirements and prepare for audit readiness. It responds to
trigger phrases like "compliance," "audit prep," "SOC 2," "ISO 27001,"
"GDPR," or "regulatory requirement." Run it twice on the same request and
the steps come out the same both times. But it doesn't reach past that
page — anything the file doesn't cover isn't part of the job.

## YOUR TURN

Paste this into Claude: I need to track our compliance requirements for
SOC 2 and prep for an upcoming audit. Before telling me whether we're
compliant, walk me through each requirement, whether we currently meet it,
and what evidence is missing — then leave the overall compliance call to
me.

That's the same order compliance-tracking follows: track the requirements,
flag the gaps, and leave the determination to a person. Run it today, on
your own framework — SOC 2, ISO 27001, GDPR, or whatever you're prepping
for.
