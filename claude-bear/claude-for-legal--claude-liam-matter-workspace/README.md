# Claude, Matter Workspace.

Claude picked up a skill called matter-workspace — does that mean it can
already see everything across every matter you have, blended into one pool?
No. A "skill" is a folder holding one file, SKILL.md, that Claude reads
before it starts and follows step by step, in order. Open a brand-new
matter and ask about specifics from a different case, and Claude can't see
them — by default, matter-workspace keeps every matter walled off from
every other one. It only reads across matters once cross-matter context is
switched on in the practice's CLAUDE.md. Watching Claude stay inside one
matter proves nothing about whether that switch is on; Claude missing a
detail from another matter proves nothing about whether isolation is
working.
