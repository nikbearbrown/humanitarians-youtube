# CARRY-OUT.md

**Carry-out line (written before any other narration, per CARRY-OUT LAW):**

> handle-complaint doesn't resolve a complaint — it drafts a response and
> suggests a fix, the same way every time; sending the reply and making the
> fix are still yours to do.

**The wrong guess it is built to defeat:** that asking Claude to "handle" an
incoming complaint means Claude sends the reply and closes the case out
itself. It doesn't — the skill's own job description says it drafts a
response and suggests an operational fix, not that it sends or implements
anything. It hands you the material to act on; it doesn't act.

**Repeatability test:** if someone repeats only the carry-out sentence in a
meeting next week, having forgotten everything else, it is still true and
still the useful distinction — "handle" means draft-and-suggest, not
resolve.
