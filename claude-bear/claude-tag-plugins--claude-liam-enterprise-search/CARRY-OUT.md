# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **Enterprise search isn't one lookup — it's search for candidates, read
> the document that matters, then say what you used, so the next search
> ranks better.**

## The wrong guess it defeats

That asking an assistant a question about a company's own knowledge is a
single step — run one search, and the top result already has the answer.
It doesn't: a search result is a ~35-word snippet built for triage, not for
answering. The loop only closes after the full document is read and the
outcome is reported back.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still
true?*

Yes — it compresses the one distinction that matters (a loop of three
steps, not a single query) without overstating what any one step alone can
tell you.

## What it deliberately does not say

- Not a claim that search is unreliable — only that a snippet is a preview,
  not an answer.
- Not a verdict on whether the loop is well or badly designed (Teardown
  territory) — Plain states the mechanism and stops.
- Not that every enterprise-search tool works exactly this way — the Glean
  Client REST API is the worked example this reel demonstrates, not a
  universal spec for every internal search product.
