# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **A fluent, confident summary and a silent omission look identical from
> the outside — the only way to tell them apart is an inventory artifact
> that counts what was processed against what was in scope, and that costs
> one sentence in the prompt.**

## The wrong guess it defeats

That a missing or unreadable file would get flagged — that the agent would
surely say something went wrong. It won't, unless it was explicitly told to
report on scope. A skipped file is silently left out, and the summary reads
exactly as fluent as one that skipped nothing.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (a plausible summary
proves nothing about completeness; only an explicit count does) without
overclaiming that a matching count guarantees the rest of the summary is
correct, or that a mismatch always means something important was lost.

## What it deliberately does not say

- Not that a matching in-scope/processed count proves the summary is
  otherwise accurate — it only proves nothing was silently dropped.
- Not that a mismatch always means something important was omitted —
  sometimes the skipped item didn't matter. The count doesn't tell you
  which case you're in; it only makes the gap visible enough to check.
- Not a claim that omission is a malfunction — the source frames it as the
  path of least resistance for an agent optimizing toward completion, not a
  bug to be shamed.
