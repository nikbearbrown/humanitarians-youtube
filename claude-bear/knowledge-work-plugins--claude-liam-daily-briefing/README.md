# Claude, Daily Briefing. — The Daily Briefing Skill

Say "Claude, daily briefing" and it's easy to assume Claude already
remembers your meetings from before. It doesn't. A skill called
daily-briefing is a folder with one file — SKILL.md — that Claude reads
fresh every time, then runs through a linear Steps section: read the file,
execute each step, return the result. The scope is specific: it works
standalone once you tell Claude your meetings and priorities in chat, and
it's supercharged once you connect your calendar, CRM, and email, so it
reads them directly instead of waiting to be told. Either way, the same
input produces the same briefing every time — and anything the file
doesn't cover, the skill has nothing to say about.

## Deliberately not claimed

No claim about what the daily-briefing skill does with information once
it's connected beyond what its SKILL.md specifies (reading meetings,
priorities, and contact/deal data to build a briefing) — this video
doesn't guess at internals the source doesn't document. No claim that
every Claude Skill works exactly this way; the file-read, linear-Steps,
same-input-same-output pattern described here is how *this* skill (and
its siblings in the knowledge-work-plugins family) are built, not a
universal claim about all Skills everywhere.
