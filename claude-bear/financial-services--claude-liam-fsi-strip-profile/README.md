# Checks the Picture, Then Stops. — The FSI-Strip-Profile Skill (Anthropic Skills)

When Claude builds an investment-banking strip profile with the
`fsi-strip-profile` Skill, it doesn't just generate a slide and hand it
over. It's a folder — this one is fsi-strip-profile — with a SKILL.md file
inside it that is the full instruction set. Claude asks about scope first
and waits for your yes before it researches anything. Then it builds one
slide at a time: after each one, it turns the slide into a picture and
looks for text spilling out, labels cut off, a chart bleeding into the
next box, fixing what it finds — then shows you the slide and stops,
waiting for your approval before the next one.
