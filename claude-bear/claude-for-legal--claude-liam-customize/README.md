## Description

Does "Claude, customize" mean Claude changes something about itself? Not quite —
a Claude Skill named `customize` shapes one task's output to a written spec, the
same way every time, and it has nothing to say about anything outside that spec.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the full instruction set in one file, SKILL.md; how the pipeline runs, step by
step, no branching unless a step says so; the exact constraint this kind of skill works
under — shape one task's output to the file's spec, nothing more; and the carry-out
that matters: same spec in, same shaped output out, every time — but anything outside
what the file says, Claude has no opinion about.

Try it yourself — the video ends with a paste-ready prompt for reading a skill's own
constraints before you let it touch anything.
