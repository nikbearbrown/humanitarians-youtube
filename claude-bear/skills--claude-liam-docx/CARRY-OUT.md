# CARRY-OUT — skills--claude-liam-docx

**Sentence (BCRY, written first per CARRY-OUT LAW):**

> A docx file is a ZIP of XML, so editing one takes no library — just
> careful edits. Creating one from scratch does take a library, and its
> defaults fail silently unless you set them yourself.

**Test:** if someone repeats only this in a meeting next week, is it still
true? Yes — it compresses the distinction that matters (edit needs no
library, create does) without overclaiming reliability (the second sentence
carries the "defaults fail silently" caution, which NB05/NB07 ground in the
page-size and table-width facts, and NB11 flags as a documented, not
enforced, list).

**Wrong guess it defeats:** that editing an existing Word file needs the
same library you'd reach for to build one from scratch. NB03/NB04 break this
with a concrete case — a docx file is just a ZIP archive of XML, so the edit
path (unpack, edit the text, repack) never touches a library at all.
