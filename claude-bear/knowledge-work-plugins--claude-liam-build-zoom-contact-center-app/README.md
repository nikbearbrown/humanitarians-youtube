# Claude Doesn't Answer Your Calls — It Builds the Contact Center App

Someone assumes "build a Zoom contact center app" means Claude hands them a
talking AI agent for the support line. It doesn't. It's a scan of one
instruction file — a SKILL.md — that Claude follows to assemble the
integration: app, web, or native pieces; engagement context and state
handling; campaigns; callbacks; or version-drift troubleshooting. Each sits
inside Zoom's existing Contact Center platform — Claude fits code around it,
it doesn't replace it. Ask for anything outside those five and there's no
mode that covers it.

the boundary that Claude writes and assembles the integration code, which

built) is stated as fact, not argued with.
