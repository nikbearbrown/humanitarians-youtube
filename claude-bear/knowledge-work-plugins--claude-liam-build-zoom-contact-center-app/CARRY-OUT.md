# CARRY-OUT.md

**Carry-out line:** Build Zoom Contact Center App doesn't hand you a talking
AI agent — it makes Claude build the app: integration code for engagement
context, state handling, campaigns, callbacks, or version-drift fixes, fitted
around Zoom's own Contact Center platform.

**Wrong guess it's built to defeat:** that "contact center app" means an AI
that itself talks to callers — a conversational agent Claude hands you ready
to answer the phone. The actual value is that Claude writes the integration:
it reads a SKILL.md spec and follows it to assemble the app/web/native
plumbing — engagement context, state, campaigns, callbacks, version-drift
fixes — that sits around Zoom's existing Contact Center platform. Nobody in
this reel is talked to by an AI; something is built for a human to run.

**Secondhand test:** "It doesn't talk to your callers — it builds the app
around the platform that does" survives being repeated by someone who wasn't
fully listening, and stays true. It compresses the distinction that matters
(build the integration vs. hand over a talking agent), not the topic (Zoom
contact centers in general).
