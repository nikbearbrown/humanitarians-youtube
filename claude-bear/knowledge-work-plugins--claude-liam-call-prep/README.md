## Description

Does "Claude, call prep" mean Claude joins or makes the call itself? Not quite —
a Claude Skill named `call-prep` assembles a briefing from Common Room signals
before a person has the call, and it never participates in the call.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the full instruction set in one file, SKILL.md; how the pipeline runs, step by
step, no branching unless a step says so; the exact scope this skill works under — one
call, prepped from Common Room account signals, triggered by phrases like "prep me for
my call with a company" or "what should I know before talking to them"; and the
carry-out that matters: Claude doesn't join the call, it preps you for it — same
signals in, same brief out, every time.

Try it yourself — the video ends with a paste-ready prompt for making a skill state its
own scope before you let it run.
