# CARRY-OUT — knowledge-work-plugins--claude-liam-call-prep

**Wrong guess it defeats:** "Claude, call prep" sounds like Claude joins or makes
the call itself. It doesn't; the skill assembles a briefing from account signals
before a human has the call, and never participates in the call.

**Carry-out line (written first, before any other narration):**

> Claude doesn't join the call. It preps you for it — same signals in, same
> brief out, every time.

**Survives-repetition test:** someone repeating only this sentence next week is
still describing what a Claude Skill named `call-prep` does correctly — it
compresses the distinction that matters (prep, not participate) rather than
summarizing the topic, and it is not tied to a detail this build had to invent.
