# CARRY-OUT.md

**Carry-out line:** Build Zoom Phone Integration doesn't make Claude answer
your calls — it makes Claude wire the connection: the OAuth, the webhooks,
and the CRM or CTI dialer code that handles the call for you.

**Wrong guess it's built to defeat:** that Claude itself becomes the Zoom
phone integration — picking up, routing, or sitting on a live call the
moment you ask. The actual value is that Claude writes the software: it
reads a SKILL.md reference and follows it to wire together OAuth, Phone
APIs, webhooks, and a CRM or CTI dialer — code you then run, not Claude
personally handling the call.

**Secondhand test:** "Claude doesn't answer the call — it builds the
integration that does" survives being repeated by someone who wasn't fully
listening, and stays true. It compresses the distinction that matters
(build vs. personally handle), not the topic (Zoom Phone in general).
