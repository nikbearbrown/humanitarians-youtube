# Claude Doesn't Answer Your Zoom Calls — It Builds the Integration

Someone assumes "build Zoom phone integration" means Claude itself picks up,
routes, or sits on your calls. It doesn't. It's a reference file — a
SKILL.md — that Claude reads once a request already leans toward Zoom Phone,
covering seven areas: OAuth, the Phone APIs, webhooks, Smart Embed events,
URI schemes, CRM or CTI dialer wiring, and call handling automation. Ask
about anything outside that list and there's nothing here that covers it.

## YOUR TURN

"I want my CRM to show customer info automatically when a call comes in
through Zoom Phone. Walk me through the pieces I'd need — the OAuth
connection, the incoming-call webhook, and the CTI dialer wiring — before
writing any code."

That's the whole idea: Claude wires the connection — OAuth, webhooks, and
dialer code — it never answers the call itself.

---

## Deliberately not claimed

This reel never claims Claude itself picks up, routes, or sits on a live
Zoom Phone call — every beat keeps the boundary that Claude writes and wires
the integration's code, which you then run. It also isn't a claim that this
replaces a developer's own Zoom Phone / OAuth setup: the boundary (only what
the instruction file specifies gets covered) is stated as fact, not argued
with.
