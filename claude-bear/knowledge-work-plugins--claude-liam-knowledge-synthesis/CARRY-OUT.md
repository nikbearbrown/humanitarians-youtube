# CARRY-OUT — knowledge-work-plugins--claude-liam-knowledge-synthesis

**The line:**

> The skill never picks a winning source — it combines every one of them,
> weighed by how fresh and how authoritative each is, and it always tells you
> which source each claim came from.

**Test:** if someone repeats only this in a meeting next week, is it still
true? Yes — it names the mechanism (combine, weighed by freshness/authority,
attributed), not the topic ("Claude can search multiple sources").

**The wrong guess it defeats:** that Claude, faced with several overlapping
search results, does what a rushed reader does — picks the one that looks
best and moves on. B00's hesitant writer stages this directly: the naive
question "Does Claude just pick the best source?" corrects, on screen, to
"Does Claude just combine the best sources?"

**Deliberately not claimed:** no claim about the exact scoring formula behind
"freshness" and "authority" (weights, thresholds) — the source material states
the two factors, not the arithmetic, and this reel doesn't invent one. No
claim that summarization behavior differs from the combine/dedupe/attribute
behavior — the source treats "summarizes large result sets effectively" as
part of the same job, not a separate mechanism, so this reel does too.
