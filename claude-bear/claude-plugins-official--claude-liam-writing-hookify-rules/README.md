# Claude, Writing Hookify Rules.

You don't switch on a Claude skill by naming it. A skill's SKILL.md carries a
plain-language description near the top, and Claude compares your own
wording against that description — land inside it and the skill fires,
without you ever typing its name. The `writing-hookify-rules` skill is the
worked example: its real description fires for "create a hookify rule,"
"write a hook rule," "configure hookify," or "add a hookify rule." Ask
something that lands inside that wording and the match fires the skill,
every time; ask something unrelated and the skill just stays off — Claude
still answers, only without that file's playbook.
