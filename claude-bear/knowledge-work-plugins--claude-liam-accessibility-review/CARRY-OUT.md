# CARRY-OUT.md

**Carry-out line (written before any other narration, per CARRY-OUT LAW):**

> accessibility-review doesn't fix a design — it checks it against WCAG 2.1 AA
> and reports exactly where it fails, the same way every time.

**The wrong guess it is built to defeat:** that asking Claude to "review a
design for accessibility" means Claude will go fix the accessibility problems
it finds. It won't — the skill's own job description is an audit ("run a WCAG
2.1 AA accessibility audit on a design or page"), not a repair. It reports
gaps against a fixed standard; it does not rewrite the design to close them.

**Repeatability test:** if someone repeats only the carry-out sentence in a
meeting next week, having forgotten everything else, it is still true and
still the useful distinction — "review" means audit-and-report, not fix.
