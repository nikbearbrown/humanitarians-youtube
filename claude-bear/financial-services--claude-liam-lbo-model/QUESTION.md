# QUESTION.md

**Question (as a newcomer would actually ask it):** When Claude runs an
Anthropic Skill like `lbo-model`, does it design the LBO model itself —
the way an analyst building deal assumptions would — or does it just fill
in an existing template's formulas, step by step?

**Who asked:** no single asker; this is a redo (hai-simple, `mode: "redo"`)
of the Teardown reel `claude-liam-lbo-model`, which taught the anatomy of
the `lbo-model` Anthropic Skill (a `model-builder` plugin skill,
financial-services family) without ever posing the question this
directly. This reel makes the question the newcomer actually has explicit
and answers it in the Plain register.

**Name use:** n/a — no named individual asker.

**Wrong guess this reel exists to correct:** that a Skill like this
builds the LBO model's structure and assumptions from scratch, the way an
analyst would design a deal. It isn't — the source description is
specific: the skill "fills in formulas, validates calculations, and
ensures professional formatting standards that adapt to any template
structure." It completes and checks a template someone else already
designed; it doesn't invent the deal.
