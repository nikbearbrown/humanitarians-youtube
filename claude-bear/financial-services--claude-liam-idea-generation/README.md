# Claude, Idea Generation.

Claude picked up a skill called idea-generation — does that mean it's now
creatively brainstorming new stock ideas, the way an analyst free-associates
in a pitch meeting? No. It runs a systematic screen: quantitative screens,
thematic research, and pattern recognition, in that fixed order, to surface
long and short candidates. Run the same screen twice on the same data and
you get the same candidates back both times — not two different creative
pitches. Say the criteria are rising free cash flow plus recent insider
buying: idea-generation runs the screen, checks the thematic angle, looks
for the pattern, and three candidates surface. Run it again tomorrow with
the same criteria, and the same three candidates surface — not a fresh set,
not a new pitch. That makes it a screener, not a strategist — the payoff is
the same criteria surfacing the same candidates, every run; the limit is
that it only finds what fits the screen you wrote. And neither result is
proof on its own: a candidate surfacing doesn't prove it's a good trade, and
a stock that never surfaces isn't proven bad.
