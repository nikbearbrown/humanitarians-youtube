# Claude, Matter Update.

Ask Claude to log an update on a legal matter, and it runs the same way
every time — a new filing, a settlement offer, a missed deadline, always
appended and logged the same way. Is that because it remembers your firm's
habits, or something else? A Claude skill is a folder with one instruction
file — this one is called matter-update — that says exactly what counts as
an update: append a dated event, refresh the log row. Claude reads that file
fresh, on every matter, in every conversation. Nothing is recalled from
before. This walks through the wrong guess, the file's one instruction, and
where its reliability actually ends.
