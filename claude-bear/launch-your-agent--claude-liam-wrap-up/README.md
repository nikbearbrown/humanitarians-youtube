# Claude, Wrap Up. — The Wrap-Up Skill (Claude Managed Agents)

A skill is a folder Claude reads before it works — this one is called
wrap-up, and the SKILL.md inside it is the full instruction set, written
in plain language. Its pipeline runs in order: refresh the overview page,
recap every primitive you now own, show the run log and live status,
suggest one or two tailored upgrades, then sweep hygiene — old sessions
archived, the key kept only in dot-env, no literal dates left in
deployment kickoffs. Because it's idempotent, running it again doesn't
start the build over or duplicate anything; it refreshes the same
overview page and status tables — same input, same output, every run —
and it only recaps and suggests, it doesn't build the upgrades it names.
Wrapping up your agent isn't a shutdown; it's a recap you can re-run any
time, and running it again only refreshes what's already there.

## Deliberately not claimed

No claim about how Claude decides which upgrades to suggest — the source
Skill documents what the recap checks and shows, not the judgment behind
which one or two upgrades it picks, and this video doesn't guess. No
claim that every wrap-up run finds something new to report; idempotent
means re-running is always safe, not that it always surfaces a change.
