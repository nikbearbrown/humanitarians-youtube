## The argument, kept from the source

The source reel (Teardown register, CLI 10-beat spine, `am_onyx`/Liam narration already)
makes these load-bearing claims, carried into this redo unchanged:

1. **Reading Claude's output is not reviewing it.** A clean, well-formatted answer can
   still be wrong — checking it takes more than reading it carefully.
2. **The fix is a tool, not more careful reading:** `verification_gate.py` takes an
   output type and a risk level as arguments and prints back three to five concrete,
   checkable steps — a protocol, not a feeling.
3. **The matrix's rules are specific to the combination, never generic:** a citation
   always includes opening the actual source; a number at strict risk always includes
   an independent recalculation; a chart always gets its axis labels and denominator
   checked.
4. **The three-combo demo (source B04):** citation at strict risk runs four steps
   ending in "open the source"; number at moderate risk runs three steps (spot-check,
   denominator, units); code at light risk runs a short skim. Same tool, three
   genuinely different depths.
5. **The `--log` flag (source B05/B06):** running the tool again with `--log` writes
   the completed checklist out as a timestamped markdown file — output type, risk
   level, timestamp, and each step with a checkbox. The record travels with the
   output; it isn't just the output anymore.
6. **The summary (source B07):** the human gate is not distrust — it is the design of
   the supervisory role. The checklist makes that role automatic instead of effortful;
   without it, "looks right" is the entire review process.

## Deliberately not claimed

- **Not "a completed checklist proves the output is correct."** The reel's
  both-directions beat (B08) states the limit: the matrix catches known risk patterns
  for that output type and tier, not every possible error. Finishing every checkbox is
  not the same as the output being fully correct.
- **Not "a failed checklist step proves the output is wrong."** The same beat states
  the other direction: a failed step means the output needs a closer human look, not
  that it is necessarily wrong.
- **No accusation that Claude, or any specific model, produces worse citations,
  numbers, or charts than any other system.** The fabricated-citation case (B03) is
  used as a generic illustration of why "reads clean" cannot substitute for "opened the
  source" — not a claim about any one model's error rate.
