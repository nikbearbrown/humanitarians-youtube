# CARRY-OUT.md

**Carry-out line:** This skill doesn't interpret your lab results — it detects
the instrument and converts the file into one exact standard shape, the same
way every time.

**Wrong guess it's built to defeat:** that a skill named "instrument data to
Allotrope" reads lab results the way a scientist would — understanding them,
judging them, flagging something odd. It doesn't interpret anything. It detects
which instrument produced the file and converts it — PDF, CSV, Excel, or TXT in;
Allotrope JSON or a flattened CSV out — following one written spec, nothing more.

**Secondhand test:** "It doesn't read your results, it converts the file — same
instrument-detect, same exact output shape, every run" survives being repeated
by someone who wasn't fully listening, and stays true. It compresses the
distinction that matters (convert vs. interpret), not the topic (lab data
standardization in general).
