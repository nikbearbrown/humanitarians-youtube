## Description

Can Claude tell you if your invention is patentable? Not quite — Anthropic's
invention-intake skill runs six screens (novelty, obviousness, § 101 eligibility, bar
dates, detectability, strategic value) and returns one of three verdicts: pursue,
investigate, or decline. It never says "patentable" — that call still needs a
prior-art search and a registered patent attorney.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the full instruction set in one file; how the pipeline runs six named screens
in order; the exact constraint this skill is bound to (a bounded triage screen, never
a patentability opinion); and the carry-out that matters: six screens in, one verdict
out, every time — but the actual patentability call is still counsel's job.

Try it yourself — the video ends with a paste-ready prompt for screening your own
invention disclosure in Claude today.
