# CARRY-OUT.md — GATE C

**Carry-out line (written before any other narration):**

> More AI models agreeing isn't more verification. It's the same blind spot, counted twice.

**Test:** if someone repeats only this in a meeting next week, is it still true? Yes — it
compresses the distinction the whole reel is built to land: *agreement* (a fact about what
several systems output) is not the same thing as *independence* (a fact about whether
their failure modes overlap). It survives being repeated cold because it names both halves
of that distinction in one breath, without needing the audit-pairing mechanism behind it.

**The wrong guess it is built to defeat:** that more AI reviewers agreeing on an answer is
stronger evidence of correctness — the way a second medical opinion, or several judges
converging on the same score, would be. The reel's falsifying case (source's positional-
bias demo: same two answers, swapped order, verdict flips) shows that "agreement" among
LLM judges can be produced by a shared structural bias rather than by the content being
right — so the agreement alone proves nothing until you know whether the checkers could
have failed differently.
