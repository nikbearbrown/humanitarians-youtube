# CARRY-OUT.md

**Carry-out line (written before any other narration, per CARRY-OUT LAW):**

> brand-review doesn't rewrite your copy — it flags where it drifts from your
> brand voice, by severity, with a suggested fix for each flag, the same way
> every time.

**The wrong guess it is built to defeat:** that asking Claude to "review
content against your brand voice" means Claude will go fix the copy itself.
It won't — the skill's own job description is to flag deviations by severity
with specific before/after fixes shown, not to silently rewrite the draft.
The suggestion is on the page; applying it is still a human call.

**Repeatability test:** if someone repeats only the carry-out sentence in a
meeting next week, having forgotten everything else, it is still true and
still the useful distinction — "review" means flagged-with-suggestions, not
auto-rewritten.
