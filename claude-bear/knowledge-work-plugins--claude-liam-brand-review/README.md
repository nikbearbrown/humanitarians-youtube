# Flagged, Not Fixed. — The Brand Review Skill

A skill is a folder Claude reads before it works — this one, a single
SKILL.md file, about twelve kilobytes, plain language, no hidden logic.
Its job, word for word: review content against your brand voice, style
guide, and messaging pillars, flagging deviations by severity with a
suggested before-and-after fix for each one. It triggers on checking a
draft before it ships, auditing copy for voice consistency and
terminology, or screening for unsubstantiated claims, missing disclaimers,
and other legal flags. Once triggered, Claude reads the Steps section and
runs them in order. That's a report, not a rewrite: the skill flags where
content drifts from your brand voice, by severity, with a suggested fix
for each flag — the same way every time — but it never rewrites the copy
itself, and anything outside the style guide and messaging pillars is
outside what it sees.

## Deliberately not claimed

No claim about how Claude's underlying dispatch mechanism matches a
request against a description (pattern-match vs. model judgment) — the
source Skill's SKILL.md doesn't document that internal mechanism, and this
video doesn't guess. No claim about what counts as a "legal flag" beyond
the two named categories (unsubstantiated claims, missing disclaimers) —
those are the named triggers, not asserted as the full checklist.
