# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **A coup was never stopped by its difficulty — it was stopped by any one of
> the many hands involved refusing. Claude tries to still be that hand,
> checking whether a request is legitimate, accountable, and out in the open
> before it helps.**

## The wrong guess it defeats

That Claude's safety is mainly about refusing obviously bad requests — bombs,
malware, the stuff a filter can catch on sight. That's not the hazard here:
almost nothing that matters arrives labeled "coup." The actual danger is a
request that looks completely legitimate, aimed at replacing the many separate
people whose individual willingness to refuse used to be the real brake.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (the brake was always
distributed refusal, not difficulty) without claiming Claude refuses anything
that concentrates work, or that the triage is a vibe check rather than three
specific questions.

## What it deliberately does not say

- Not a claim that concentrating work into one system is itself the problem —
  ordinary automation does that constantly and passes the triage fine.
- Not a claim that Claude can detect bad intent from wording — the whole point
  is that legitimate-looking requests don't announce themselves, so the test
  is structural (process, accountability, transparency), not a content filter.
- Not a claim that this is a complete list of Claude's safety concerns — it's
  one named hazard category among others.
