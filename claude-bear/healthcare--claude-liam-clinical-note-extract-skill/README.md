# It Cites the Evidence. It Never Guesses.

**Channel:** @HumanitariansAI

## Description

When Claude pulls structured data out of a clinical note, does it guess at
a value it can't find, or only report what's literally on the page?

This is Professor Bear's Claude-basics series, narrated by Liam. Today's
worked example is `clinical-note-extract-skill`, an Anthropic Claude Skill
from a healthcare plugin. A Skill is a folder Claude reads before it acts —
one file, SKILL.md, written in plain language, plus folders for assets,
references, scripts, and workflows: six files total. The instructions run
as four steps, in order: define a schema for what to pull, extract
candidate values, validate each one (checking that its span actually
appears in the note, then dispatching further checks by field type), and
report the result. For every field it finds, it cites the exact span of
text that supports it. For every field it can't find, it returns an
explicit null — never a guess.

Carry-out: clinical-note-extract-skill only writes down what the note
actually says, citing the exact text — and marks everything else null
instead of guessing.

**Your turn — paste this into Claude:**
"I have a block of text with several facts I need pulled into fields. For
each field, don't guess — show me the literal text you're using as
evidence, and if you can't find it, tell me it's null instead of
inferring."
