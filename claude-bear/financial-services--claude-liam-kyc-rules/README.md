## Description

When Claude screens a new client's file for KYC/AML risk, does it decide
whether to accept them, or just score the file against the rules?

This is Professor Bear's Claude-basics series, narrated by Liam. Today's
worked example is `kyc-rules`, an Anthropic Claude Skill from a
financial-services compliance plugin. A Skill is a folder Claude reads
before it acts — one file, SKILL.md, written in plain language, with
instructions run as steps in order. `kyc-rules`'s specific job: given an
already-parsed onboarding record, apply the firm's KYC and AML rules grid
to it — assign a risk rating, cite the rule behind every outcome, and flag
what's missing or worth escalating. It doesn't decide whether to accept the
client. It scores the file and routes it — the accept-or-reject call stays
with a person.

Carry-out: kyc-rules scores a client file against the firm's own rules and
flags what needs a person — it never decides whether to accept anyone.
