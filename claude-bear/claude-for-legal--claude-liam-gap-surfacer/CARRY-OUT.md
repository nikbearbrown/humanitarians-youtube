# CARRY-OUT — claude-for-legal--claude-liam-gap-surfacer

**The line (written first, GATE C):**

> A gap-surfacer doesn't tell you a clause is missing — it tells you where
> to look. No match found is a lead, not a verdict; the read is still yours.

**Test:** if someone repeats only this in a meeting next week, is it still
true? Yes — it compresses the one distinction the reel is built to land
(no-match is a pointer, not a finding), not the topic (contract review
generally).

**The wrong guess it defeats:** that a check like this looks for *bad*
clauses — reads what's there and judges it. It doesn't. Its whole job is
absence: walk a checklist of things a document is supposed to contain, and
report which items have no matching text anywhere in it. That's a harder,
different question than "is this clause well written" — and a no-match
doesn't automatically mean the protection is actually gone, because the
same coverage can live under different wording the checklist item never
named.
