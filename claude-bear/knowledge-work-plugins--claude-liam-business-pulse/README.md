# A Skill Is A File, Not An App. — The Business-Pulse Skill

A Claude skill is a folder Claude reads before it works — not software it
switches on. This one is called business-pulse. Inside is one file,
SKILL.md: the full instruction set, written in plain language, no hidden
code underneath it. Claude reads that file, then acts on what it says. The
instructions live in a Steps section, and Claude reads each step in order
and carries it out — linear, one step after another, no branching unless a
step itself says to branch. Because it's a written spec, Claude only does
what that file says — the same steps, the same order, every time it runs.
That's what makes it repeatable. It also means the reverse: anything not
written in the file is simply outside what the skill covers.
