## Title

Claude, Debug Zoom. (Skills, Explained)

## Description

Ask Claude to "debug" a broken Zoom integration and the natural guess is that
it goes and fixes it. It doesn't. The `debug-zoom` skill's stated job is to
isolate the failure point in a broken Zoom integration — auth, API, webhook,
SDK, or MCP behavior — and hand back a ranked hypothesis list plus
verification steps. Diagnosis, handed to you. Not a repair, performed for
you.

In this Claude Basics short: what a Claude skill actually is (a folder, one
file, `SKILL.md`, plain language, no hidden logic), how its pipeline runs
(read the file, execute each step in order, return the result — linear, no
branching unless a step says so), and what "ranked hypothesis list plus
verification steps" looks like worked through on a concrete case: a Zoom
webhook that's gone silent.

Try it yourself — the paste-ready prompt is in the video.
