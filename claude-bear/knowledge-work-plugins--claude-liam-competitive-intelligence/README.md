# Same Battlecard, Every Time. — The Competitive-Intelligence Skill (Anthropic)

A Claude skill is a folder Claude reads before it works. The
competitive-intelligence skill's job: research your named competitors, then
build one interactive battlecard — an HTML artifact with clickable
competitor cards and a comparison matrix. Ask with a phrase like "battlecard
for one competitor" or "how do we compare to them," and Claude works through
the SKILL.md's steps in order: read the trigger, research, build. It's not
an ongoing monitoring service — it's a fixed recipe that runs once, on
request, and only ever produces what the file specifies. Ask for something
outside that spec — a rival not on your list, a different output shape —
and there's nothing to fall back on.
