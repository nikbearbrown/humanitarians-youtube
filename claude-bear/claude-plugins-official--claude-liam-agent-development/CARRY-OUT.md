**Carry-out line (BCRY narration):**
> A subagent only gets called when its description says exactly when to use
> it — not just what it does. The best agent in the world never fires if its
> description only lists capabilities.

**Wrong guess it defeats:** that listing an agent's skills/capabilities in the
description is enough for Claude to know when to use it (B00's
hesitant-writer correction: "skills" → "triggers" — the naive framing asks if
listing what the agent *does* is enough; the corrected question asks whether
listing its *triggers* is what tells Claude when to use it, which is what
the rest of the reel shows: the description's real job is stating dispatch
conditions, the body's own When to invoke section repeats that in more depth
for the agent itself, and the whole design's real cost is that the two
locations can drift out of sync).

**Test:** if someone repeats only this sentence next week, it is still true
and still the distinction that matters — not a summary of the whole topic.
