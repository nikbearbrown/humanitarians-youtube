## Title

Why Individual Caution Does Not Add Up to Team Safety — The Team Fence Gap, Explained

## Description

Five teammates each use Claude carefully, on their own account — surely that adds up to a
careful team? Not when agents act on shared assets. One teammate adds a connector to read
the shared team Dropbox. It's added at the account level, not scoped to just that person, so
every teammate's agent inherits read access — including a client contract marked
confidential. No one intended it, and no one knew. The gap isn't inside anyone's careful
practice; it opens at the boundary between people, in the shared space nobody individually
owns or watches.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: the natural assumption that careful individuals sum to a careful team; the
concrete case where a single account-level connector breaks that assumption; where the
accountability gap actually sits; and the failure mode on the other side, where not every
shared thing needs its own rule. The fix is naming the fence around the shared space, before
anyone connects anything — what data each agent can reach, who approves an account-level
connector, and who's accountable if something leaks.

Try it yourself — the video ends with a paste-ready prompt for building a minimal
shared-rule structure for your own team.
