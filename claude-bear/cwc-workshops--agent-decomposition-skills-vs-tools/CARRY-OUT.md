# CARRY-OUT

> Faster agents don't know less — they load only the knowledge each task actually
> needs, exactly when it needs it.

Test: if someone repeats only this in a meeting next week, is it still true? Yes —
it compresses the key distinction (decomposition vs. deletion) without overstating it.

**Wrong guess this defeats:** "A slow, expensive agent needs more — more tools, more
context, more instructions in the prompt, so it never misses a case." The carry-out
replaces that frame: the fix is not more knowledge in one window, it's the same
knowledge split so only the relevant slice loads per task.
