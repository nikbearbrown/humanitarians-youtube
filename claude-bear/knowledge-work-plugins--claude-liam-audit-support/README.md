# It Tests and Classifies. It Doesn't Decide.

## Description

When Claude runs SOX 404 control testing, does it decide whether the
company's controls pass, or does it just test the sample and write it up?

This is Professor Bear's Claude-basics series, narrated by Liam. Today's
worked example is `audit-support`, an Anthropic Claude Skill from a
knowledge-work finance plugin set. A Skill is a folder Claude reads before
it acts — one file, SKILL.md, written in plain language, with instructions
run as steps in order. `audit-support`'s specific job: given a control to
test, pick the sample using the firm's sampling methodology, test each
item against the control's stated criteria, and classify any exception it
finds. It doesn't decide whether the company's controls pass overall. It
tests the sample and writes it up — the audit opinion stays with the
auditor.

Carry-out: audit-support tests the sample against the firm's own criteria
and classifies what it finds — it never decides whether the company's
controls pass.

**Your turn — paste this into Claude:**
"I have a set of criteria and a sample of items I need to test against
them. Before you tell me whether it passes overall, walk me through each
item, whether it meets the criteria, and what doesn't — then leave the
overall call to me."
