# CARRY-OUT — claude-tag-plugins--claude-liam-grafana-api

**The wrong guess it defeats:** that Claude already "knows" an outside API
like Grafana's the way it knows common knowledge — so it can just guess the
right time format, the right alert surface, or the right way to update a
dashboard.

**The carry-out line (written first, GATE C):**

> A skill doesn't make Claude know an API. It gives Claude a map of where the
> traps are — and Claude only avoids the ones the map actually marks.

**Survives-being-repeated test:** someone who only half-heard the reel and
repeats just this sentence next week is still saying something true: a Skill
is documentation Claude reads, not knowledge it already has, and that
documentation's coverage is uneven — so a skill narrows the guessing, it
doesn't eliminate it.

**Compresses the distinction, not the topic:** the topic is "the Grafana API
skill." The distinction is "read vs. know, and mapped vs. unmapped" — which is
what every beat before it built toward (B00's correction, B01–B02's specific
map contents — time formats, role model, alert surfaces, dashboard replace,
batching — B03's both-directions split between what's marked and what isn't).
