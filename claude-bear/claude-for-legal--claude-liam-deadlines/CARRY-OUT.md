# CARRY-OUT.md

**Carry-out line:** "Same rule in, same calendar out, every time. Knowing which rule
actually governs your matter is still yours."

**The wrong guess it defeats:** that Claude "knows" your legal deadlines — that you can
hand it a case and it will independently determine which statute of limitations or
court-rule deadline applies. It doesn't track your matter against the law; it computes
forward from a triggering date and a rule you (or your firm's checklist) supply. Feed it
the wrong rule and it will confidently return the wrong date.

**Test:** repeatable next week without going wrong — "same rule in, same calendar out"
stays true regardless of jurisdiction or matter, and "knowing which rule governs is still
yours" is the one thing the skill never does for you.
