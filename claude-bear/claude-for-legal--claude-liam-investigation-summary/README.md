# Claude, Investigation Summary.

Claude picked up a skill called investigation-summary — does it write one
summary of the investigation, the same for everyone who asks? It doesn't.
The investigation is privileged, and not every reader is entitled to the
same amount of it: send the version written for outside counsel to the
workforce, and you'd hand over the very analysis privilege exists to
protect. The skill is one file — a folder holding a single SKILL.md —
instructions for drafting an audience-specific summary from one underlying
privileged investigation. Claude reads it top to bottom and follows it step
by step: read the record, draft for the audience it's given, return one
output. That makes it a specification, not judgment about privilege — the
payoff is the same shape of summary every run; the limit is that a reader
the file never anticipated gets no guidance on where the line should sit.
And neither a plain, factual summary nor a heavily redacted one proves
anything on its own about whether the line was drawn correctly.
