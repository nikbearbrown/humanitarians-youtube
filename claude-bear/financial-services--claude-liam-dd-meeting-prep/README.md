# How Does Claude Prep for a Due Diligence Meeting?

Ask Claude to prep you for a diligence call and it's tempting to picture it
drawing on some private sense of what makes a sharp question — the kind of
feel an experienced deal person has. That's not what's happening.
Anthropic's `dd-meeting-prep` skill reads which meeting you're prepping for
— a management presentation, an expert network call, a customer reference,
or an advisor session — then builds a targeted question list, the
benchmarks to reference, and the red flags to probe, all from what the file
already defines for that meeting type. Watch the anchor: an expert network
call about a staffing company. One question — same-store margin trend —
gets drafted, gets a benchmark attached, gets asked live on the call, and
comes back flagged: the expert's answer leans on one large client. Prep
that same call twice and the question list, benchmarks, and red flags come
back identical. Ask for a meeting type the file never described — a
regulator sit-down, say — and there's nothing tailored to reach for. A
Claude due-diligence meeting prep is a written procedure tailored to the
meeting type — not Claude's private instinct for what's worth asking.

## Deliberately not claimed

This reel redoes a published Teardown-register skill-showcase reel
(`claude-liam-dd-meeting-prep`) in the Plain register for a general
audience. The underlying facts are unchanged from the source: the skill
prepares for due diligence meetings — management presentations, expert
network calls, customer references, and advisor sessions — generating
targeted question lists, benchmarks to reference, and red flags to probe;
it does not exercise private instinct about which questions matter for a
specific call beyond what the file and the meeting type already define.
This script makes no claim about specific companies, questions, or
benchmark figures — only the general mechanism (a written procedure that
tailors to the meeting type) and its two failure directions.
