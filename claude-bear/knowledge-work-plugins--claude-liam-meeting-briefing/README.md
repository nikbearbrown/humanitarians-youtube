# A Written Plan, Not a Guess. — The Meeting-Briefing Skill (Anthropic)

A Claude Skill is a folder Claude reads before it acts — this one,
meeting-briefing, prepares structured briefings for meetings with legal
relevance and tracks the resulting action items. The instructions live in
one file, SKILL.md, written in plain language with no hidden logic, and the
actual plan lives in that file's Steps section: Claude reads each step in
order and executes it, linear, no branching unless a step itself says so.
Because the steps are fixed, the same request produces the same kind of
briefing every time — same sections, same action-item tracking, run after
run — and what it can't do is step outside that file: anything the SKILL.md
doesn't spell out isn't part of the plan.

## YOUR TURN

Paste this into Claude: I have a meeting coming up on [your topic]. Before
you prepare a briefing, walk me through your plan as a numbered list of
steps — then execute it.

That two-part ask is the whole lesson: a plan you can read before Claude
runs it, not an improvisation you only see after. Run it today, on a
meeting you actually have — you don't need the meeting-briefing Skill
installed for this to work.
