# Content Creation Isn't One Post for Everywhere

Someone hears "content creation" and assumes one piece of marketing copy,
written once and pasted everywhere. It isn't. It's six different formats —
blog posts, social media, email newsletters, landing pages, press releases,
case studies — each built to its own channel's rules: SEO copy for a blog,
a headline and a call to action for a landing page, a subject line and
preview for email. The instructions live in one file Claude reads before it
works; ask for a seventh kind of writing and there's no format that covers
it.

## YOUR TURN

"I just published a new blog post about backyard composting. Give me a
short social media post, a two-line email subject and preview, and one
landing-page headline with a call to action — built for each channel, not
the same paragraph three times."

That's the whole idea: one instruction file in, six different shapes out —
never the same paragraph wearing three labels.

---

## Deliberately not claimed

This reel never claims one draft is silently reused across channels — the
skill's whole point is that it isn't. It also isn't a claim that six is a
limit on marketing writing in general: the boundary (only what the
instruction file specifies gets covered) is stated as fact, not argued
with.
