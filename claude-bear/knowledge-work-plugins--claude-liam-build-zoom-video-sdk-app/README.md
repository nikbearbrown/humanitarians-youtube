# Claude Doesn't Build You a Zoom Meeting — It Builds a Custom Video App

Someone assumes "build a Zoom video SDK app" means Claude assembles a
client that joins an actual Zoom meeting. It doesn't. This skill applies
after the work is already routed to a custom-session workflow — when you
need full control over the video experience, not the standard Zoom
meeting screen. It's built from one instruction file that spells out a
reference for embedding Zoom's Video SDK across six platforms: Android,
Flutter, iOS, Linux, macOS, and React Native. Ask for a Zoom meeting and
this isn't the skill; ask for a custom video session, on any of those six
platforms, and it is.

## Deliberately not claimed

This reel never claims the skill can build you an actual Zoom meeting
client — every beat keeps the boundary that it applies to CUSTOM video
sessions, distinct from the standard Zoom meeting experience. It also
isn't a claim that this replaces a developer's own Zoom Video SDK setup
on any one platform: the boundary (only what the instruction file
specifies gets built) is stated as fact, not argued with.
