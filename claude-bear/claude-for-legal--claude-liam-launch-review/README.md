# Claude, Launch Review.

Claude picked up a skill called launch-review — does that mean it got
authority to approve a launch? No. A "skill" is a folder holding one file,
SKILL.md, that Claude reads before it starts and then follows step by step,
in order. Delete the folder and Claude loses no launch authority, because
there was none to begin with — it just stops following that one checklist.
That makes a skill a specification, not new judgment: the payoff is the
same checklist, every launch, every time; the limit is anything the file
never wrote down. And watching Claude flag every risk, or flag nothing,
proves nothing on its own about whether the launch is actually clean.
