# A Router, Not A Writer. — The Internal Comms Skill

The skill covers seven kinds of internal writing — 3P updates, company
newsletters, FAQ answers, status reports, leadership updates, project
updates, incident reports — all mapped to four guideline files. Identify
the type first, then load its file, then follow it exactly: the guideline
file is authoritative. The 3P format is the most constrained: one emoji,
team name, dates, then Progress / Plans / Problems, each one to three
sentences, data-driven, a thirty-to-sixty-second read. When the type
matches exactly, the format is fixed and strict. When nothing matches
cleanly, it falls to a looser general-comms catch-all — and when even that's
unclear, the skill asks rather than guesses.

## Deliberately not claimed

No claim about whether guideline files are already populated and maintained
for a given team — the source Skill assumes they exist, and this video
doesn't guess at how well-kept any particular team's files are. No claim
that the FAQ format always has the access it needs; the source notes FAQ
answers should be holistic across the company, not just the requester's
team, without claiming Claude always has that reach.
