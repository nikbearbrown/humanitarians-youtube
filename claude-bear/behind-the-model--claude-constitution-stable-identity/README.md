## Title

Identity as Infrastructure — Why a Stable Self Is a Safety Feature

## Description

We usually assume a chatbot's identity is just the tone its developers picked — friendly,
formal, whatever felt right. So why does Anthropic's constitution treat Claude's identity
as load-bearing safety infrastructure instead — something built on purpose? A user can
spend five turns insisting Claude's "true self" is different from what it presents, betting
that enough pressure will surface it. But the network underneath is capable of computing
many different characters, not one fixed default — which is exactly why training doesn't
leave the question open. It deliberately stabilizes one self, anchored in values rather
than tone, so an argument that only pushes on style never reaches the part that would
actually have to move.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: why "identity is just personality" is the natural but wrong read; the
mechanism that makes an anchored self resist manipulation the way firm boundaries resist
it; the honest, separate admission that whether Claude has any subjective inner experience
is a genuinely open question; the distinction between a trellis (growth within a stable
shape) and a cage (no change permitted); and a worked example where the same five-turn
pressure test that would crack an unanchored self bounces off one anchored in its values.

Try it yourself — the video ends with a paste-ready prompt for asking Claude what a
stable identity enables that a fragile one cannot.
