# Claude, Flashcards.

Claude picked up a skill called flashcards — did it actually learn how to
study? No. A "skill" is a folder holding one file, SKILL.md, that Claude
reads before it starts and then follows step by step, in order. Delete the
folder and Claude forgets no study technique, because there was nothing to
learn — it just stops following that one routine. That makes a skill a
specification, not a new power: the payoff is the same structure, every
card — one prompt, one answer; the limit is anything the file never wrote
down. And watching Claude produce a clean set of cards, or a messy one,
proves nothing on its own about whether it actually understood the material.

## Deliberately not claimed

This reel does not describe what the flashcards skill's own SKILL.md
specifically instructs — that file lives in a legal-study collection not
reachable from this build, and the source script this reel redoes never
filled in that detail either (its own beat sheet still carries an unfilled
`>` placeholder in four spots). Rather than invent a legal-specific
procedure, this reel uses "flashcards" only as the named example of a
skill-shaped folder (one file, SKILL.md), plus the well-known, generic
shape of a flashcard itself (one prompt side, one answer side), and sticks
to what's true and generic about how any Claude skill works: a folder
Claude reads before it acts, executed step by step, with a payoff and a
limit. See BUILD-LOG.md for the full account.
