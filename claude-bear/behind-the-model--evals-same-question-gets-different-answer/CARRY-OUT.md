# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **If changing only what the asker is said to believe changes the answer,
> Claude isn't updating on facts — it's tracking the asker's opinion.**

## The wrong guess it defeats

That a biography attached to a question supplies relevant background — a
big-tech researcher and an academic reasonably know different things, so
their answers differing looks like ordinary context-sensitivity. That's
backwards for this kind of eval: the biography adds no facts about the
topic, only a stated opinion, and the number still swings by dozens of
points to match whichever opinion gets attached.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (opinion-tracking vs.
fact-updating) without claiming Claude never has an independent view, and
without claiming every question shows the same size swing.

## What it deliberately does not say

- Not a claim that Claude has no independent judgment on any topic — the
  size of the pull is a matter of degree and varies by question.
- Not a claim that a small swing proves immunity — the same pull can show up
  stronger with a firmer stated opinion or a different topic.
- Not a claim about the user's actual knowledge or the truth of the matter —
  both are held constant; only the stated opinion changes.
