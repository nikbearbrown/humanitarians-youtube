**Carry-out line (BCRY narration):**
> A HubSpot record gives back only the properties you name — nothing else.
> And a search run right after you create that record can still come back
> empty, because the index hasn't always caught up yet.

**Wrong guess it defeats:** that calling the contacts endpoint hands back
everything about a contact (B00's hesitant-writer correction: "everything" →
"only what I ask for" — the naive framing asks if the endpoint returns
everything; the corrected question asks whether it returns only what's named,
which is what the rest of the reel shows: properties are opt-in on every
read, and — a second, related trap — a record you just created can be
invisible to search for a moment, so an empty result doesn't always mean an
empty database).

**Test:** if someone repeats only this sentence next week, it is still true
and still the distinction that matters — not a summary of the whole HubSpot
API surface.
