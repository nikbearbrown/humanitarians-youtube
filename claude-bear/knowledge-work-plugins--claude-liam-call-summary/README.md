# Claude, Call Summary.

What does a Claude "skill" actually do with your sales call notes? Not
listen — call-summary is a folder Claude reads before it works: one file,
SKILL.md, written in plain language. It runs five fixed steps in order —
read the notes or transcript, pull the action items, draft the follow-up
email, generate the internal summary, hand back the result — the same way
every single time. Ask it for something the file doesn't cover, and there's
no instruction for that. This walks through what's inside the skill, how it
runs, and where its edge is.

## Deliberately not claimed

No claim that Claude can listen to, dial, or transcribe a call — only that
it processes text you already have. No verdict on whether the skill's fixed
steps are the right design; the reel states the behavior (consistent output,
an unstated case) without ruling on the trade-off.
