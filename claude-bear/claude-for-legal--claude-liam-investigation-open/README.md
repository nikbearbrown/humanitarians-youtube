# Claude, Investigation Open.

Claude picked up a skill called investigation-open — does that mean Claude
itself decides when a workplace issue becomes a formal investigation? No. A
"skill" is a folder holding one file, SKILL.md, that Claude reads before it
starts and then follows step by step, in order. Delete the folder and Claude
loses no power to decide when to investigate, because there was none to
begin with — it just stops running that one intake checklist. That makes a
skill a specification, not new judgment: the payoff is the same intake,
every matter, every time; the limit is anything the file never wrote down.
And watching Claude open a matter and run a thorough intake, or leave one
unopened, proves nothing on its own about whether it judged the underlying
issue correctly.

## Deliberately not claimed

This reel does not describe what the investigation-open skill's own
SKILL.md specifically instructs — that file lives in an employment-legal
collection not reachable from this build, and the source script this reel
redoes never filled in that detail either (its own beat sheet still carries
an unfilled `>` placeholder in three spots). Rather than invent an
employment-law-specific procedure, this reel uses "investigation-open" only
as the named example of a skill-shaped folder (one file, SKILL.md, opening a
matter and running intake), plus the one fact fragment that survived the
source's placeholder bug intact — that it opens a new matter and runs
intake — and sticks to what's true and generic about how any Claude skill
works: a folder Claude reads before it acts, executed step by step, with a
payoff and a limit. See BUILD-LOG.md for the full account.
