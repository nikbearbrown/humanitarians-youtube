# Claude, Draft.

Claude picked up a skill called draft — did it actually learn legal
writing? No. A "skill" is a folder holding one file, SKILL.md, that Claude
reads before it starts and then follows step by step, in order. Delete the
folder and Claude forgets no drafting ability, because there was nothing to
learn — it just stops following that one routine. That makes a skill a
specification, not a new power: the payoff is the same structure, every
draft; the limit is anything the file never wrote down. And watching Claude
produce a clean draft, or a rough one, proves nothing on its own about
whether it actually understood the matter.

## Deliberately not claimed

This reel does not describe what the draft skill's own SKILL.md
specifically instructs — that file lives in a legal-clinic collection not
reachable from this build, and the source script this reel redoes never
filled in that detail either (its own beat sheet still carries an unfilled
`>` placeholder in three spots plus the handoff clause). Rather than invent
a legal-specific procedure, this reel uses "draft" only as the named
example of a skill-shaped folder (one file, SKILL.md) aimed at producing a
formatted document, and sticks to what's true and generic about how any
Claude skill works: a folder Claude reads before it acts, executed step by
step, with a payoff and a limit. See BUILD-LOG.md for the full account.
