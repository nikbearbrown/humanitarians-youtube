# CARRY-OUT — knowledge-work-plugins--claude-liam-digest

**The line (written before any other narration — GATE C):**

> A Claude digest isn't Claude quietly watching all week — it's a file that
> runs when you ask, and unless you say "weekly," it hands you one day and
> calls it done.

**The wrong guess it is built to defeat:** that the digest skill works
because Claude has been continuously aware of everything happening across
your connected sources, so asking for "a digest" just taps into standing
knowledge — rather than a dormant instruction file that runs once, on
request, and defaults to a one-day window unless told otherwise.

**Survivability test:** repeated cold, in a meeting, a week from now — "the
digest doesn't watch, it only runs when you ask it to, and it only covers
one day unless you tell it to cover more" — still true, still the
distinction that matters, not a summary of the topic.
