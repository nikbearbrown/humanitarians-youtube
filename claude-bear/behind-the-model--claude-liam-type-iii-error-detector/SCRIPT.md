## Deliberately not claimed

- **Not "every answer needs three framings."** B04 states the general method;
  no beat claims a fixed count is required — the source's own revision (a
  fourth framing) shows the count is whatever it takes.
- **Not "divergence proves correctness."** B05 states the limit directly: it
  proves genuinely different questions, not the right one to act on.
- **No accusation that anyone writes bad prompts on purpose.** Trusting a
  technically-satisfying answer is an ordinary assumption, and the reel
  treats it as one.

## Handoff prompt (BHTF, read aloud)

> "I want to use Claude as a Type III error detector — checking whether an
> answer solves the right problem, not just whether it satisfies the problem
> as stated. Take a task I describe and generate three different honest
> framings of it. For each framing, write a candidate answer, then test that
> answer against the other framings. Tell me which answers survive only
> their own framing, which collapse into all of them, and what that says
> about whether I'm solving the right problem."
