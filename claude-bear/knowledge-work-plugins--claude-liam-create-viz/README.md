# Create-Viz Isn't About Making It Pretty

Someone assumes Claude's create-viz skill is about making a chart look nice.
It isn't. Before any styling happens, it matches the chart type to what the
data actually shows — a trend gets a line, a comparison gets a bar, a
distribution gets a histogram, a correlation gets a scatter plot. Then it
enforces rules that can't be styled away: bar charts start at zero, axis
breaks are never hidden, colors are colorblind-safe and used meaningfully,
titles state the actual finding instead of just naming the numbers. Style
comes after accuracy, never instead of it.

pretty, tell me what chart type this data calls for and why, then build it

prettying it up is a separate, later step.

## Deliberately not claimed

This reel never claims style doesn't matter — the skill still applies
typography, color, and layout practice, just after the chart type and
accuracy constraints are settled, not instead of them. It also isn't a claim
that this chart-type table is a universal visualization law: it's the
boundary this specific skill states for itself.
