# QUESTION

**The question:** "Can I just ask Claude to fix this broken code right now?"

**Asked by:** a newcomer who has heard Claude has a "debug" skill and assumes
it's a one-shot fix command — the same thing as saying "fix my code."

**Why it earns a reel:** the answer isn't "yes" or "no" — it's "that's not
what the word means here." Invoking the `debug` skill doesn't hand Claude a
patch to apply; it hands it a fixed four-step session — reproduce, isolate,
diagnose, then fix — run in that order, every time, and only when the
problem matches what the skill actually looks for.

**Source:** redo of `claude-liam-debug` (Teardown, walks the Anthropic
`debug` engineering skill — knowledge-work-plugins family).
