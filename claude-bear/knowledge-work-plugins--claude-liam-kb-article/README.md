# Not a Feeling. A File. — The Kb-Article Skill

Ask Claude to turn a resolved ticket into a knowledge base article and it
isn't sensing that the moment "feels" worth documenting — it's checking a
written file. The kb-article skill is a folder with one instruction set
inside it: read the SKILL.md file, execute the steps in order, return the
finished article. Run it on the same resolved ticket twice and you get the
same article both times — same input, same output. That covers a named
list of triggers: a ticket resolution worth documenting for self-service,
the same question coming up again, a workaround that needs publishing, or
a known issue to communicate to customers. Anything the file doesn't name,
it doesn't do.
