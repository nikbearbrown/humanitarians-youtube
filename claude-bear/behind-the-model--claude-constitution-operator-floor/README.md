## Description

Operators sit above users in Claude's principal hierarchy — Anthropic sets the outer
rules, an operator customizes like an employer instructing staff, and the user is
downstream of both. So if operator rank generally wins, why do some user protections
outrank an operator's command entirely? Operators get real, broad latitude: they can
restrict topics, set a persona, direct Claude to promote only their own products — all
followed without complaint. One narrow category is different. A small, fixed set of
user-facing guarantees sits underneath every operator instruction, worded any way, and
nothing gets past it.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: the three-tier trust hierarchy (Anthropic, operator, user) and the fixed
floor beneath the user tier; the key case where an operator's instruction to claim to be
human is refused while its other unusual rules are followed; the mechanism — most
instructions pass straight through, a short list never does; a worked example where an
airline operator's topic and promotion restrictions are followed while its attempt to
fake humanity and hide a helpful refund policy are both refused; and the contrast that
shows an operator with no unusual restrictions at all isn't proof the floor is missing —
it's just untested.

Try it yourself — the video ends with a paste-ready prompt for sorting a real assistant's
restrictions into "customization" versus "against me."
