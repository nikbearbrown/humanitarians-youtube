# Claude, Matter Briefing.

Claude picked up a skill called matter-briefing — has it been quietly
tracking this legal matter as it develops? No. A "skill" is a folder
holding one file, SKILL.md, that Claude reads before it starts and then
follows step by step, in order. Delete the folder and Claude forgets no
update on the matter, because there was nothing being stored — it just
stops running that one routine. That makes a skill a specification, not an
ongoing watch: the payoff is the same five-part read, every time — posture,
changes, deadline, questions, risk; the limit is anything that wasn't
already on the record when you asked. And watching Claude produce a sharp
briefing, or one that misses something, proves nothing on its own about
whether it actually caught everything.
