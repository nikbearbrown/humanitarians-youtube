"The incident-response skill isn't Claude's judgment about your outage. It's
your team's playbook — triage, communicate, postmortem — typed once and
followed exactly, every time it's asked."

**The wrong guess it defeats:** that Claude "just knows" how to run an
incident because it has read countless postmortems in training — i.e. that
the skill is instinct. It isn't instinct, it's instructions: a SKILL.md file
Claude reads before it acts, with a Steps section it executes in order.

incident-response skill is a written playbook, not Claude's judgment" still
holds regardless of which incident, which team, or which day.
