# Claude Didn't Learn Bioinformatics. It Read a File.

The nextflow-development Claude skill runs nf-core bioinformatics pipelines —
rnaseq, sarek, atacseq — on sequencing data. That sounds like Claude picked up
domain expertise. It didn't. A Claude skill is a folder Claude reads before it
acts: a SKILL.md instruction set, a linear Steps section, and a fixed job. Same
input, same output, every run — and nothing outside what the file says.
