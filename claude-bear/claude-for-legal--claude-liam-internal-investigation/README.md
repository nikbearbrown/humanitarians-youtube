# Claude, Internal Investigation.

Claude picked up a skill called internal-investigation — does that mean it
got judgment about who did something wrong? No. A "skill" is a folder
holding one file, SKILL.md, that Claude reads before it starts and then
follows step by step, in order. Delete the folder and Claude loses no
investigative judgment, because there was none to begin with — it just
stops following that one framework. That makes a skill a specification, not
new judgment: the payoff is the same framework, every investigation, every
time; the limit is anything the file never wrote down. And watching Claude
flag every irregularity, or flag nothing, proves nothing on its own about
whether wrongdoing actually occurred.
