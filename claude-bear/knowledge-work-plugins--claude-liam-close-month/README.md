# Not Judgment. A File. — The Close-Month Skill

Ask Claude to close the month and it isn't reaching for accounting judgment —
it's reading a file. The close-month skill is a folder with one instruction
set inside it: reconcile the books against payment processors, flag anything
that doesn't match, write a plain-language P&L summary, export the finished
packet. Four fixed steps, run in that order, every time. Run it twice on the
same numbers and you get the same four steps both times — same input, same
output. That reliability has exactly one edge: it only does what those steps
say. Anything the file doesn't cover, it doesn't do.
