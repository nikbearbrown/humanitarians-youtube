# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **campaign-plan doesn't make Claude a strategist. It makes Claude fill
> six fixed slots, the same way, every time your words match what the file
> was built to hear.**

## The wrong guess it defeats

That asking Claude for a campaign plan means Claude is exercising creative
marketing judgment — inventing a bespoke strategy the way a strategist
would, tailored freshly to each product. It doesn't invent; it assembles.
The `SKILL.md` names an exact, fixed deliverable — objectives, audience,
messaging, channel strategy, content calendar, success metrics — and that
shape never changes with the product. The skill isn't creative judgment
Claude applies; it's a file Claude reads, and it only reads it when the
request's words match one of the triggers it was written for.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (a skill is a fixed
spec being filled in, not creative strategy being invented) and it also
carries the trigger-matching gotcha in the same breath: match the words,
and you get the repeatable six-piece brief; miss them, and you're back to
whatever Claude would say without the skill at all.

## What it deliberately does not say

- **Not a verdict on the design.** The source's B03 framed the trigger spec
  as "what it gets right" (repeatable results) against "where it bites"
  (anything outside the spec) — Teardown language, including an implicit
  judgment about the trade-off. Plain keeps the underlying fact (matching
  triggers get you the six-piece brief; anything else doesn't) but states
  it as a mechanism boundary, not a critique of the skill's design.
- **Not a claim that Claude has no marketing knowledge.** Claude plainly
  can discuss marketing strategy generally. The reel's point is narrower:
  the skill's output is a fixed deliverable shape, not an on-the-fly
  creative judgment call, and that shape is what makes it repeatable.
- **Not that every phrasing outside the trigger list fails loudly.** The
  source doesn't describe an error state for a non-matching request; it
  simply never starts the pipeline. The reel states that as silence, not
  breakage.
