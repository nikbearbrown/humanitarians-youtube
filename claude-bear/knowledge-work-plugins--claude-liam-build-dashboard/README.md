# The Dashboard Isn't a Live App

Someone hears "build me a dashboard" and assumes a live app — running on a
server, wired to a database, that has to be hosted to be shared. It isn't.
It's one self-contained HTML file, built once from whatever data it's
given, with charts, filters, and a table already wired together, that
opens straight in a browser. The skill covers four situations — an
executive overview with KPI cards, a query result turned into a shareable
report, a team's monitoring snapshot, or several charts with filters
bundled into one file — and nothing outside that list gets a template. The
instructions live in one file Claude reads before it works.

## YOUR TURN

"Build me one self-contained HTML dashboard from this data — charts,
filters, and a table — that I can just open in a browser and share. No
server needed."

That's the whole idea: your own data in, one file out — never a hosted,
live-connected app.

---

## Deliberately not claimed

This reel never claims the dashboard stays connected to a live data source,
a running server, or a refreshing feed — it's built once from whatever
data it's given at build time. It's also not a verdict on whether four
situations is the right set: the boundary (only what the instruction file
specifies gets a template) is stated as fact, not argued with.
