# CARRY-OUT.md

**Carry-out line:** A dashboard here isn't a live app — it's one
self-contained HTML file, built once from your data, with its charts,
filters, and table already wired together to open and share.

**Wrong guess it's built to defeat:** that "build me a dashboard" means a
hosted, live-connected app — something running on a server, wired to a
database, that has to be deployed to be shared. The actual artifact is a
single HTML file: built once from whatever data it's given, then opened
straight in a browser. Nothing to host, nothing that stays connected to a
live source.

**Secondhand test:** "It's one file, not a live app — everything's already
baked in" survives being repeated by someone who wasn't fully listening,
and stays true. It compresses the distinction that matters (one static,
self-contained file vs. a hosted live app), not the topic (dashboards in
general).
