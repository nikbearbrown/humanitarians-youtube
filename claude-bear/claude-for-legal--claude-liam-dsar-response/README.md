# Claude, Dsar Response.

A person asks a company what personal data it holds on them. The easy move
is to check the one system where they're an obvious record — the customer
database, say. That's not enough: someone's data trail scatters across
support tickets, mailing lists, and old accounts a single database was
never built to see. Watch the anchor: one requester found under three
different identifiers — a current email in the database, name-only in the
support tickets, an email they closed two years ago still sitting in the
mailing list. Search only the current email, and the mailing-list record
never turns up. A system returning nothing under one identifier hasn't
ruled the person out — it's only ruled out that identifier. And a record
that does turn up isn't automatically ready to send: a support ticket that
names a coworker too has to be cut back to just the requester's
information first.

## YOUR TURN

"List every system your organization stores customer or user data in, plus
every name, email, and account identifier one specific person has used.
Build a search checklist covering every system and identifier, and flag
anywhere a shared record — like a support ticket naming someone else too —
would need redacting before it goes out."

Why it's worth running: the exercise surfaces the same distinction the
reel is built around — a checklist that covers every identifier catches
every place a single-system search would have missed a record, or shipped
one that wasn't only the requester's.

## Deliberately not claimed

This reel is a reconstruction: the reel this one redoes had never had its
skill-specific facts written (its narration carried literal unfilled
template placeholders, and the SKILL.md file it pointed at doesn't exist).
Rather than invent specific product claims, this script describes the
generic shape of a data subject access request — search broadly under
every identifier, ship narrowly — not any single tool's documented
behavior. It never claims every DSAR is this simple, only that the
ordinary requirement is search everywhere, then redact before it ships.
