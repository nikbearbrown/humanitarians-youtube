# Claude, Competitive Analysis. — The Competitive-Analysis Skill (Market Research)

A skill is a folder Claude reads before it works — this one, competitive-
analysis, is a SKILL.md file and a references folder, two files total. The
pipeline is linear: read SKILL.md, execute each step in order, return the
result — no branching unless a step says so. And it only answers within what
that file specifies: ask for something inside its written scope — a market
map, a peer comparison, a positioning assessment — and it runs the same
steps every time; ask for something outside that scope, and there's nothing
there to answer with.
