# A File, Not a Mode. — The Morning-Note Skill (Financial Services)

A Claude Skill is a single file — SKILL.md — that Claude reads before it
works, not a special built-in mode. The morning-note Skill drafts concise
7am morning-meeting notes from overnight developments, trade ideas, and key
events for a coverage list, and it wakes up on plain trigger phrases like
"morning note" or "what happened overnight." Once triggered, Claude reads
the file top to bottom and executes each step in order — no branching unless
a step says so — which is exactly why it's repeatable: same input, same
output, every run. But that repeatability has a hard edge: the skill only
covers what the file actually says, and can't stretch past it.

## Deliberately not claimed

No claim about how the real, proprietary `morning-note` financial-services
Skill is written internally beyond what its own SKILL.md specifies (the
task, the trigger phrases, and the linear read-then-execute pipeline). No
claim that Claude's judgment about *which* trade ideas or events matter is
itself bounded by the file — only that the *procedure* it follows is. No
trading or investment advice of any kind; the subject here is how a Claude
Skill works, not what to trade.
