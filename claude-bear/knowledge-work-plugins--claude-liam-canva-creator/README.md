# Claude, Canva Creator.

A Claude Skill named `canva-creator` doesn't design anything you ask for — it
fills in a fixed template with your text, colors, and logo, the same way
every time. That's what makes the output repeatable. It's also the whole
limit: ask for a layout the template doesn't cover, and the skill has
nothing to reach for.
