# Same Text, Better Scaffold — Access Scaffolding vs. Text Substitution in ELA

A below-level reader can't access the grade-level text — so the easy move is
a simpler version. But swap the words and you've locked them out of the
grade-level conversation. Access scaffolding keeps the exact same passage on
both tiers: one gets a reading protocol, a two-word vocabulary gloss, and a
comprehension anchor built around it; the other gets the identical words,
clean. Scaffolds add steps and vocabulary support — they never lower the
target. The test that tells a scaffold from a crutch is removal: fade it one
piece at a time, and if comprehension holds without it, it was a scaffold.
If it collapses, it was doing the reading for the student.

scaffolded version for your below-level readers — a reading protocol, a
two-word vocabulary gloss, one anchor question — with the passage's words
left untouched. Then check both versions side by side: are the words

## Deliberately not claimed

No claim about how much a scaffold should reduce cognitive load in general,
or how long a fading schedule should take for any given student — those are
classroom judgment calls the source plugin leaves to the teacher, and this
video doesn't guess at them. No claim that access scaffolding is always the
right call over text substitution; the video states the distinction between
the two approaches, not a verdict that one is universally correct.
