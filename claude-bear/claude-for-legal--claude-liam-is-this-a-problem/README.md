# Claude, Is This A Problem.

Most people assume Claude answers "is this a problem?" the way a person
would — by weighing the situation and forming an opinion. It doesn't. A
Claude skill is a folder with one file, `SKILL.md`, that spells out the
whole instruction set in plain language; for a triage skill like
`is-this-a-problem`, that file is what defines what counts as a problem
here. Claude reads the situation, checks it against the conditions the
file names, and answers. Feed it a situation the file anticipated and it
answers the same way every time — reliable, on repeat. Feed it something
the file never named, and there's nothing to fall back on: not wrong,
just outside what the checklist covers.

escalating, is this a problem. Help me write out the actual criteria I'm
using as a short checklist. Then walk my next three real cases through it
and flag anything that doesn't fit."

matches what you're really checking for, and whether it flags the cases

## Deliberately not claimed

Not a claim about what any specific legal `is-this-a-problem` skill's
criteria are — this reel teaches the generic mechanism (a written
specification decides, not Claude's live judgment) using the skill's name
and structure as the concrete case, not its unpublished internal criteria.
Not a verdict on whether checklist-driven triage is the right design for
any given team — that's Teardown territory; this reel states the
mechanism and its limit, and stops.
