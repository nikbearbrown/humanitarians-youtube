# A Checklist, Not an Algorithm. — The Competitive-Brief Skill (Knowledge-Work Plugins)

A Claude Skill is just a folder Claude reads before it starts working — this
one is called competitive-brief. Inside is one file, SKILL.md, written in
plain language, not a hidden algorithm. The pipeline lives in that file's
Steps section: Claude reads each step in order and executes it, linear,
with no branching unless a step itself says otherwise. This particular
skill does one job — research the competitors, then generate a positioning
and messaging comparison covering content gaps, opportunities, and threats
— and whatever isn't spelled out in those steps, it simply doesn't do.
