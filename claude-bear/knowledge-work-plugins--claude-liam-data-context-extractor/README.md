# The Skill Doesn't Already Know Your Data

Someone assumes Claude already reads their company's data automatically. It
doesn't. A skill called data-context-extractor generates or improves a
data-analysis skill built around your company's own data — a written file,
produced once, that spells out what your tables and columns actually mean.
Claude reads that file before it works, the same way it reads any skill: a
folder, one instruction file in plain language, steps that run in order.
What comes out is built around one company's own definitions, not a
general-purpose one — outside the context the file was given, there's no
fallback, though the same input still returns the same output every time.

## YOUR TURN

"Here's a quick rundown of my company's data — what my key tables and
columns actually mean. Turn this into a written skill file so every future
analysis of my data uses these exact definitions, not a guess."

That's the whole idea: your own definitions in, once, written down — never
an automatic read of your data.

---

## Deliberately not claimed

This reel never claims Claude connects to a live, continuously-updated
database — the skill produces a written file, once, from whatever data
context it's given. It's also not a specific list of use cases: the
source material's own description of the skill's method was incomplete, so
this reel states only the confirmed job (generate or improve a
company-specific data-analysis skill) and the generic mechanics true of
every Claude skill, without inventing a use-case list to fill the gap.
