## Description

Claude can hand back a citation, a claim, and a quantified number in the same paragraph,
in exactly the same confident voice. Fluent, assured prose is a training habit — it looks
identical whether the content underneath is verified or invented. So the natural move is
to proofread: read it over, check that it flows. If it reads clean, it feels checked. It
isn't: a fabricated citation, formatted exactly like a real one, passes every read-through.
Only opening the actual source catches it.

Editing asks "is this clear?" Auditing asks "is this true, traceable, and supported by the
source?" — two different questions, and editing never opens the source. The verification
matrix assigns the right check per output type before you read for clarity: a citation
means opening the source, a number means recomputing a sample and checking the
denominator, a claim means tracing it to one specific sentence. The depth of that check
should match the consequence — light for personal notes, moderate for an internal
document, strict for anything published, submitted, or signed. A client email is strict,
because the consequence is yours.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: why fluent prose isn't an accuracy signal; the difference between editing and
auditing; how the verification matrix assigns a check per output type; the one flag worth
knowing (the matrix assumes you can reach the primary source); and both directions — what
passing every check proves, and what a single failed check does not.

Try it yourself — the video ends with a paste-ready prompt for building your own
verification matrix.
