# Not Guesswork. A File. — The Journal-Entry-Prep Skill

Ask Claude to prep a journal entry and it isn't reaching for trained
accounting sense — it's reading a file. The journal-entry-prep skill is a
folder with one instruction set inside it: read what needs to be booked,
work out the debit and the credit, attach the paperwork that backs it up.
Run it on the same numbers twice and you get the same debit, the same
credit, the same documentation both times — same input, same output. That
covers a named list: accruals, prepaid amortization, fixed asset
depreciation, payroll entries, revenue recognition. Anything the file
doesn't name, it doesn't do.
