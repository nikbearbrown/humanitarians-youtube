## Description

Does "Claude, crm maintenance" mean Claude keeps your CRM tidy in the background, all
the time, on its own initiative? Not quite — a Claude Skill named `crm-maintenance` is a
bounded specification: one SKILL.md file, read in full each time, executed step by step,
producing the same result for the same input every time — never a standing job running
on its own.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the instruction set in one file, SKILL.md, plus a reference folder; how the
pipeline runs, step by step, no branching unless a step says so; and the scope guarantee
that matters — the skill runs once per request, does exactly what the file says, and has
nothing to say about anything outside it.

Try it yourself — the video ends with a paste-ready prompt for making a skill state its
own steps and boundaries before you let it run.
