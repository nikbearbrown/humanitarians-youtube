# Claude, Cowork Plugin Customizer.

A Claude Skill is a folder, not installed software. Inside is a file named
`SKILL.md` — plain-language instructions, no hidden binary. Claude opens
that file before doing anything else. `cowork-plugin-customizer` is one
such folder: its stated job is to customize a Claude Code plugin for one
organization's tools. Claude then works through whatever Steps section the
file lays out, top to bottom, in order — the same request runs the same
sequence every run. That guarantee only covers what's written down: ask for
something the Steps section never anticipated, and Claude isn't wrong to
attempt it, it just isn't following that skill anymore — it's using its own
judgment, off the map the file drew.

## Deliberately not claimed

This reel's source was an unfinished batch build: four of its narration
lines carried a literal unfilled placeholder where a skill-specific detail
was meant to go, and the real `SKILL.md` lives only on a machine outside
this workspace. Nothing behind those placeholders is guessed at. The one
fact the source states outright — "customize a Claude Code plugin for a
specific organization's tools" — is kept as the anchor; how it does that,
step by step, is never invented. The source's own Your Turn task named that
private skill directly, which no viewer could run — this reel generalizes
the same move (read the file, predict the run) to any Skill the viewer
actually has. Not a verdict on the skill's design: going past a Skill's
written scope isn't a failure, it's Claude switching to its own general
judgment.
