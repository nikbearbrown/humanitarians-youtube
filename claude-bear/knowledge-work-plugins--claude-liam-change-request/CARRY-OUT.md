# CARRY-OUT.md

**Carry-out line (written before any other narration, per CARRY-OUT LAW):**

> change-request doesn't make the change — it writes the request: the
> impact, the risk, the rollback plan, for someone else to approve, the
> same way every time.

**The wrong guess it is built to defeat:** that asking Claude to "create a
change request" means Claude will go make the system or process change
itself. It won't — the skill's own job description is to produce a change
management request with an impact analysis and rollback plan, the
document a Change Advisory Board reviews before approving anything. It
writes the proposal; it does not execute it.

**Repeatability test:** if someone repeats only the carry-out sentence in a
meeting next week, having forgotten everything else, it is still true and
still the useful distinction — "change request" means write-up-for-approval,
not do-it-yourself.
