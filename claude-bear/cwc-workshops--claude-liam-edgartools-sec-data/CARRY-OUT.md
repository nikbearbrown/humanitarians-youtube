# CARRY-OUT

> A skill file makes Claude's actions repeatable, not all-knowing — it only
> does what the file actually wrote down.

Test: if someone repeats only this in a meeting next week, is it still true? Yes —
it compresses the key distinction (bounded-but-reliable vs. general expertise)
without overstating either side.

**Wrong guess this defeats:** "Claude now has a skill for SEC data, so it must
generally understand finance and filings — ask it anything and it'll know." The
carry-out replaces that frame: the skill is a fixed list of steps (company lookup,
filings, XBRL statements, sections like Item 1A), not a grant of general expertise —
reliable exactly as far as the file goes, and no further.
