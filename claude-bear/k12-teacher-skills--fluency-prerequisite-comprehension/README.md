# The Fluency Ceiling. — Why Working Memory Limits Comprehension Scaffolds

A student has every comprehension scaffold you can think of — vocabulary
support, a graphic organiser, a reading protocol — and still isn't
comprehending. The instinct is to add a bigger scaffold. That's backwards.
Working memory is conserved: one bar covers the whole reading task, split
between decoding and comprehension. In an illustrative low-fluency case,
seventy-eight percent of that bar goes to decoding, leaving twenty-two
percent for meaning-making; in a high-fluency case decoding drops to twelve
percent and comprehension expands to eighty-eight. The bar doesn't grow —
the split moves. That's why an immediate read-aloud bridge buys time but a
separate fluency intervention is the real fix, why AI can help catch errors
as a student reads aloud but can't substitute the reading itself, and why
only a cold read — a passage never rehearsed — shows whether the split
actually moved. Claude doesn't hand you a bigger scaffold; it helps you
check whether decoding is still effortful first.

## Deliberately not claimed

The 78%/22% and 12%/88% percentages are a teaching illustration, not a
measurement of any real student — the video says so directly. No claim
about exactly how long a fluency intervention should run before it counts
as failed; the video states the test (a cold read on a novel passage) not a
fixed timeline. No claim that AI can run fluency practice unsupervised —
the reader role stays human by design, since the decoding is the
intervention itself. The mechanism (working memory is conserved between
decoding and comprehension) holds regardless of grade level or reading
program.
