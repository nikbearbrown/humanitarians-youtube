# Claude, Month End Prep.

A Claude Skill isn't something Claude learns — it's a folder Claude reads
before it acts, fresh, every single time. The `month-end-prep` skill is a
real example: a `SKILL.md` file holding the whole instruction set in plain
language, plus a small reference folder beside it. Nothing hidden, nothing
trained — the file is the entire program. Inside, the Steps section runs
top to bottom: Claude reads the first step, does exactly that, then moves
to the next, with no branching unless a step itself says so. Run the same
file in January or in June and it opens to identical steps both times —
that's the guarantee: same file, same checklist, every run, nothing
improvised. But it cuts both ways. Leave something a given month actually
needs out of the file, and Claude doesn't invent it — the skill only ever
does what the file says, never what it doesn't.
