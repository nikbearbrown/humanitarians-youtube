## Description

When a Claude Skill called "model update" runs, does it update Claude
itself, or does it update a financial model?

This is Professor Bear's Claude-basics series, narrated by Liam. Today's
worked example is `model-update`, an Anthropic Claude Skill from a
financial-services earnings-review plugin. A Skill is a folder Claude reads
before it acts — one file, SKILL.md, written in plain language, with
instructions run as steps in order. `model-update`'s specific job: given
new data — quarterly earnings, management guidance, macro changes, or a
revised assumption — adjust the estimates, recalculate the valuation, and
flag whatever changed enough to matter. None of that changes Claude. It
changes the model. The investment call still belongs to a person.

Carry-out: a model update doesn't make Claude smarter — it makes the model
current, and the decision still belongs to a person.
