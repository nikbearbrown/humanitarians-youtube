# Claude, Form Generation.

Claude picked up a skill called form-generation — did it learn to draft
legal forms? No. A "skill" is a folder holding one file, SKILL.md, that
Claude reads before it starts and then follows step by step, filling each
field in order. Delete the folder and Claude can still write a sentence,
because there was no drafting talent stored there — it just stops
following that one fixed checklist. That makes a skill a specification,
not drafting power: the payoff is the same field layout, every form; the
limit is any field the file never wrote down. And watching Claude fill out
a clean form, or leave one field wrong, proves nothing on its own about
whether it actually understood the request.

## Deliberately not claimed

This reel does not describe what the form-generation skill's own SKILL.md
specifically fills or how — that file lives in a legal-clinic collection
not reachable from this build, and the source script this reel redoes
never filled in that detail either (its own beat sheet still carries an
unfilled `>` placeholder in four spots). Rather than invent a
legal-specific procedure, this reel uses "form-generation" only as the
named example of a skill-shaped folder (one file, SKILL.md), plus the
well-known, generic shape of a fillable legal form (parties, dates,
signatures), and sticks to what's true and generic about how any Claude
skill works: a folder Claude reads before it acts, executed step by step,
with a payoff and a limit. See BUILD-LOG.md for the full account.
