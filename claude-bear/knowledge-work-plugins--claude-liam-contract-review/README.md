# Is Claude My Contract's Lawyer?

Claude doesn't read a contract like a lawyer, weighing every clause on
judgment. A contract-review skill runs a SKILL.md: a fixed checklist, read
before acting, executed the same way every time. Watch the anchor: run a
freelance contract through it, and the termination clause comes back
flagged — not judged, just noticed, because the checklist says to look
there. Run the exact same contract again and the same flag comes back,
identical: that's consistency, not a verdict on the contract. A flag means
a listed check matched, nothing more. And a clean pass isn't a clean bill
of health either — it just means nothing on the list tripped, and whatever
the list never named stays invisible either way. The read-through is
still yours.

## YOUR TURN

"Before you review this contract, list exactly what you will check for and
what you will not. Then do the review."

That's the whole handoff: paste in any contract, get the checklist made
visible before the checklist runs — so what the review can't see is as
clear as what it can.
