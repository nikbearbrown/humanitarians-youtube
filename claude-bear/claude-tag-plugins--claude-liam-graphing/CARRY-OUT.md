# CARRY-OUT — claude-tag-plugins--claude-liam-graphing

**The wrong guess it defeats:** that Claude already "knows" how to make a
good chart the way a designer has taste for it — so it will just pick the
right chart type, the right colors, and a real title on its own.

**The carry-out line (written first, GATE C):**

> A charting kit doesn't give Claude good taste. It gives Claude judgement
> defaults to start from and a few sharp edges marked — and Claude only
> dodges the edges the kit actually marks.

**Survives-being-repeated test:** someone who only half-heard the reel and
repeats just this sentence next week is still saying something true: a
charting skill is a set of defaults and named traps Claude reads, not design
sense it already had — so it narrows the guessing, it doesn't replace
looking at the result.

**Compresses the distinction, not the topic:** the topic is "the graphing
skill." The distinction is "defaults vs. taste, and marked vs. unmarked" —
which is what every beat before it built toward (B00's correction, B01–B02's
specific kit contents — primitives, data helpers, the four-step workflow,
judgement defaults — B03's both-directions split between what's marked
plainly and what's easy to miss).
