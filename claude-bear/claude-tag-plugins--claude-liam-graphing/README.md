## Description

Does Claude already know how to make a good chart, or does something have to tell it
what to check? Not quite the first — Claude reads a charting kit, a set of judgement
defaults, before it draws anything: how it derives colors from a background, when to
skip a data helper, and what "render and look at the result" actually means.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: five chartkit primitives (theme, palette, finish, save, write_html) and
three data helpers with explicit skip conditions; the four-step workflow — look, infer
colors, write, render and look again; five judgement defaults with permission to
deviate; and the carry-out that matters: a charting kit doesn't give Claude good taste,
it gives Claude defaults to start from and a few sharp edges marked — and Claude only
dodges the edges the kit actually marks.

Try it yourself — the video ends with a paste-ready prompt for testing this on any
dataset you pick, today, in Claude.
