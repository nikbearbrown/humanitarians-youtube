# Claude, Create Cowork Plugin.

Ask Claude to create a Cowork plugin, and it doesn't just generate one on
the spot. The real `create-cowork-plugin` skill runs five phases in order:
Discovery (what should this do, who's it for), Component Planning (which
of Skills, MCP servers, Agents, or Hooks does it need — laid out in a table
you confirm), Design & Clarifying Questions, Implementation (the phase that
actually writes files), then Review & Package. Nothing gets written until
you've confirmed the plan. Say "whatever you think is best" instead of
choosing, and Claude still doesn't guess silently — it gives a specific
recommendation and still waits for your yes.
