# CARRY-OUT.md

**Carry-out line:** Build Zoom Bot doesn't make Claude join your meetings
itself — it makes Claude build the bot: a meeting bot, a recorder, or a
real-time media workflow, assembled from Zoom's own Meeting SDK, RTMS, and
your backend.

**Wrong guess it's built to defeat:** that Claude itself becomes the Zoom
bot — dialing into a call, sitting in as a participant, live, the moment
you ask. The actual value is that Claude writes the software: it reads a
SKILL.md spec and follows it to assemble a bot, recorder, or media
pipeline out of Zoom's own developer pieces — code you then run, not
Claude attending in person.

**Secondhand test:** "Claude doesn't join the call — it builds the bot
that does" survives being repeated by someone who wasn't fully listening,
and stays true. It compresses the distinction that matters (build vs.
personally attend), not the topic (Zoom integrations in general).
