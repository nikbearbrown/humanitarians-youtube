own how to tidy up the CRM — whatever it judges messy, it fixes. It doesn't; the
skill scans HubSpot for exactly three named things and fixes only what the owner
approves.

**Carry-out line (written first, before any other narration):**

> Claude doesn't clean up your CRM however it wants. It scans for exactly what
> the file specifies, and fixes only what you approve.

**Survives-repetition test:** someone repeating only this sentence next week is
still describing what a Claude Skill named `crm-cleanup` does correctly — it
compresses the distinction that matters (bounded scan, approval-gated fix, not
free-form autonomous cleanup) rather than summarizing the topic, and it is not
tied to a detail this build had to invent.
