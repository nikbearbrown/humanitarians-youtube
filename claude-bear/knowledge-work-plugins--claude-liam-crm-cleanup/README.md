## Description

Does "Claude, crm cleanup" mean Claude decides on its own how to tidy up your CRM?
Not quite — a Claude Skill named `crm-cleanup` scans HubSpot for exactly three named
things, and fixes only what the owner approves.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the full instruction set in one file, SKILL.md; how the pipeline runs, step by
step, no branching unless a step says so; the exact scope this skill works under —
stale deals, duplicate contacts, and missing fields in HubSpot, narrowed further by an
optional scope argument (deals, contacts, or all); and the carry-out that matters:
Claude doesn't clean up your CRM however it wants, it scans for exactly what the file
specifies, and fixes only what you approve.

Try it yourself — the video ends with a paste-ready prompt for making a skill state its
own scope before you let it touch anything.
