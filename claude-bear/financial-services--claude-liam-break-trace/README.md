## Description

When Claude finds a break in the books — two records that should match and
don't — does it fix the discrepancy, or just explain it?

This is Professor Bear's Claude-basics series, narrated by Liam. Today's
worked example is `break-trace`, an Anthropic Claude Code Skill from a
financial-services reconciliation plugin. A Skill is a folder Claude reads
before it acts — one file, SKILL.md, written in plain language, with
instructions run as steps in order. `break-trace`'s specific job: given a
break another skill has already flagged, follow the audit trail back, on
each side, to the original transaction or posting, and state exactly what's
different and why. It doesn't decide what to do about the difference — it
never fixes anything. It just finds where the break started.

Carry-out: break-trace finds exactly where two numbers stopped agreeing and
says why — it never decides what happens next.

**Your turn — paste this into Claude:**
"I have two numbers that should match, but they don't. Before you try to
fix anything, walk me through exactly where they first differ and why."
