# Claude, Gaps.

Claude picked up a skill called gaps — does that mean it can now judge
compliance risk on its own? No. A "skill" is a folder holding one file,
SKILL.md, that Claude reads before it starts and then follows step by
step, in order. Delete the folder and Claude loses no compliance
judgment, because there was none to lose — it just stops following that
one tracking routine. That makes a skill a specification, not a new
power: the payoff is the same tracker check, every time — what's open,
what's closed, what's been risk-accepted; the limit is anything the file
never wrote down. And watching Claude close a gap cleanly, or mishandle a
tracker update, proves nothing on its own about whether it actually
understood the underlying risk.
