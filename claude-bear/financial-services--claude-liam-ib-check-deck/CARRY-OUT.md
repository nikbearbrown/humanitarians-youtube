# CARRY-OUT.md

**Carry-out line:** A skill like this doesn't proofread a deck — it reconciles it:
the same four checks, every slide, every run, and nothing outside that checklist
gets caught.

**Wrong guess it's built to defeat:** that "checking" a deck before sending it just
means a spellcheck / read-through for typos. The actual value is structural
reconciliation — numbers that stop agreeing across slides, a narrative that drifts
from the data — the kind of error a spellcheck cannot see and a tired eye misses
on the fifth read-through.

**Secondhand test:** "It reconciles the deck — same four checks, every slide, every
run" survives being repeated by someone who wasn't fully listening, and stays true.
It compresses the distinction that matters (structural reconciliation vs.
proofreading), not the topic (pitch decks in general).
