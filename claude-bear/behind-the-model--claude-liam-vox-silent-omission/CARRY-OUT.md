# CARRY-OUT — behind-the-model--claude-liam-vox-silent-omission

**The sentence:** "A confident 'done' only tells you what finished — never
what got skipped. Ask for the count, not just the completion."

**Test:** repeated by someone who wasn't paying full attention next week —
still true. It compresses the distinction that matters (what a completion
report proves vs. what it can't), not the topic (agent reliability in
general).

**The wrong guess it defeats:** that if an agent says a task is complete, it
must have gone through everything there was to go through — that a confident
finish is proof of a full pass. It isn't: a six-bullet brief can read exactly
that confident and still have been built from a folder scan that skipped
three dissenting documents in a subfolder it never opened, one of which said
the opposite of the recommendation. No error ever appeared, because the
report only tallies what succeeded.

**Source of the line:** `anthropics/youtube/behind-the-model/claude-liam-vox-silent-omission`
beat B12 (endcard): "A completion report should predict a complete scan.
Here is why it does not: the report is built from successful operations, not
from a census of everything that existed. Ask for the inventory, not just
the result." Kept verbatim in spirit; compressed to survive repetition per
CARRY-OUT LAW.
