# Claude, Log Leave.

Claude picked up a skill called log-leave — does that mean it can approve
an employee's leave request on its own? No. A "skill" is a folder holding
one file, SKILL.md, that Claude reads before it starts and then follows
step by step, in order. Delete the folder and Claude loses no approval
authority, because there was none to begin with — it just stops following
that one checklist. That makes a skill a specification, not new judgment:
the payoff is the same log entry, every leave request, every time; the
limit is anything the file never wrote down. And watching Claude log an
entry cleanly, or flag one as incomplete, proves nothing on its own about
whether the request was actually judged right.

specifically instructs — that file lives in an employment-legal collection

never filled in that detail either (its own beat sheet still carries an

reads before it acts, executed step by step, with a payoff and a limit.
