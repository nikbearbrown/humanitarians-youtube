# Claude, Launch Your Agent. — The Launch-Your-Agent Skill (Claude Managed Agents)

A skill is a folder Claude reads before it works — this one is called
launch-your-agent, and the SKILL.md inside it is the full instruction set,
written in plain language. Inside is a Steps section, the pipeline: find
out what the founder wants to build, scope a v0, launch it into their
account, grade the result, iterate, and — if it should run on a clock —
put it on a scheduled deployment, with anything bigger laid out as v1 and
v2. Execution is linear, no branching. Because it's a fixed specification
rather than open-ended judgment, it behaves the same way every time: same
input, same output, every run — and that reliability has an edge, since
Claude only does what the SKILL.md actually specifies. Telling Claude to
launch your agent doesn't launch a finished product; it launches a v0
into your account, then earns anything bigger through grading and
iteration.

## Deliberately not claimed

No claim about how Claude decides, moment to moment, when a step's
instructions are ambiguous enough to need judgment rather than a literal
read of the SKILL.md — the source Skill documents the steps, not its own
internal decision process, and this video doesn't guess. No claim that
every Claude Managed Agents build ends up scheduled or grows to v1/v2;
the skill only puts a build on a scheduled deployment if it should run on
a clock, and "everything bigger" is a stated option, not a guarantee.
