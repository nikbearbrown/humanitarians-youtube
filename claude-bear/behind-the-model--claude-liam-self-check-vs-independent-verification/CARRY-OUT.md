# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **A self-check can only confirm what it already believes — verification
> means checking against a source the agent never wrote.**

(Compressed from the source's B07 summary beat — "Self-check improves output
at the margins but cannot catch systematic errors -- the agent checks its
claims against the same representations it used to generate them.
Independent verification is what makes 'verified' mean something." —
restated in Plain register. It states mechanism, not a design judgment, so
nothing needed removing.)

## The wrong guess it defeats

That when Claude checks its own answer and calls it "verified," that settles
the matter. That's backwards: a citation swapped for a paper that doesn't
support the claim can still come back "verified" from a self-check, because
the check reasons from the same claim it's supposed to be testing, not from
the paper itself. Only opening the actual source — evidence from outside the
agent's own reasoning — catches the mismatch.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (checking your own
claim again vs. checking it against something you didn't write) without
claiming self-checks are worthless or that every self-check misses errors.

## What it deliberately does not say

- Not a claim that self-check is worthless — the source's own five-claim
  pass shows it can and does come back genuinely clean on unaltered claims
  (direction B, B06).
- Not a claim that catching one planted error means every claim in the
  summary got equally rigorous scrutiny — a check proves what it specifically
  checked, not more (direction A, B05).
- Not a claim that agents can never be trusted to self-report — it's a claim
  about what counts as *independent* evidence, not a blanket suspicion.
