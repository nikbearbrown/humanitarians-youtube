## Description

Can Claude decide which contract issues kill a deal? Not quite — a diligence
issue-extraction skill screens a batch of documents against the categories a SKILL.md
specifies (things like change-of-control clauses, missing consents, expired licenses)
and returns a structured issues report. Deciding which issues actually kill the deal is
still yours.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the full instruction set in one file; how the pipeline runs, step by step, no
branching unless a step says so; the exact constraint this skill screens to (the
categories the file specifies, flagging anything that matches); and the carry-out that
matters: same documents in, same issues report out, every time — but deciding which
issues actually kill the deal is still yours.

Try it yourself — the video ends with a paste-ready prompt for screening your own next
batch of documents in Claude today.
