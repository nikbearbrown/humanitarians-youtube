# Philosophy Before Canvas. — The Canvas Design Skill

Ask Claude for a poster and a picture does come back — but not immediately.
The canvas-design skill is a two-step pipeline in one skill file: step one,
Claude writes a design philosophy — it names an aesthetic movement, something
like Geometric Silence, and describes it across four to six paragraphs
covering form, space, color, and composition. Step two, Claude reads that
philosophy back and generates the canvas itself, a single PDF or PNG page.
The philosophy comes first, every time — it's the brief the second step
follows, and there's no loop back to revise it. The philosophy itself names
five visual dimensions (space and form, color and material, scale and
rhythm, composition and balance, visual hierarchy), and one word keeps
recurring on purpose: craftsmanship, repeatedly emphasized so the finished
piece looks like it took countless hours to make. One more thing worth
noticing: the skill's final step opens with a line that's already written
into it — "the user already said it isn't perfect enough" — so a refinement
pass runs on every canvas, regardless of how the first draft turned out.
