## Deliberately not claimed

- **Not "fluent AI answers are usually wrong."** The claim is narrower:
  fluency only ever answers the cognitive question, not the moral one.
- **Not "disclosure fixes it."** B06 states the opposite — a hedge or an
  AI-written label isn't the same as naming who's accountable.
- **No accusation of anyone building bad tooling.** The gap between feeling
  right and being accountable is treated as an ordinary category error, not
  a failure by any one person or team.

## Handoff prompt (BHTF, read aloud)

> "I want to run a legitimacy audit on an AI answer I'm about to act on,
> using Suchman's three types. Check: does it serve my actual interest —
> pragmatic; is a specific person or role named as accountable if it's
> wrong — moral; and am I trusting it because it sounds right, or because I
> can trace it — cognitive. Tell me which one is missing."
