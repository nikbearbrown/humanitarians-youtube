# Claude, Investigation Add.

Claude picked up a skill called investigation-add — does that mean it can
open a workplace investigation on its own? No. A "skill" is a folder
holding one file, SKILL.md, that Claude reads before it starts and then
follows step by step, in order. Delete the folder and Claude loses no
investigative authority, because there was none to begin with — it just
stops following that one checklist. That makes a skill a specification,
not new judgment: the payoff is the same intake, every investigation,
every time; the limit is anything the file never wrote down. And watching
Claude fill in every field, or leave one blank, proves nothing on its own
about whether the case was actually judged right.

SKILL.md specifically instructs — that file lives in an employment-legal
