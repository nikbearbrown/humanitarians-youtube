# Claude Doesn't Write One Email. It Designs the Sequence. — The Email-Sequence Skill

A skill is a folder Claude reads before it works — this one is
`email-sequence`, and its SKILL.md is the whole instruction set, in plain
language, no hidden logic. The instructions run in order: read the file,
then run each step. The actual job isn't drafting one message — it's
designing the full multi-email flow: copy for every send, timing between
them, branching logic for opens and clicks, exit conditions, and benchmarks
to judge it by. Built for onboarding, lead nurture, win-back,
re-engagement, and launch flows. Ask it for an email, and email-sequence
hands back the whole sequence — built the same way every time.
