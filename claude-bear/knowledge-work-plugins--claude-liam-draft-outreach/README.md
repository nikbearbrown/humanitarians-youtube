# Claude, Draft Outreach.

You ask Claude to draft outreach to a real prospect. The natural guess is
that it already knows the company — pulling color from what it remembers
from training, not from anything checked today. It doesn't work that way.
`draft-outreach` is a **skill**: a folder Claude reads before it acts,
a single file (`SKILL.md`), that names exactly one job in two steps —
research a prospect, then draft personalized outreach — with web research
running **by default**, and named triggers ("draft outreach to," "write
cold email to," "reach out to"). Say a prospect closed a funding round
last week — the line in the draft that mentions it isn't recalled from
training, which has a cutoff; it's what the research step found when it
actually looked. That default can be supercharged with enrichment and CRM
data, but the base habit is the same: go check, don't guess. When a draft
reads generic instead, that doesn't mean it broke: it can mean the research
turned up little, or those extra sources aren't hooked up.
