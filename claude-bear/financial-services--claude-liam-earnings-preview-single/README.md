# Claude, Earnings Preview Single.

Claude picked up a skill called earnings-preview-single — does that mean it's
now analyzing the numbers and deciding if a stock is a buy? No. A "skill" is
a folder Claude reads before it starts; this one holds a report template and
a SKILL.md that tells Claude how to fill it in — pull the latest earnings
transcript, map the competitor landscape, note the valuation, and fold in
recent news. Delete the folder and Claude loses no investment opinion,
because there was none to begin with — it just stops filling in that one
template. That makes it a template-filler, not a stock picker: the payoff is
the same four-to-five page structure, filled from real inputs, every time;
the limit is anything the template never asked for. And a report that reads
confident, or one that hedges, proves nothing on its own about whether the
numbers were actually checked.
