# QUESTION.md

**Question (as a newcomer would actually ask it):** When Claude runs an
Anthropic Skill like `comps-analysis`, does it reason its way through the
task the way an analyst would — or does it just follow a written file,
step by step?

**Who asked:** no single asker; this is a redo (hai-simple, `mode: "redo"`)
of the Teardown reel `claude-liam-comps-analysis`, which taught the anatomy
of the `comps-analysis` Anthropic Skill (a `market-researcher` plugin skill,
financial-services family) without ever posing the question this directly.
This reel makes the question the newcomer actually has explicit and answers
it in the Plain register.

**Name use:** n/a — no named individual asker.

**Wrong guess this reel exists to correct:** that a Skill is loose guidance
Claude interprets and reasons through, the way a person would read a memo.
It isn't — a Skill is a spec Claude reads and executes, one step at a time,
in the order written.
