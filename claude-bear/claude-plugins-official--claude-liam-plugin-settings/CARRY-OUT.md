> A plugin's settings file works per project, not globally, and no change
> takes effect until Claude Code restarts. Set it, save it, restart it —
> that's the whole contract.

**Wrong guess it defeats:** that flipping a setting — an enabled flag, in a
per-project settings file — applies the moment you save it (B00's
hesitant-writer correction: "now" → "later" — the naive framing asks
whether a toggled setting takes effect now, the corrected question asks
whether it takes effect later, which is what the rest of the reel shows:
the file lives at a fixed per-project path, three different consumers read
it, hooks are built to quick-exit safely when it's absent, and the one
value that never carries over between projects is the setting itself).
