# Claude, Mining — What's Actually in a Skill

You'd guess Claude just "knows" the answer — that a skill for Claude means
built-in knowledge, like a plugin unlocking a new ability. It doesn't work
that way. A Claude skill is a folder Claude checks before it acts, and this
one, called "mining," has exactly one file inside: `SKILL.md`. Open it and
there's no reasoning, no cross-referenced guide — one sentence: "where
diamonds spawn in Minecraft 1.20." That's the entire file. Claude reads it,
then acts on it directly: no branching, no invented steps. Ask the same
question twice and you get the identical answer, every time — that
consistency is real. But ask about a different Minecraft version, or a
different resource entirely, and there's nothing left to reach for. The file
only ever said the one thing.

## Deliberately not claimed

No claim that every Claude Skill is this small — "mining" is used because
it's the source example and makes the point vividly, not because all skills
are one sentence. No verdict on whether "mining" is a *well-built* skill:
the reel states what the file contains and what Claude does with it, and
stops there. No claim that Claude is otherwise ignorant of Minecraft — only
that *this skill's* answer comes from the one sentence in its file, not from
general training recall.
