# Claude, Earnings Preview — What a Preview Skill Actually Previews

Can Claude predict what a company's earnings will be? No — it can preview
them. A Claude skill is a folder Claude reads before it acts: this one is
called earnings-preview, and its SKILL.md holds plain-language
instructions, no hidden code. The instructions live in a Steps section
Claude reads and executes in order — linear, no branching unless a step
calls for it. This particular skill's job: build pre-earnings analysis —
estimate models, bull-and-bear scenarios, and the handful of metrics
likely to move the stock. That's the whole brief; it doesn't forecast the
number itself. A skill can get Claude ready for earnings day — the same
estimate models and scenarios, every time. It still won't tell you what
the report will say.

## Deliberately not claimed

No claim about whether earnings-preview (or any specific skill) ships by
default with a given Claude plan — the video describes the general
mechanism (a folder, a SKILL.md, a Steps section) that any Claude Agent
Skill follows, not a promise about availability. No claim about the
quality or accuracy of any scenario the skill produces, since that depends
on the data supplied at run time, not the file's structure. The
estimate-model / bull-bear-scenario / metrics-to-watch scope is this
specific skill's stated brief, not a general property of Claude skills.
