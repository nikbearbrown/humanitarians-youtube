# Runs the Steps, Not Its Own Reasoning. — The Merger-Model Skill (Anthropic Skills)

When Claude builds a merger model, it doesn't reason its way through the
deal the way an M&A analyst would. A Skill is a folder — this one is
merger-model — with a SKILL.md file inside it that is the full
instruction set. Claude reads the file's Steps section and executes each
step, one at a time, in the order written. That's what the file
specifies: accretion or dilution analysis for an M&A deal — pro forma EPS
impact, synergy sensitivities, purchase price allocation. Run it on the
same two companies twice and you get the same result, both times — but
step outside what the file actually says, and there's nothing written
down to fall back on.
