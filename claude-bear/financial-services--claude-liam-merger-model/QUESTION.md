# QUESTION.md

**Question (as a newcomer would actually ask it):** When Claude builds a
merger model — accretion/dilution, pro forma EPS, the whole thing — is it
reasoning through the deal the way an M&A analyst would, or is it just
following a written file, step by step?

**Who asked:** no single asker; this is a redo (hai-simple, `mode: "redo"`)
of the Teardown reel `claude-liam-merger-model`, which walked the anatomy
of the `merger-model` Anthropic Skill (an `investment-banking` plugin
Skill, financial-services family) without ever posing the question this
directly. This reel makes the question the newcomer actually has explicit
and answers it in the Plain register.

**Name use:** n/a — no named individual asker.

**Wrong guess this reel exists to correct:** that building a merger model
means Claude reasons and judges its way through deal economics, the way an
analyst forms a view. It doesn't — `merger-model` is a spec Claude reads
and executes, one step at a time, in the order written.
