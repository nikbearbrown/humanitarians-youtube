## Description

When Claude runs customer-pulse-check on a pile of complaints, does it
send the replies itself, or does it just find the pattern and draft them?

This is Professor Bear's Claude-basics series, narrated by Liam. Today's
worked example is `customer-pulse-check`, an Anthropic Claude Skill. A
Skill is a folder Claude reads before it acts — one file, SKILL.md,
written in plain language, with instructions run as steps in order.
`customer-pulse-check`'s specific job: pull complaints from PayPal
disputes, HubSpot tickets, and review exports, group the recurring themes,
rank the top three, and draft a reply template for each — with an optional
since-date argument. It doesn't decide which replies go out. It drafts
them — sending one is still a person's call.

Carry-out: customer-pulse-check finds the repeating complaints and drafts
a reply for each — it never decides which ones actually go out.

**Your turn — paste this into Claude:**
"I have a stack of customer complaints. Before drafting any responses,
find the three that come up most often, tell me what people are actually
saying, and only then draft a reply for each — leave it to me whether any
of them goes out."
