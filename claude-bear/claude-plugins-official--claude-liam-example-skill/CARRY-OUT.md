**Carry-out line (BCRY narration):**
> A skill's description isn't a summary of what it does — it's the trigger
> Claude reads to decide when to use it. Write it as an activation rule, not
> a topic blurb.

**Wrong guess it defeats:** that naming the skill's topic in the description
is enough for Claude to activate it (B00's hesitant-writer correction:
"topic" → "trigger" — the naive framing asks if a topic description tells
Claude when to use the skill; the corrected question asks whether a trigger
description does, which is what the rest of the reel shows: the description
field is the activation mechanism itself, the good pattern names specific
phrases/keywords/topics as trigger conditions rather than a topic label, and
the skill's own advice to "test that it activates" comes with no method to
do so).

**Test:** if someone repeats only this sentence next week, it is still true
and still the distinction that matters — not a summary of the whole topic.
