# Claude, Compose Outreach.

You ask Claude to draft outreach to a real contact. The natural guess is that
it free-styles the personal touch — inferring a detail from its own general
sense of the contact. It doesn't. `compose-outreach` is a **skill**: a folder
Claude reads before it acts, containing `SKILL.md` and a `references` folder,
that names exactly one job (generate personalized outreach messages using
**Common Room signals**) and exactly what triggers it (four phrases: "draft
outreach to," "write an email to," "compose a message for," or any
outreach-drafting request). Say a contact's title changed since your last
outreach — the line in the draft that mentions it isn't a flourish Claude
invented, it's the signal the file told it to go find. When a draft reads
generic instead, that doesn't mean it broke: it can mean no strong signal was
on file, and the file never says invent one to fill the gap.
