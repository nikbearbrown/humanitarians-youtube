## Description

Does "Claude, interview prep" mean Claude conducts the interview itself? Not quite —
a Claude Skill named `interview-prep` builds a structured interview plan, competency-
based questions, and a scorecard before a person runs the interview, and it never
conducts the interview itself.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the full instruction set in one file, SKILL.md; how the pipeline runs, step by
step, no branching unless a step says so; the exact scope this skill works under —
one structured interview plan, built from competency-based questions and a scorecard,
triggered by phrases like "interview plan for", "interview questions for", "how should
we interview", or "scorecard for"; and the carry-out that matters: Claude doesn't
interview the candidate, it preps the plan — same role in, same questions and
scorecard out, every time.

Try it yourself — the video ends with a paste-ready prompt for making a skill state its
own scope before you let it run.
