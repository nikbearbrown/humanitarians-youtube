# Claude, Investigation Memo.

Claude picked up a skill called investigation-memo — does that mean it got
judgment about what happened? No. A "skill" is a folder holding one file,
SKILL.md, that Claude reads before it starts and then follows step by step,
in order. Delete the folder and Claude loses no investigative judgment,
because there was none to begin with — it just stops following that one
template. That makes a skill a specification, not new judgment: the payoff
is the same memo structure, every investigation, every time; the limit is
anything the file never wrote down. And watching Claude produce a thorough
memo, or a thin one, proves nothing on its own about whether it actually
understood what happened.

## Deliberately not claimed

This reel does not describe what the investigation-memo skill's own
SKILL.md specifically instructs — that file lives in an employment-legal
collection not reachable from this build, and the source script this reel
redoes never filled in that detail either (its own beat sheet still carries
an unfilled `>` placeholder in two spots, plus a truncated, unfinished
sentence in two others). Rather than invent an employment-law-specific
procedure, this reel uses "investigation-memo" only as the named example
of a skill-shaped folder (one file, SKILL.md, writing up an investigation
in a fixed structure), and sticks to what's true and generic about how any
Claude skill works: a folder Claude reads before it acts, executed step by
step, with a payoff and a limit. See BUILD-LOG.md for the full account.
