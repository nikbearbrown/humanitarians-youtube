# Same Close, Same Order. — The Close-Management Skill (Task Sequencing & Status Tracking)

A skill is a folder Claude reads before it acts — this one, close-management,
manages the month-end close process: task sequencing, dependencies, and
status tracking. Inside is a SKILL.md written in plain language, no hidden
code, plus a Steps section Claude executes in order — linear, no branching
unless a step explicitly says to branch. Because it's a fixed specification,
following it produces the same sequence every time. But it only covers what
it names: anything a real close needs that the file never wrote down, this
skill doesn't handle.

## Deliberately not claimed

No claim about how close-management behaves outside the exact task
sequencing, dependency-tracking, and status-tracking scope its SKILL.md
names — the source Skill doesn't document handling for anything broader,
and this video doesn't guess. No claim that a linear, non-branching Steps
section is how every Anthropic Skill is built; it's this particular Skill's
design, and the "only for what it names" limit is a property of this
specific spec, not a claim about every possible skill file.
