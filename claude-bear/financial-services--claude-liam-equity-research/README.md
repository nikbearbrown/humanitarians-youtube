# Claude, Equity Research.

`equity-research` is a Claude Skill: a folder Claude reads before it works,
not a specialized or separately trained model. It's one file, `SKILL.md`,
written in plain language. Its stated purpose: combine analyst consensus
estimates, company fundamentals, historical prices, and macroeconomic
context into a research snapshot — for researching stocks, comparing
estimates to actuals, analyzing financials, assessing valuations, or
building investment cases. Ask Claude to research one company and it opens
that file and runs the steps in order — pull the estimates, the
fundamentals, the prices, the macro context — then assembles them into one
snapshot, the same way every time. Ask it something the file never wrote
down, like whether to buy the stock, and nothing happens — not Claude
refusing to think, just no step for it. And the reverse holds too: a clean
snapshot back doesn't mean the numbers were checked or judged — the file
only assembled what its steps say to pull.

## Deliberately not claimed

Not a verdict on the skill's design — the source framed this as "what it
gets right: repeatable results. What it bites: anything outside the spec,"
Teardown language; this reel keeps the same underlying facts (repeatable
because it's a spec; bounded to what the spec says) but states them as
mechanism boundaries, not a critique of the file. Not a specific company,
estimate, or price — the source narration never names one, and neither does
this reel; the one concrete case shows what runs, not what number comes
back. Not a claim that Claude in general can't reason about valuation
questions — the boundary demonstrated is this file's steps, not Claude's
general capability.
