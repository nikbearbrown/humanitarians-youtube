## Description

Does "Claude, lead triage" mean Claude decides, on its own judgment, which leads are
worth chasing? Not quite — a Claude Skill named `lead-triage` is a bounded
specification: one SKILL.md file, read in full each time, executed step by step,
producing the same result for the same input every time — never an autonomous verdict
on a lead's worth.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the instruction set in one file, SKILL.md, plus a reference folder; how the
pipeline runs, step by step, no branching unless a step says so; and the scope
guarantee that matters — the skill runs once per request, does exactly what the file
says, and has nothing to say about anything outside it.

Try it yourself — the video ends with a paste-ready prompt for making a skill state its
own steps and boundaries before you let it run.
