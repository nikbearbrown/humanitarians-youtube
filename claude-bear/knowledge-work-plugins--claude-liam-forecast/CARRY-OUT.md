# CARRY-OUT

> The forecast weighs probability, not certainty — a stage-weighted number tells
> you how big your pipeline is, never which deals inside it will actually close.

Test: if someone repeats only this in a meeting next week, is it still true?
Yes — it compresses the whole mechanism (amount × stage probability, summed) and
its actual limit (a size, not a prediction of specific outcomes) without
overstating either.

**Wrong guess this defeats:** "the forecast skill predicts which deals will close"
(or its mirror, "a low-probability deal is basically dead"). Both miss that the
skill has no opinion about any single deal — it multiplies each deal's amount by
a stage probability (negotiation 80%, discovery 20%, by default) and sums the
result. A deal sitting in the high-confidence "Commit" bucket can still stall for
lack of activity; a 20%-probability deal in Discovery can still close. The number
is a weighted size of the pipeline, not a forecast of any one deal's fate.
