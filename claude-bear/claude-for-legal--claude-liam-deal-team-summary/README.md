Claude, Deal Team Summary.

Does Claude just know how to write a deal-team status update? It doesn't — it reads
instructions first, from a file called a skill. A merger needs one shared picture across
the whole deal team (parties, key terms, status, open issues, next steps), and asking
five people for that picture gets five different shapes. A Claude Skill fixes that: a
folder Claude reads before it acts, containing one file, SKILL.md, whose steps run in a
fixed order — pull the parties, pull the terms, check status, flag open issues, list next
steps. Run it on the same illustrative deal (Aster Corp buying Vale Robotics) twice, a
week apart, and the same five fields come back in the same order — only the contents
update. That consistency isn't a fact-check on the underlying documents, and two
summaries that look different without the skill aren't necessarily wrong either — that's
the exact inconsistency a skill removes.
