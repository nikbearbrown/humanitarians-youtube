# Claude, Draft Content. — The draft-content Skill (Marketing Copy, Channel-Formatted)

A Claude skill is a folder Claude reads before it works — a SKILL.md file
holding the full instruction set in plain language, nothing hidden. Claude
reads the file, then acts, running each step in a Steps section in order,
start to finish. This particular skill, draft-content, has one job: draft
marketing content — blog posts, social media, email newsletters, landing
pages, press releases, and case studies — with channel-specific formatting
and SEO recommendations attached, for three named moments: writing any
marketing content, generating headline or subject-line options, or adapting
a message for a specific platform, audience, and brand voice. Outside those
three moments, the file has nothing to say. Same input, same output, every
time you run it — a skill isn't a new writing talent, it's one file doing
one job.
