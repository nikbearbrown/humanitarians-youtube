## Description

Does the comp-analysis Skill decide what to pay someone on its own, like an app would?
Not quite — Anthropic's comp-analysis skill benchmarks pay, places roles in bands, and
models equity grants from the data and roles you give it, all from one instruction file
(SKILL.md) that Claude reads and follows step by step.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the full instruction set in one file; how the pipeline runs, step by step, no
branching unless a step says so; the exact job this skill does (benchmark pay, place
roles in bands, and model equity grants); and the carry-out that matters: a Skill
doesn't give Claude judgment about pay, it makes Claude run your benchmarking steps, in
order, every time.

Try it yourself — the video ends with a paste-ready prompt for watching Claude read and
follow a Skill file step by step, using your own toy example.
