# Claude, First Run.

Watch Claude pick up a documented skill for the first time and it looks like magic —
like the behavior must be built into the model. It isn't. Using the real Anthropic
skill named `first-run` as the specimen, this video opens the file: one folder, one
`SKILL.md`, written in plain language. Claude reads it before acting, runs its Steps
section in order, and has nothing to say about anything the file never described.
A skill isn't a built-in capability — it's a folder of instructions, followed exactly,
only as far as the file goes.
