# Drafting an Offer Isn't Just the Letter

Someone assumes drafting an offer means writing the congratulatory letter.
It isn't. It's the full comp package — base, equity, signing bonus — the
offer letter text itself, and negotiation guidance for the hiring manager,
once a candidate's ready to hire. The instructions live in one file Claude
reads before it works; ask for anything outside those three parts and
there's no mode that covers it.

## Deliberately not claimed

This reel never claims the skill negotiates directly with the candidate —
the negotiation guidance is scoped to the hiring manager, exactly as the
source specifies. It also isn't a claim that this replaces HR or legal
review: the boundary (only what the instruction file specifies gets
covered) is stated as fact, not argued with.
