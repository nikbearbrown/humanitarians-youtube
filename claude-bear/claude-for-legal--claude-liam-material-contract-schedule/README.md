# Claude, Material Contract Schedule.

Claude picked up a skill called material-contract-schedule — did it
actually learn contract law? No. A "skill" is a folder holding one file,
SKILL.md, that Claude reads before it starts and then follows step by
step, in order. Delete the folder and Claude forgets no contract law,
because there was nothing to learn — it just stops following that one
routine. That makes a skill a specification, not a new power: the payoff
is the same schedule structure, every time — one row per contract, the
same columns filled in; the limit is anything the file never wrote down.
And watching Claude fill in every row, or leave gaps, proves nothing on
its own about whether the review actually happened.

## Deliberately not claimed

This reel does not describe what the material-contract-schedule skill's
own SKILL.md specifically instructs — that file lives in a corporate-legal
collection not reachable from this build, and the source script this reel
redoes never filled in that detail either (its own beat sheet still
carries an unfilled `>` placeholder in four spots). Rather than invent a
legal-specific procedure, this reel uses "material-contract-schedule" only
as the named example of a skill-shaped folder (one file, SKILL.md), plus
the well-known, generic shape of a material contracts disclosure schedule
itself (a document, produced during M&A diligence, listing contracts
material to a deal), and sticks to what's true and generic about how any
Claude skill works: a folder Claude reads before it acts, executed step by
step, with a payoff and a limit. See BUILD-LOG.md for the full account.
