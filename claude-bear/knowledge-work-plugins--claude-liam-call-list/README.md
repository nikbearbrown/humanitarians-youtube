# Claude, Call List. — The Call-List Skill (Small Business)

A skill is a folder Claude reads before it works — this one, call-list, is a
single SKILL.md file. The pipeline is linear: read SKILL.md, execute each
step in order, return the result — no branching unless a step says so. And
it only answers within what that file specifies: rank the five leads most
worth calling today, pull talking points from email history, block time on
the calendar, draft the follow-up — ask for something outside that written
scope, and there's nothing there to answer with.

## Deliberately not claimed

No claim about how Claude internally decides which lead is a better fit —
the source Skill documents the procedure (read, execute, return), not the
model's internal reasoning, and this video doesn't guess. No claim that
every Claude skill works this way; the read → execute → return, no-branching
pipeline is a property of this specific Skill's written steps, not a claim
about every possible Skill.
