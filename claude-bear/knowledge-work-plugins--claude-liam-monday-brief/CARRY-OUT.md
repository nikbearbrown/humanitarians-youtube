# CARRY-OUT.md

**Carry-out line:** Claude doesn't already know your Monday numbers — it
checks them, against a written file that says exactly what counts, and
returns exactly that, the same way every time.

**Wrong guess it is built to defeat:** that Claude already "knows" your
business — cash, sales, pipeline — the way a person who's been paying
attention would, and just recites it back on Monday. It doesn't. It has no
memory of your numbers between runs; it follows a file that specifies exactly
five things to check and nothing else.

**Secondhand test:** "It checks your numbers against a written file that says
exactly what counts, and returns exactly that, every time" survives being
repeated by someone who wasn't fully listening, and stays true. It compresses
the distinction that matters (checks a spec, not recalls from memory), not
the topic (Monday briefings in general).
