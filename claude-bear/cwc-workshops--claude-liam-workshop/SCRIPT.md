## Body — anatomy, the no-peeking rule, the artifact/world gap

**NB01 — A skill is a folder** (source B01, anatomy)
A skill is a folder Claude reads before it acts. This one is `workshop` — a
coach for a seven-act SEC-agents training, acts zero through six. The file
spells out two modes: you drive while Claude hints, or Claude makes the
change and walks you through it after. Either way, it's still one text
file, followed act by act.

**NB02 — No peeking at the answer key** (replaces source B02's generic
pipeline diagram + source B03's design tell; re-registered Teardown → Plain,
re-grounded against the skill's own text)
Here's the interesting constraint: even when a step breaks, Claude isn't
allowed to shortcut it. The file explicitly bars reading the solutions
folder or the project's git history for the fix. Instead, it checks the
real documentation and the error message, fixes it forward, and explains
what changed — the same explanation it gives when the step just works.
Stuck or not, the explanation has to come from understanding the stub,
never from copying a known answer.

**NB03 — The script, and the understanding** (source B04, the Plato/lens
move; re-registered Teardown → Plain)
The file also fixes exactly how each explanation is shaped: what changed,
why it works, the platform idea behind it, where to see it live, one thing
to try. That's the artifact — Claude's coaching script. Whether the
participant actually walks away understanding how a managed agent works is
a different thing entirely, and no text file can promise that part.

## Close

**BCRY — carry-out**
A SKILL.md file can fix exactly what Claude says next. It can't fix
whether the person listening actually understands it.

**BHTF — your turn**
Your turn. Paste this into Claude: Write a short, five-part coaching

a for loop. Follow those exact steps to coach me through one I'll paste in.
Then ask me to explain the fix back in my own words, and tell me honestly
whether that proves I understood it, or just that I could repeat you.

**BOUT — outro**
The Script, Not The Understanding. Liam, in for Bear.
