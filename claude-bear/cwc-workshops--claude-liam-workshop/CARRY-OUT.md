# CARRY-OUT

> A SKILL.md file can fix exactly what Claude says next. It can't fix
> whether the person listening actually understands it.

Test: if someone repeats only this in a meeting next week, is it still
true? Yes — it compresses the reel's actual distinction (the file governs
Claude's coaching script, not the learner's grasp of it) without overstating
either half, and it generalizes past this one skill to any instruction file
Claude reads before acting.

**Wrong guess this defeats:** "Claude's `workshop` skill just builds the SEC
agents for me automatically" (the natural read of a skill named after a
hands-on workshop). The SKILL.md is explicit that this is a *coach*: "You
are the participant's coach for this workshop... move them through
WORKSHOP.md one act at a time." Even in its "do it and teach me" mode, where
Claude does make the change itself, the file still requires an explanation
afterward, every time — what changed, why it works, the platform concept it
demonstrates, where to see it, one thing to try. The skill can guarantee
that explanation happens. It cannot guarantee the explanation lands.
