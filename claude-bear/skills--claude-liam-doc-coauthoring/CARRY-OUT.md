# CARRY-OUT — skills--claude-liam-doc-coauthoring

**The line (BCRY, read aloud, WantQuote):**

> Writing sounds finished when it's actually just familiar to you. The
> doc-coauthoring skill won't call it done until a Claude with none of your
> context can read it cold and get it right.

**The wrong guess it defeats:** that asking Claude to write a doc is a
one-shot request — describe it well enough and the draft that comes back is
the finished thing. The line targets the specific failure mode: a draft can
read as *finished* to the person who already knows every unstated fact in
it, which is exactly the person least able to notice what's missing.

**Test:** if someone repeats only this sentence in a meeting next week, is
it still true? Yes — it compresses the distinction (familiar-to-you vs.
actually-clear) rather than the topic (three-stage doc workflow), and names
the mechanism (a fresh, context-free Claude as the reader) that makes the
distinction checkable rather than a platitude.
