# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **A Claude skill isn't code Claude writes on the fly — it's a file
> someone already wrote, that Claude reads and follows the same way,
> every single time.**

## The wrong guess it defeats

That a named skill like `cash-flow-snapshot` means Claude programmed
something custom to handle it — wrote logic on the fly for this one job.
It didn't. Open the folder and there is no hidden script: two things sit
there, a `SKILL.md` file (plain language, not code) and a `reference/`
folder. Claude reads the `SKILL.md` itself and treats it as the program —
there is nothing else to find, and nothing it improvises.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (a skill is a
pre-written file Claude follows, not code Claude authors at runtime) into
a sentence that doesn't overstate what a skill guarantees.

## What it deliberately does not say

- **Not what a cash flow snapshot specifically computes.** The source
  sheet's own template lost the line naming the skill's exact job (visible
  as a bare `>` at every occurrence — see QUESTION.md). No local copy of
  `cash-flow-snapshot`'s `SKILL.md` exists to recover it. This reel states
  only the mechanism the source's *other* beats already confirm — a
  folder, a `SKILL.md`, an ordered Steps section, determinism — and never
  invents the specific fields or formulas a snapshot would contain.
- **Not a verdict on whether this design is good.** That's Teardown
  territory; this reel states the mechanism and stops.
- **Not that every skill is this simple in practice.** Only that the
  mechanism — read the file, run the steps in order, same input same
  output — is what every Agent Skill guarantees, regardless of how
  elaborate its Steps section gets.

## Why no ONE-FLAG beat

Every claim in this reel is the source's own confirmed statement about how
Agent Skills work (a folder, not code; SKILL.md as the instruction set;
linear step execution; same-input-same-output; the limit is only what the
file says). None of it is this reel's inference. The one thing genuinely
unconfirmed — what a "cash flow snapshot" specifically contains — is never
asserted, so there is nothing to flag.
