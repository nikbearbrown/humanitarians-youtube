# Claude, Investigation Query.

Claude picked up a skill called investigation-query — does that mean it can
independently work out what actually happened, cross-referencing witness
accounts and judging who's telling the truth? No. A "skill" is a folder
holding one file, SKILL.md, that Claude reads before it starts and then
follows step by step, in order. Delete the folder and Claude loses no power
to judge witness credibility, because there was none to begin with — it
just stops running that one search routine. That makes a skill a
specification, not new judgment: the payoff is the same search, every
question, every time; the limit is anything the file never wrote down. And
watching Claude find an answer in the log, or come up empty, proves nothing
on its own about whether it actually understood what happened.
