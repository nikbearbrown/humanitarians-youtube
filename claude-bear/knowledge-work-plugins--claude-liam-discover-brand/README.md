# It Doesn't Know Your Brand. It Reads It. — The Discover-Brand Skill

A skill is a folder Claude reads before it works — this one is
discover-brand, and its SKILL.md file holds the full instruction set, in
plain language, no hidden logic. The instructions are laid out in a Steps
section: Claude reads each step in order and runs it, linear, no branching
unless a step says otherwise. Here's the actual job, as its name suggests:
it reads material you already have and pulls out the patterns — words you
favor, words you avoid, the tone that keeps showing up — then writes that
down as a spec. It doesn't already know your brand's voice. It reads what
you give it and writes that down, same material in, same spec out, every
time — and the limit is exactly what it was given to read.

and tell me three words I use again and again, one word I clearly avoid,
and one sentence that describes my tone. Don't claim anything you can't
point to in the text.
