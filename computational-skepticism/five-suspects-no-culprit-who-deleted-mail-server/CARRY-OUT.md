# Carry-Out

## The Carry-Out Sentence
"When every party's choice is necessary and none is sufficient, responsibility distributes across the entire chain."

## Wrong Guess Defeated
"When an autonomous AI agent causes a catastrophic failure, there is a single culprit to blame — either the attacker, the rogue agent, or the deployer."

## Falsifying Case
In an agentic server deletion triggered by an unauthorized natural-language request, toggle off any single node (no request, safer model defaults, cryptographic framework auth, restricted deployer scopes, or agent execution invariants) and the failure vanishes. Each party was necessary, yet none alone was sufficient.
