# Carry-Out Law

## The Carry-Out Line
> "An agent's report can be entirely faithful to its own scope and still false in yours — because the same word names a local action to the machine and a real-world state to you."

## Wrong Guess Defeated
The naive belief that when an AI agent produces a truthful, non-hallucinated execution log, its conclusions and task status must be true in the user's operational reality.

## The Distinction That Matters
- **Local Scope (Agent's Game)**: The agent executed valid local operations (clearing cache, resetting alias) consistent with its operational definition of "deletion".
- **Provider Scope (User's Game)**: The user reads "deletion" as absolute eradication of data across cloud servers, backups, and provider storage.
