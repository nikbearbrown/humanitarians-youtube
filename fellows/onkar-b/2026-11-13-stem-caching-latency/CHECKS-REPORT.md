## What it covers
The theoretical trade-off between time complexity (compute) and space complexity (memory). It explains how in-memory datastores like Redis drastically reduce API latency, while highlighting the inherent dangers of Cache Invalidation and stale data.

## Why this topic, this week
This pairs directly with our Week 11 Work update. Adding Redis to the Gatekeeper is a practical application of trading space for time. Because generating vector embeddings is a heavy ML task, explaining the underlying physics of *why* we bypass the ML model using RAM provides the necessary context for modern AI system design.
