## What it covers
The security vulnerabilities of connecting Large Language Models to backend databases, specifically exploring prompt injections, malformed data types, and server thread exhaustion.

## Why this topic, this week
Developers frequently fall for the "System Prompt Fallacy"—believing that telling an AI to "only output integers" is a sufficient security measure. This explainer proves why the LLM itself is an attack vector and why deterministic normalization (Regex, strict equality checks) is mathematically necessary to prevent system crashes.
