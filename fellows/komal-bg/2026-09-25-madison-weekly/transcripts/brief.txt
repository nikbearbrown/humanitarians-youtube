Jungian Brand Archetype Detector

Focused on the Ruler archetype (luxury) this week, aiming to prove the full
pipeline end-to-end on one archetype before scaling to all twelve.
Worked through the section-5 methodology and started shaping it into a
concrete technical design, covering:
- Inputs — what goes in (brand website copy, social captions, tagline,
  possibly competitors) and in what format
- Scoring — how a brand's real language is scored against the Ruler trait
  profile, with evidence cited behind each score so results are defensible
  rather than a black box
- Evaluation — how accuracy will be tested, by checking against a small set
  of hand-labeled brands first, to confirm the tool reads real brand voice
  rather than surface keywords

SurveyMind Study

Built and tested the full analysis code.
Loaded and cleaned the real human personality dataset (~603,000 usable
responses), then ran statistical tests checking whether two datasets show
matching personality trait patterns.
Validated the code on two synthetic datasets first — one built to look
realistic (passed correctly) and one built to be clearly wrong (failed
correctly).
This week's goal: get the real SurveyMind data to run the actual test,
instead of the self-generated dummy data used for code validation.
