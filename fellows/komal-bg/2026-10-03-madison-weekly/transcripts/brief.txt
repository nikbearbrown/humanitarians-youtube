Loon Conservatory (desktop app)

Backend refactoring: We refactored the backend from Python to Rust to
improve performance and reduce resource usage. The app’s memory footprint
dropped from approximately 80 MB to 40 MB.
Batch processing: We shipped support for processing up to 25 files at once,
including ZIP folders.
Automatic update injection: Updates are now automatically injected based
on the number of updates we push and download.
For next week, I’d like to focus on testing the application in a Windows
environment. Most of my testing so far has been on macOS, so we have good
confidence that it works well there, but we haven’t done as much
Windows-specific testing yet. I think validating the app on Windows should
be the next priority.

Laptop Recommendation Study (separate)

This week I moved from preparation into actual model testing. I ran the
same 13-prompt mini-pilot twice in separate Claude chats using Opus 5.5 at
medium effort with web search enabled, giving us 26 real responses. I
compared the two rounds for consistency. Apple appeared in all 26
responses, while Lenovo and Dell appeared at the same frequency in both
rounds. I also found that the recommendation reasoning changed by user
context—for example, developer prompts emphasized Docker and memory,
creative prompts emphasized displays and GPUs, and enterprise prompts
emphasized security and fleet management. I’ve added these results to the
research paper draft. The next step is to run the remaining 26 prompts
using wording variants 2 and 3, then complete the full 39-prompt analysis.
