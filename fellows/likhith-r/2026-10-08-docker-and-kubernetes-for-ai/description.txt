Why does a model work on your laptop but break in production? This explainer covers containerization for AI workloads with Docker and Kubernetes.

What's covered:
- Library versions, the OS and GPU drivers differ between machines, and one mismatch can break a model
- Docker packs the model, code and dependencies into one image that runs the same anywhere (with the host's GPU driver)
- One container can't absorb spikes or recover from crashes
- Kubernetes runs many containers across machines, adds copies with demand, replaces failed ones and spreads traffic
- For one small model, Kubernetes is often overkill

Sources: Docker documentation, NVIDIA Container Toolkit documentation, Kubernetes documentation. Versions, errors and counts shown are illustrative.
