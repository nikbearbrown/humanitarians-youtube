How does an AI coding agent fix a bug in a codebase it has never seen? This explainer walks through the loop.

What's covered:
- It maps the project first, listing folders and files
- It searches for what the bug mentions and opens only the matches
- It makes a small, exact edit and leaves the rest alone
- It runs the tests, reads the failure, adjusts and reruns until they pass
- The loop is only as good as the tests, and a person still reviews the change

Sources: Anthropic's Claude Code documentation, "Claude Code: Best practices for agentic coding" and "Building effective agents". The repo, search and test output shown come from a scripted replay with real pytest.
