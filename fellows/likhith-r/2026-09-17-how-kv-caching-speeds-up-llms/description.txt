Why does a chatbot pause before its first word, then stream the rest so fast? This explainer covers the KV cache inside every modern LLM.

What's covered:
- Each token makes a query, key and value; past keys and values never change
- The model stores them in the KV cache, so each new token brings only its own query
- Work per new token drops from quadratic to roughly linear (counts from a real script)
- The price: memory grows with every token, so long contexts need memory, not just compute

Sources: Vaswani et al. (2017), Pope et al. (2022), Touvron et al. (2023). The memory figure uses Llama 2 7B's published shape; the example sentence is illustrative.
