If you want an AI model in your app, do you have to run the GPUs yourself? This explainer covers why Amazon Bedrock exists.

What's covered:
- Running a model yourself means GPUs, scaling, patching and uptime
- Every model has its own API and hosting
- Bedrock is a managed service: one API to models from many providers, with no servers to provision
- Guardrails, fine-tuning and agents sit on the same platform
- Switching models is mostly a change of model ID

Sources: AWS documentation for Amazon Bedrock, the Converse API, Guardrails, model customization and Agents. Model IDs shown are examples; availability varies by region.
