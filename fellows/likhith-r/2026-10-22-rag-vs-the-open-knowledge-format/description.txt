RAG is the default way to give an AI agent outside knowledge. In June 2026 Google proposed something different: the Open Knowledge Format. This explainer compares the two.

What's covered:
- RAG chunks documents into vectors and searches them again on every question
- OKF is a folder of linked Markdown files with YAML metadata that an agent reads directly
- OKF needs no embeddings or vector store, and lives in git, so every change can be reviewed
- Its cost is curation: people or agents must write, check and update every page
- RAG still wins on huge, unstructured piles nobody could curate

Sources: Google Cloud blog, "How the Open Knowledge Format can improve data sharing" (June 2026), the OKF specification v0.2, and Lewis et al. (2020). Scores, file walks and git history shown come from a real OKF bundle.
