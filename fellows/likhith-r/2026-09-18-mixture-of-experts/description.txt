Models now hold hundreds of billions of parameters — so how are they still fast? This explainer covers Mixture of Experts.

What's covered:
- A dense model runs every parameter for every token
- Mixture of Experts splits each layer into many smaller expert blocks
- A small router picks a few experts per token, and only those run
- Mixtral holds 47B parameters but uses about 13B per token (DeepSeek-V3: ~37B of 671B)
- The catch: every expert still has to stay loaded in memory

Sources: Shazeer et al. (2017), Mistral AI's Mixtral paper (2024), DeepSeek-V3 technical report (2024). Router scores shown are illustrative.
