## What it covers

How the Model Context Protocol lets an AI application call external tools
through one standard interface, demonstrated with a minimal Python server.

## Why this topic, this week

The gateway built in [this week's project work](../08282026-mycroft-logbook/)
is the same idea one layer down: one door every model request passes through,
rather than each caller wiring up its own. Understanding MCP's single-interface
argument fed directly into the adapter design in Sprint 2.
