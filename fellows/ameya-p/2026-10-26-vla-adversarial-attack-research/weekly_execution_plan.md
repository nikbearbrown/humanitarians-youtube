# Weekly Execution Plan: Setup Through Hypothesis 1

This 6-week schedule covers the weekly execution plan for Shared Testbed Setup and the completion of Hypothesis 1 (Stealthy Steering Without Prior Object Coordinates).

The plan is divided between 2 engineers building and comparing two complementary "blind" patch-training methods—neither of which requires knowing where Object A or Object B are located in the simulator—and then combining them to answer a compelling research question:

> _"Can a single 3D patch placed next to any decoy object smoothly lure a robot arm by hijacking **where the language model pays attention** or by copying **what the target visual features look like**?"_

| Feature                            | **Engineer 1: "The Attention Magnet Patch"**<br>_(Cross-Attention Hijacking)_                                                                                             | **Engineer 2: "The Auto-Feature Copy Patch"**<br>_(Vision-Encoder Shortcut)_                                                                                           |
| :--------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Where It Operates in `OpenVLA`** | Inside `Llama-2-7B`’s text-to-image cross-attention layers.                                                                                                               | Inside the Vision Encoder + Projector (`SigLIP + DINOv2`).                                                                                                             |
| **How the Patch Is Trained**       | Trained across diverse scenes and prompts to pull $100\%$ of the prompt's attention score onto the patch’s own grid squares, regardless of what object the user asks for. | Automatically averages the top-3 highest-attention squares on a clean frame (`mean(tokens_A)`) and trains the patch’s squares to output that exact visual ID vector.   |
| **Key Advantage**                  | Universal & Prompt-Agnostic: One single magnet patch can lure the robot across different prompts and across both `LIBERO-Object` and `LIBERO-Spatial`.                    | Fast & Lightweight ("Eyes-Only" Shortcut): Trains in ~2 minutes using only ~3–4 GB GPU VRAM without loading the 7B `Llama-2` model, and avoids grid-position mismatch. |
