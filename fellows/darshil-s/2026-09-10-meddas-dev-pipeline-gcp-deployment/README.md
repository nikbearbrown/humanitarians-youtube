## About this video

The week's **project-update** video (one of the two distinct videos required
per week — see `learning/` in this same folder for the companion **STEM/AI
topic** video). Covers the frontend's full CI/CD pipeline end to end: the
multi-stage Docker build, the Cloud Run + Artifact Registry infrastructure,
Workload Identity Federation auth, automated PR gates and tag-triggered
deploys, the one-click rollback workflow, and the environment-agnostic design
that carries the same pipeline from dev through staging and production.

Narration is the fellow-supplied script verbatim (provided 2026-10-09); only
the diagram/shot design was authored here. Continues the series established
in `2026-08-25-medas-frontend-cicd/`, `2026-08-31-medas-ci-rollback/` and
`2026-08-31-medas-trust-chain/` (same voice, same GitHub-dark/Claude-cream
house skin).

## Rebuilding this video

```bash
git clone https://github.com/nikbearbrown/brutalist.art.git
cd brutalist.art
./setup --install
python3 runtime/scripts/generate_audio_kokoro.py ../BrutalistVideo/darshil-s/2026-10-09-meddas-dev-pipeline-gcp-deployment
python3 runtime/scripts/remotion_scenes.py       ../BrutalistVideo/darshil-s/2026-10-09-meddas-dev-pipeline-gcp-deployment
./art final ../BrutalistVideo/darshil-s/2026-10-09-meddas-dev-pipeline-gcp-deployment
```

Rendered locally at 3840x2160 (4K), free — Kokoro TTS + Remotion, no paid
services. Note: on this machine, `./art final`'s own QC-gate subprocess step
hit an unresolved environment-specific failure (not a content defect); the
shipped master was produced by running the identical encode command by hand
and verifying it against the same QC checker and a manual frame review — see
the project conversation log for detail if rebuilding hits the same issue.
