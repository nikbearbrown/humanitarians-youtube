## About this video

Week 6's **project-update** video (one of the two distinct videos required
per week — see `learning/` in this same folder for the companion **STEM/AI
topic** video). Covers full integration testing between the staging
frontend and backend: build-time environment-specific configuration that
unambiguously points the staging build at the staging backend, verifying
the CORS cross-origin boundary between the two separately-deployed Cloud Run
services, methodically tracing a browser-visible CORS error to its true
root cause rather than its surface symptom, and a full regression pass
across core user flows against the live staging backend.

**Provenance note:** the fellow-supplied script for this reel had several
garbled/cut-off fragments (mid-sentence corruption, likely a copy-paste
glitch — the same pattern seen two weeks prior in
`medas-stage-pipeline-validation`). Each was repaired to a complete sentence
preserving the evident intended meaning — every repair is logged verbatim,
before and after, in `FACTCHECK.md`.

Continues the series established in `2026-08-25-medas-frontend-cicd/`
through `2026-10-08-medas-stage-hardening-observability/`.

## Rebuilding this video

```bash
git clone https://github.com/nikbearbrown/brutalist.art.git
cd brutalist.art
./setup --install
python3 runtime/scripts/generate_audio_kokoro.py ../BrutalistVideo/darshil-s/2026-10-15-medas-fullstack-integration-validation
python3 runtime/scripts/remotion_scenes.py       ../BrutalistVideo/darshil-s/2026-10-15-medas-fullstack-integration-validation
./art final ../BrutalistVideo/darshil-s/2026-10-15-medas-fullstack-integration-validation
```

Rendered locally at 3840x2160 (4K), free — Kokoro TTS + Remotion, no paid
services. Note: on this machine, `./art final`'s own QC-gate subprocess step
hit the same unresolved environment-specific failure as every other reel in
this book (not a content defect); the shipped master was produced by running
the identical encode command by hand (faster x264 preset) and verifying it
against the same QC checker and a manual frame review.
