## About this video

Week 9's **STEM/AI topic / technical-learnings** video. Another
STEM/learning-only week: no separate project-update video was supplied
alongside this one, so it stands alone rather than nesting under an
implementation folder.

Covers what actually happens inside a Docker build: per-instruction layer
caching and why instruction order matters, why multi-stage builds discard
the heavy toolchain so only the final output ships, how CI-level dependency
caching (keyed off a lockfile hash) differs from and complements Docker's
own layer cache, how container vulnerability scanning checks image layers
against CVE databases, and why both caching and scanning have to be
designed-in steps rather than afterthoughts.

**Provenance note:** the fellow-supplied script for this reel had several
garbled/cut-off fragments (mid-sentence corruption, likely a copy-paste
glitch — the same pattern seen in several prior weeks' scripts). Each was
repaired to a complete sentence preserving the evident intended meaning —
every repair is logged verbatim, before and after, in `FACTCHECK.md`.

Continues the series established in `2026-08-25-medas-frontend-cicd/`
through `2026-10-29-terraform-cloudrun-billing-learning/`.
