## About this video

Week 5's **project-update** video (one of the two distinct videos required
per week — see `learning/` in this same folder for the companion **STEM/AI
topic** video). Covers hardening staging from merely functional into
observable and self-verifying: an automated post-deploy smoke test gate,
Cloud Run's immutable-revision model and what it enables, traffic
splitting/pinning across revisions, centralized structured logging via Cloud
Logging, and basic monitoring on latency, error rate, and traffic volume.

Narration is the fellow-supplied script verbatim (provided 2026-10-08, no
garbling this time). Continues the series established in
`2026-08-25-medas-frontend-cicd/` through
`2026-10-01-medas-stage-pipeline-validation/`.

## Rebuilding this video

```bash
git clone https://github.com/nikbearbrown/brutalist.art.git
cd brutalist.art
./setup --install
python3 runtime/scripts/generate_audio_kokoro.py ../BrutalistVideo/darshil-s/2026-10-08-medas-stage-hardening-observability
python3 runtime/scripts/remotion_scenes.py       ../BrutalistVideo/darshil-s/2026-10-08-medas-stage-hardening-observability
./art final ../BrutalistVideo/darshil-s/2026-10-08-medas-stage-hardening-observability
```

Rendered locally at 3840x2160 (4K), free — Kokoro TTS + Remotion, no paid
services. Note: on this machine, `./art final`'s own QC-gate subprocess step
hit the same unresolved environment-specific failure as every other reel in
this book (not a content defect); the shipped master was produced by running
the identical encode command by hand (faster x264 preset) and verifying it
against the same QC checker and a manual frame review.
