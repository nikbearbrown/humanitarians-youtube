## About this video

Week 10's **STEM/AI topic / technical-learnings** video. Another
STEM/learning-only week: no separate project-update video was supplied
alongside this one, so it stands alone rather than nesting under an
implementation folder.

Covers the theory behind canary and blue-green deployments: the shared
problem both solve (a standard deploy exposes 100% of users instantly), how
a canary gradually ramps traffic while monitoring, how blue-green validates
a fully isolated second environment before an atomic cutover, why Cloud
Run's immutable-revision-plus-traffic-percentage model makes both just two
usage patterns of one primitive rather than separate features, how to
choose between them, and why deployment strategy is risk management, not
just automation.

**Provenance note:** the fellow-supplied script for this reel had several
garbled/cut-off fragments (mid-sentence corruption, likely a copy-paste
glitch — the same pattern seen in several prior weeks' scripts). Each was
repaired to a complete sentence preserving the evident intended meaning —
every repair is logged verbatim, before and after, in `FACTCHECK.md`.

Continues the series established in `2026-08-25-medas-frontend-cicd/`
through `2026-11-05-docker-layers-caching-scanning-learning/`.
