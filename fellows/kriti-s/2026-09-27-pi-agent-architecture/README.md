# Week 1: Pi Agent Architecture

**Group:** RL Environment **Reporting week:** 2026-09-21 through 2026-09-26

## Executive Summary

This report covers the production of explainer video designed to demonstrate that Pi achieves effective coding agent behavior through four modular packages (`pi-ai`, `pi-agent-core`, `pi-coding-agent`, `pi-tui`) and a single execution while-loop, dispelling the need for opaque monolithic frameworks. The technical breakdown highlights minimalist default tools (`read`, `bash`, `edit`, `write`), prompt assembly from `AGENTS.md`, before/after extension hooks, and branching JSONL session management. Produced through human source verification and review alongside AI-driven Remotion scene compilation and Kokoro `am_onyx` narration. The film is credited to original production.
