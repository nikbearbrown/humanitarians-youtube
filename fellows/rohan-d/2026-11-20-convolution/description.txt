THE PROMPT FROM THIS EPISODE
Write a short Python script, no ML libraries, that slides the 3 by 3 kernel with columns of minus 1, 0 and 1 over a 6 by 6 image whose rows are 0, 0, 0, 9, 9, 9, and prints the 4 by 4 output. Predict the output before you run it. Then move the edge one column left and print the output again. Finally, pad the image with a border of zeros and print the output size.
