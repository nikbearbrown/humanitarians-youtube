The film shows why: swings across the valley cancel in the velocity while steady slopes along it add up.

THE PROMPT FROM THIS EPISODE
Write a short Python script, no ML libraries, that runs gradient descent with momentum on loss = 0.5 * (x squared + 25 y squared), starting at x = 4 and y = 1, with step size 0.07. Each step, set v = beta * v + gradient, then subtract step size times v. Try beta = 0, 0.5, 0.9 and 0.99, and print how many steps each needs to get the loss below 0.01. Before running it, predict which beta wins.
