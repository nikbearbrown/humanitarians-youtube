Eight noisy points around y = 2x. A straight line has train error 0.099 and test error 0.074. A degree-7 curve passes through every point (train 0.000) but its test error is 0.221. THE PROMPT FROM THIS EPISODE
Write a short Python script, numpy only, that draws 8 noisy points from y = 2x with noise standard deviation 0.25, fits polynomials of degree 1 to 7, and prints the training error and the test error on 200 fresh points for each degree. Before running it, predict which degree has the lowest test error and why. Then repeat with 40 training points.
