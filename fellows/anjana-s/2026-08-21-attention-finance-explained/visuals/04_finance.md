# Beat 4 — Why Finance Needs This

**Visual type:** Remotion
**Duration:** ~15 seconds

## What the viewer sees

Three rapid-fire financial examples. Each follows the same visual pattern: sentence appears → one key attention line draws → verdict comparison shows. Five seconds each.

**Example 1 (0-5s):**
Sentence: "We delivered strong results but expect moderation going forward."

The words appear as blocks. One thick attention line draws: "strong" ↔ "moderation" — connected through the pivot word "but," which glows amber.

Split verdict:
- Without attention: "POSITIVE" (green) — wrong ✗
- With attention: "CAUTIOUS" (amber) — correct ✓

**Example 2 (5-10s):**
Sentence: "Margins improved sequentially although headcount reductions contributed significantly."

One thick attention line: "improved" ↔ "reductions" — the improvement is qualified by cost-cutting.

Split verdict:
- Without attention: "POSITIVE" (green) — wrong ✗
- With attention: "MIXED" (amber) — correct ✓

**Example 3 (10-15s):**
Sentence: "Revenue grew twelve percent excluding the impact of foreign currency fluctuations."

One thick attention line: "grew" ↔ "excluding" — the growth has an asterisk.

Split verdict:
- Without attention: "STRONG POSITIVE" (green) — wrong ✗
- With attention: "QUALIFIED POSITIVE" (amber) — correct ✓

Each example appears, resolves, and transitions quickly. The pattern is clear by the third one: attention catches what sequential reading misses.

## Technical notes

- These three examples should feel rapid-fire — same visual template, new content each time
- Only show ONE attention line per example — the most important connection. Don't draw the full web
- The pivot words ("but," "although," "excluding") should glow amber in each example — they are the pattern
- The split verdict (without/with) should appear side by side for quick visual comparison
- Each transition should be a clean cut or quick fade — no slow transitions
- The rhythm should accelerate slightly — example 3 resolves fastest
