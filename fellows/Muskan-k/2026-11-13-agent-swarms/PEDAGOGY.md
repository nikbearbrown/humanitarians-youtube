# PEDAGOGY — Agent Swarms (claude-hai · AI, Explained · ~2.5min)

**Genre:** concept explainer (framework-first, built to pass PROOF).

**The ONE reusable idea (throughline/verdict):** an agent swarm is many agents
that **divide** a task, work in **parallel** with separate contexts, and
**converge** on one answer — and it only wins when the work genuinely
*decomposes*. The viewer should leave able to apply one test to any task:
**can you name the split and the merge?** If not, one good agent beats a swarm.

**Audience (HAI):** followers of the Fellows' STEM thread; anyone deciding
between a single agent and a multi-agent setup.

## Act structure
- B00 HOOK (composer) — one agent is limited; a swarm is many agents; when do
  more agents actually help? ✓
- B01 FRAMEWORK (versus) — one agent (serial · one context · one view) vs a
  swarm (parallel · separate contexts · specialized); coordinate = divide,
  share, converge ✓
- B02 THE GAINS (grid) — parallelism, specialization, diversity (combine/vote) ✓
- B03 WORKED EXAMPLE (example) — a report: orchestrator splits → research +
  write + fact-check in parallel → merge → critic reviews ✓
- B04 THE TRADE (grid, falsifiability) — ×N cost, conflict/duplication,
  convergence is hard, and only worth it if the task splits ✓
- B05 VERDICT (artifact) · B06 HANDOFF (name the split and the merge) ·
  B07 OUTRO ✓
- Body B01–B04 = 4K PIL cards; Claude UI only at B00/B05/B06/B07 (ILLUSTRATE LAW).

## Correctness (DOUBLE-CHECK LAW)
All claims are standard, non-dating multi-agent material; no product, framework,
or version names.
- A swarm = multiple agents coordinating toward one goal; the design choice is
  how they coordinate (here: orchestrator–worker; peer/shared-workspace noted in
  register, not over-claimed).
- Gains: **parallelism** (independent subtasks run at once),
  **specialization** (role-specific agents), **diversity** (independent attempts
  combined or voted — ensembling; beats a single try on average).
- Costs are real and the beat is falsifiable: token cost scales ~×N with agent
  count; agents can duplicate or contradict; **merging/convergence is its own
  hard problem**; and if a task does not decompose, a swarm is strictly worse
  than one capable agent. The honest claim is "wins *only when* the work splits."
- The worked example uses exactly five roles (orchestrator, researcher, writer,
  fact-checker, critic) — the card and narration agree.
