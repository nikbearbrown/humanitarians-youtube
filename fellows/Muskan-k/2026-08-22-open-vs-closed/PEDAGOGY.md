# PEDAGOGY — Open vs Closed AI. (claude-hai · teaching explainer, ~2min)

**The ONE insight:** open-weight vs closed-weight is really one question — *how
much of the model can you actually access and control?* It's a trade-off
(control vs convenience), and open-weight ≠ open-source.

**Audience (HAI):** learners new to the open/closed distinction.

- B01 closed-weight = the **black box** (hero visual) · B02 open-weight = the
  **downloadable model** (hero visual) ✓
- B03 the trade-off table (control vs convenience) ✓
- B04 the distinction: open-weight ≠ open-source ✓
- B05 verdict (the one question) · B06 title outro ✓
- Body B01–B04 = 4K cards; UI only at B00/B05/B06 (ILLUSTRATE LAW).

## Correctness (DOUBLE-CHECK LAW — accurate, non-dating)
- Closed: weights unreleased, API/app access, provider controls updates/infra/access.
- Open: weights released → download, self-host, fine-tune, integrate.
- open-weight ≠ open-source (weights ≠ training code/data).
- Labs named only as generic examples (OpenAI, Anthropic, Google); no version
  numbers or claims that will date. Framed as trade-off, not advocacy.
