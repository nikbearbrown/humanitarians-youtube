# PEDAGOGY — Agentic Dev Life Cycle. (claude-hai · teaching explainer, ~2.5min)

**The ONE insight:** when agents write the code, your leverage moves to the two ends
of the loop — **specify** (what "done" means) and **verify** (that you got it). The
ADLC is Specify → Plan → Build → Verify → Iterate; the agent owns Plan+Build, you own
Specify+Verify. The gates are the point.

**Audience (HAI):** learners/builders adopting AI coding agents who need a mental
model for how their role changes.

## Act structure (framework-first — built to pass PROOF)
- B00 hook (composer) — the loop changes, and so does your job ✓
- **B01 REFRAME (framework)** — classic SDLC (you author) vs ADLC (you specify + verify,
  agent builds) ✓
- **B02 THE LOOP** — Specify → Plan → Build → Verify → Iterate, with owners (loop kind) ✓
- **B03 worked example** — fixing a bug through the cycle (you at the two ends) ✓
- **B04 falsifiability / edge** — NOT fire-and-forget: skip spec = wrong answer; skip
  verify = slop at scale ✓
- B05 verdict · B06 handoff (write acceptance criteria first) · B07 outro ✓
- Body B01–B04 = 4K PIL cards; Claude UI only at B00/B05/B06/B07 (ILLUSTRATE LAW).

- The human-in-the-loop gates (specify, verify) are emphasized as required, matching
