# PEDAGOGY — Multimodal AI. (claude-hai · teaching explainer, ~3min)

**The ONE insight:** "multimodal" isn't a buzzword — it's a *test you can run.*
A model is multimodal when **one model takes in AND connects more than one kind
of input** (text · image · audio · video) in the same context. The tell that
catches fakes: **did the model actually see/hear the thing, or just read a
transcript a converter made of it?**

**Audience (HAI):** learners who keep hearing "multimodal" and want a definition
they can actually apply to a new tool — not four facts and a slogan.

## Act structure (framework-first — built to pass PROOF)
- B00 hook (composer) — frames it as a *test*, not trivia ✓
- **B01 FRAMEWORK shown BEFORE any example** — the reusable definition (one
  model · connects · text/image/audio/video) as a hero diagram ✓
- B02 the four kinds of ask (the inputs, enumerated) ✓
- **B03 worked example** — one case walked through: image + text → one connected
  answer about the picture ✓
- **B04 falsifiability / edge case** — bolt-on (image→converter→text→model, never
  saw it) vs true multimodal (model sees pixels). The friction beat ✓
- B05 why it matters — real work arrives mixed (kept tight; not fact-recitation) ✓
- B06 verdict (the one-page rubric) · B07 HANDOFF (a *scaffolded* task, not "ask
  Claude") · B08 title outro ✓
- Body B01–B05 = 4K PIL cards; Claude UI only at B00/B06/B07/B08 (ILLUSTRATE LAW).

## Correctness (DOUBLE-CHECK LAW — accurate, non-dating)
- No model names, version numbers, or benchmark counts that will date the video.
- "Multimodal" defined by capability (takes in + connects ≥2 input types in one
  context), not by any product.
- The bolt-on/OCR contrast is described as an architecture distinction, not a
  claim about any named product.
- Applications (healthcare/manufacturing/education/business/software) framed as
  categories of mixed input, no invented metrics.
