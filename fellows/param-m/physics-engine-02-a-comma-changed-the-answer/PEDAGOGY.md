## Learning outcome

After watching, a viewer with no math or coding background can:

1. **Explain** that a language model predicts text in chunks (tokens) rather than
   calculating digit by digit.
2. **Describe** the comma experiment: same addition problems, formatting changed,
   GPT-3.5 accuracy 75.6% → 97.8% with randomness off — so the errors are
   systematic, not random.
3. **Apply** the rule: when a number must be right, have the AI write the
   calculation as code and run it.

Measurable: shown a chatbot's numeric answer, the viewer asks "calculated or
predicted?" and knows the fix.

## Audience

Students and general viewers. Defined on first use: *language model* (B01),
*token* (B02), *place value* (B03), *randomness switched off* (B04), *SymPy* (B05),
*reference answer* (B06).
