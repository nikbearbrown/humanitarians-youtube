# Read-aloud: Short (9:16), draft 1

8 lines, 245 words, about 82 seconds at 3.0 words a second. Written fresh for the Short, one persistent scene. Numbers in words.

**S01 · THE PUZZLE** (18 words)

Can you check that a key is there without ever looking at the key? A pipeline has to.

**S02 · WHO** (32 words)

I'm Tanmay Kulkarni, for Humanitarians AI. This week I contributed to Mycroft, an open repository where work is written as recipes an agent can run. This recipe stress tests an invented portfolio.

**S03 · ONE ROW** (31 words)

One job in this recipe is to list what the pipeline would reach for. One is a model call, and it gets a row: a name, a status, and a reason.

**S03b · THE OTHERS** (17 words)

The other sources get rows too: one available, one skipped with a reason, one more approval required.

**S04 · IS IT THERE** (41 words)

Then one question to the program's settings: is a key with this name set? The answer is a yes or a no. Here, no. The value is never stored, so a yes or a no is all there is to leak.

**S05 · WHO SAYS YES** (24 words)

Then, who has to agree. No approval is recorded, so it stays false, and no call is made. Saying yes is a person's act.

**S06 · THE TEST** (52 words)

To test that promise, the test needs a key. A made-up key typed into a file can look like a real leak, so it makes a dummy one while it runs. Set it, and the page says yes, and looks for the value in every file. It is nowhere. Thirty-seven checks pass.

**S07 · ASK WHETHER** (30 words)

So ask whether it is there, and who says yes, and leave the value alone. The full film is "Ask Whether, Never What: Checking a Pipeline's Keys Without Reading Them".
