Two Customers, One Run (Short)

An AI pipeline finishes a run. Two readers need to know what happened: the next script, and the person who decides. They need different pages. In 90 seconds: the machine's page (a 16-field log), the person's page (a 15-section report), the same fact on both, the call the report adds, and what I found by reading my own log as a person would. The long film is "Two Customers, One Run: Writing a Pipeline's Results for a Program and a Person".

The contribution: nikbearbrown/mycroft pull requests #81 and #82 (merged), the Scenario Stress Testing Agent recipe, steps 4 and 6 in sample mode.
https://github.com/nikbearbrown/mycroft/pull/81
https://github.com/nikbearbrown/mycroft/pull/82

What this Short claims, and what it does not: every request is invented, nothing here is investment advice; the log has 16 fields and the report 15 sections; both say 12 requests read; the recommendation (approve for sample mode only YES, block live execution YES) is computed from the run's files; the stop-condition line in the report now reads "0 of 4 triggered".

Narration is a synthetic voice (Kokoro, run locally). Visuals are original code-drawn animations; open-licence fonts only.
