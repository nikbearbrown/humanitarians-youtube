## What This Video Covers

Using a real, built system prompt as the working example. This video breaks down what separates a well-designed AI assistant from a vague one: phase-gating, fallback behavior, and scoping what a tool deliberately does not do before building it.

**Takeaway:** a mental model viewers can apply the next time they try to design their own AI tool or prompt.
