# PROMPTS.md — National Loon Center – Educational Games

All beats render from props in beat_sheet.json. No generated images, no paid API, no open slots.

## BHTF — Your Turn prompt

```
Here is a game I exported for the web: [describe it]. Show me how to embed it in my site: the folder layout, the page code that opens it, and any headers it needs to run. Explain why each header is there.
```

Rubric:

- Does it explain why each header is needed?
- Does the game open without leaving the page?
- Could you add another game by changing one line?
