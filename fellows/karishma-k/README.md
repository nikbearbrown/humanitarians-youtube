# Karishma K.

Weekly video and research updates from **Karishma Suresh Kumar**, Humanitarians AI Fellow.

Create one folder per weekly update using lowercase kebab-case and a leading ISO date:

```text
2026-09-04-short-descriptive-title/
```

Submit updates through a branch and pull request to
`nikbearbrown/humanitarians-youtube`. A separate fork is not needed while the
GitHub account `SKKarishma20` has collaborator access.

## Voice choice

Choose one Kokoro voice before producing the first narrated report and retain it
across the series. Record the approved voice here and in each episode's
`beat_sheet.json`.
