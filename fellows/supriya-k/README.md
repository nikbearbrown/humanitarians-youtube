`fellows/README.md` requires each fellow to choose one Kokoro voice, keep it
across the series, record it in this README and in every episode's
`beat_sheet.json`, and get the fellow's approval before the first audio
generation. Recorded here on **2026-09-16**.

Consistent with the two most recent reels in this folder
(`banking-domain-sql-running-total-bug`, `banking-domain-star-method-behavioral`),
both of which already use `voice_kokoro: af_bella`.

`@HumanitariansAI`. Any future change of voice is an explicit, documented re-voice
decision, not a per-episode default.
