# SOURCES.md — how-do-you-know-it-worked

Primary source: `05_how_do_you_know_it_worked.md` (the authored script, kept
verbatim for reference) and `05_narration_tts_ready.txt` (the condensed,
TTS-normalized narration actually spoken, split by beat). Both live in this

Unlike `why-agents-fail` (STEM2), which describes general agent-engineering
practice, this script describes **this project's own code** — the three
mitigation mechanisms in `accountability_layer/claims.py`,
`accountability_layer/verification.py`, and
`accountability_layer/consistency.py` (one level up from `youtube/`). Per
`youtube/CLAUDE.md` §4 ("verify claims about any real external project
against the live source"), every mechanism claim below is checked directly
against that code, with file and line references, not against general
industry description.

## Simplifications (declared)

- **The worked example ("34% YoY… source: 10-K") is illustrative**, not a
  logged trace from a real run — declared above and in-scene (B02's visual
  intent notes it explicitly).
- **"HIGH agreement — 0.82" and "LOW agreement — 0.21" are the source
  script's own illustrative figures**, not measurements; carried forward
  rather than re-derived.
- **The verification-rollup caveat (B04) is stated plainly, not hedged
  away** — this reel would be self-refuting if it claimed "no source, no
  verdict" while quietly smoothing over a real precision gap in its own
  verification code.
- **Hedge word list and causal phrase list are each a fixed, finite set**
  in the real code (`claims.py:43-55`) — the narration says "a fixed list,"
  which is accurate; it does not claim the lists are exhaustive of natural
  language.
