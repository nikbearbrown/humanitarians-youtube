# PROMPTS — Where the Error Lives

The on-screen prompts, as typed into the composer.

## B00 — the cold-open ask
> I built IVF-PQ vector search from the paper. It returns fewer than half the true
> nearest neighbours, and scanning more cells barely helps. Help me find where the
> error actually lives.

## B09 — the viewer handoff prompt
> Pick ten things a summary you rely on told you and check them against the
> original. Then check ten more you would not have doubted. Where were the errors?
