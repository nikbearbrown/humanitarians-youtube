# Run this reel — exact commands for your terminal

This folder is a complete, self-contained reel. Drop it into your
`brutalist.art-main/reels/` (or any folder — the toolkit doesn't care where
a reel lives) and run these from the **toolkit root**, not from inside this
folder.

```bash
# 0. Place this whole folder somewhere under your brutalist.art-main checkout, e.g.:
mv humanitarians-ai-week1-diagnostic-audit reels/
cd brutalist.art-main

# 1. Generate narration audio — Kokoro, Onyx voice, this IS the master clock.
python3 runtime/scripts/generate_audio_kokoro.py reels/humanitarians-ai-week1-diagnostic-audit

# 2. Draft compile — renders all 14 Manim scenes at native 4K (3840x2160, 24fps)
#    and assembles a review cut. Watch this before doing anything else.
./art run reels/humanitarians-ai-week1-diagnostic-audit

# 3. Anything still outstanding?
./art todo reels/humanitarians-ai-week1-diagnostic-audit

# 4. Clean 4K master, 16:9 — this is the "4K at source" deliverable.
./art final reels/humanitarians-ai-week1-diagnostic-audit
# → reels/humanitarians-ai-week1-diagnostic-audit/humanitarians-ai-week1-diagnostic-audit-cut.mp4

# 5. 9:16 short, derived from the same beat sheet — the second required deliverable.
./art shorts reels/humanitarians-ai-week1-diagnostic-audit
```

## Before you run step 2 — one thing to check

`scenes.py` uses the **Oswald** font for all overlay/kicker text. This
toolkit's own `./setup --install` fetches Oswald automatically. If you
haven't run that on this machine, either run it now, or swap `FONT =
"Oswald"` near the top of `scenes.py` to a font you know is installed
(Helvetica / Arial / Archivo Black all match the brief's suggested type).

## After step 2 — what to actually check in the review cut

1. **B06's footer crop** (the Projects-column zoom) — this is the one crop
   I estimated by column position rather than pixel-measuring, since there
   was no color to threshold on. If it's off by a column, open `scenes.py`,
   find `B06_FooterZoom`, and adjust the `box = (0.62, 0.0, 0.92, 0.55)`
   tuple, then rerun `./art run` — only that beat recompiles.
2. **B08's type-scale ladder** — confirm the four rungs ("DISPLAY,"
   "HEADLINE," "SUBHEAD," "BODY") don't clip against the frame edge at
   your actual rendered resolution.
3. **B03 and B09's red annotations** — these were pixel-measured from your
   screenshots (see BUILD-LOG.md for the exact method), but double check
   the box/circle actually lands on the right element once you see it
   moving on screen, not just as a still frame.
4. Whether the runtime feels right once real narration timing replaces my
   word-count estimates — total is currently projected at 3:43, inside
   your 3–4 minute target.
