# Time Series — When Order Is the Signal

**Series:** STEM Explainer
**Status:** Complete

## Topic
Time series fundamentals — what makes temporal data different from tabular data, the components hiding inside a time series (trend, seasonality, noise), stationarity and why it matters, classical vs ML forecasting approaches, and the evaluation trap of leaking the future.
