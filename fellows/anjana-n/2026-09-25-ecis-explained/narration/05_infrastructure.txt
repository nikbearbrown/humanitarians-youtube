The data layer outgrew its original infrastructure. The system migrated from SQLite to PostgreSQL with connection pooling and composite indexes on the most frequent query patterns. Time-series market data moved into a TimescaleDB hypertable with automatic partitioning. The outcome resolver now reads from a local database instead of making live API calls for previously resolved dates. Materialized views pre-compute the heaviest dashboard aggregations, so the dashboard loads from cached results instead of recomputing on every page refresh.
