## About
Mixture of Experts (MoE) architecture — how routing tokens to specialist sub-networks lets a model hold far more knowledge than it uses on any single input. 

In a standard model, every parameter runs for every word. Mixture of Experts (MoE) changes this. It splits the feed-forward network into several experts, and a router picks only a few of them for each word. The model gets much more capacity without more processing per word.
