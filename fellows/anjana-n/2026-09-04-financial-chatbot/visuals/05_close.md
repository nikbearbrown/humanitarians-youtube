# Beat 5 — The Close

**Visual type:** Remotion
**Duration:** ~7 seconds
**Followed by:** Claude-branded outro bookend

## What the viewer sees

A horizontal pipeline diagram shows all four steps in a clean left-to-right flow:

1. **"Embed"** — question icon transforms into a vector dot
2. **"Retrieve"** — vector dot searches database, chunks slide out
3. **"Read"** — chunks flow into LLM node
4. **"Generate"** — answer with citation badges exits

Each step lights up as the narration names it, left to right in sequence.

On "Every answer is grounded in a real document" the citation badges in the answer glow, and faint lines trace all the way back through the pipeline to the chunks in the database. The full chain is visible.

Title text lands:

**What Happens Inside a Financial Chatbot**
*Retrieval Augmented Generation*

Hold. Fade to Claude-branded outro bookend.

## Technical notes

- The four-step pipeline should be clean and horizontal, like a process diagram
- Each step is a compact icon with a label, not a full recreation of the earlier beats
- The citation trace-back lines are the final visual insight: every answer connects to a real source
- Title text: main line bold, subtitle lighter
- No company names in the title card
