# B01 — Recap

## Composition type
Remotion

## Layout
Dark stage. Fast-paced animated pipeline recap, then pullback to multi-company view.

## Elements

### Pipeline recap (first 15s)
- Transcript document icon enters from left.
- Four reader nodes light up in parallel: keyword (white), FinBERT (blue), NER (green), LLM (purple). Same shapes and colors as Ep1-Ep6.
- Arrows converge at the triangulator (central hexagon).
- Signal badge appears: "raised, 0.82."
- Prediction layer node glows gold (Ep6 addition).
- Arrow to 30-day market check (calendar icon with checkmark).

### Pullback (last 5s)
- Camera pulls back to reveal 4-5 parallel pipelines (one per company: Company A, B, C, D, E).
- Each pipeline is a miniaturized version of the one above.
- Dotted lines begin connecting across pipelines, hinting at correlation.

## Animation sequence

3. Arrows converge to triangulator (1s).

5. Gold prediction node glows (1s).
6. 30-day check icon (1s).
7. Hold single pipeline (1s).
8. Pullback reveals parallel pipelines (3s).
9. Dotted cross-lines fade in (1s).
