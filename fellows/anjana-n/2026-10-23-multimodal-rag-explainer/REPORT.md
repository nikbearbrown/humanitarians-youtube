# Video Report: Multimodal RAG Explainer — Retrieving Images, Tables, and Code

**Type:** STEM/AI Video


**Week:** Week 17 (Phase 17) · October 18 – October 24, 2026

## Summary
This educational video explains how AI search systems can retrieve information from documents that contain tables, charts, and code, not just plain text.

**Credits:**
- **Concept, script, and direction:** original work.
- **Assembly:** Claude, using the video generation tool created by Humanitarians AI.

## Video Outline
1. **Introduction:** opens with the central question.
2. **Why text-only systems fail:** shows how tables lose their structure, charts disappear, and code loses its formatting.
3. **Splitting documents by content type:** the system first identifies what each part of a document is.
4. **Converting content into searchable descriptions:** each content type gets its own method.
   - **Tables:** summarized by their columns and values.
   - **Charts:** described in words.
   - **Code:** summarized by what it does.
5. **Searching across content types:** a worked example where one question returns a table, a chart, and a piece of code.
6. **The full process:** an end-to-end summary.
7. **Closing:** key takeaways and a prompt for viewers.

## Key Points Presented
- **Standard text-only systems quietly lose information.** They lose most of what tables, charts, and code contain.
- **Identifying content type first makes the difference.** Each type can then be handled correctly.
- **The original content is kept.** It sits alongside its searchable description, so the right table or chart can be returned as it is.
- **One search index can serve all content types.**
