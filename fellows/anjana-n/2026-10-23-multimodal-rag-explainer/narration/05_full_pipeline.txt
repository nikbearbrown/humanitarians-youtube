The full multi-modal RAG pipeline: a document enters. Layout detection identifies content regions. Each region is chunked by type. Non-text chunks go through structured extraction. All chunks are embedded — text, table summaries, image descriptions, code summaries — into a unified index. At query time, retrieval pulls the most relevant chunks regardless of their original format. The language model receives structured context: tables as tables, code as code, charts as descriptions with source images. The answer is grounded in the full document, not just the parts that happened to be plain text.
