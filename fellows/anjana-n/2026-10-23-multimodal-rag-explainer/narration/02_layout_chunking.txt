Layout-aware chunking solves the first problem: it sees the page as a human does. Instead of splitting on token count alone, it detects content boundaries — where a paragraph ends and a table begins, where a code block starts, where a figure sits. Each content type becomes its own chunk with a type label attached. A table chunk preserves rows, columns, and headers. A code chunk keeps indentation and language tags. The chunker doesn't just split text — it classifies what it's splitting.
