Now each chunk has a text representation that can be embedded — but not all embeddings are equal. Text chunks use a standard text embedding model. Table summaries may use the same model or a specialized one trained on structured data. Image descriptions embed alongside their source metadata. Code summaries can use a code-aware embedding model that understands programming semantics. At retrieval time, the query matches against all modalities. A question about revenue trends might retrieve a text paragraph, a revenue table, and a bar chart — all from different pages, all relevant, all preserving their original format for the language model.
