Non-text content needs a translation step before it can be embedded. Tables go through structured extraction — the raw grid becomes a schema-aware representation with column types, row relationships, and summary statistics. Charts and diagrams are processed by a vision-language model that generates a text description capturing the visual's key information: axes, trends, labels, relationships. Code blocks are parsed into an abstract syntax tree, then summarized as a natural language description of what the function does, its inputs, and its outputs. Each extraction creates a retrievable text representation without losing the original.
