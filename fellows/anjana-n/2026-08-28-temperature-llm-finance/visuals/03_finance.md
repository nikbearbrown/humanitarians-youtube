# Beat 3 — What This Means for Finance

**Visual type:** Remotion
**Duration:** ~15 seconds

## What the viewer sees

The earnings quote returns at the top: "We anticipate moderate revenue growth in the back half of the year."

Below it, three columns appear side by side, each headed by a temperature setting and the dial icon at that position.

**Column 1 — T = 0.0 (0-5s):**
Header: "T = 0.0" with dial pointing to zero.

Three extraction rows appear one at a time:
- Run 1: "maintained — 0.71" (blue)
- Run 2: "maintained — 0.71" (blue)
- Run 3: "maintained — 0.71" (blue)

All identical. All the same color. A lock icon appears at the bottom of the column. Label: "Stable."

The column glows with a calm green border — this is the good one.

**Column 2 — T = 0.5 (5-10s):**
Header: "T = 0.5" with dial at mid-point.

Three rows:
- Run 1: "maintained — 0.68" (blue)
- Run 2: "maintained — 0.72" (blue)
- Run 3: "raised — 0.54" (green)

Two match, one differs. An amber border. A "2/3 agree" tag appears. Label: "Mostly stable."

**Column 3 — T = 1.0 (10-13s):**
Header: "T = 1.0" with dial maxed.

Three rows:
- Run 1: "raised — 0.61" (green)
- Run 2: "maintained — 0.44" (blue)
- Run 3: "lowered — 0.38" (red)

All different directions. All different colors. A warning triangle icon. Red border. Label: "Unstable."

**Self-consistency callout (13-15s):**
A bracket draws around all three runs in Column 2. An arrow points from the bracket to a verdict box: "Vote → maintained (2/3)." A label: "Self-consistency: run multiple times, take the majority."

## Technical notes

- The three columns should be visible simultaneously — the comparison is the point
- Column 1's identical rows should feel reassuringly boring — same, same, same
- Column 3's chaos should feel alarming — three different directions, three different colors
- The self-consistency callout at the end connects this concept to practical usage
- Color code the directions consistently: raised = green, maintained = blue, lowered = red
- The bracket + vote arrow should be the last visual beat before the transition
