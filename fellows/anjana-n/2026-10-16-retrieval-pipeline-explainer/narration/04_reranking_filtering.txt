The initial search returns candidates ranked by vector similarity — a bi-encoder score. A cross-encoder reranker reads each candidate alongside the original query and produces a more accurate relevance score. This is expensive — the cross-encoder processes each pair independently — so it runs on the top twenty or fifty candidates, not the full index. After reranking, metadata filters remove candidates that don't match hard constraints: date ranges, document types, access permissions. The result is a short, high-quality list.
