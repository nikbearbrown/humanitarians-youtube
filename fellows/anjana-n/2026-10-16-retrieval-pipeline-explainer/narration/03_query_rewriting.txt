The user's question is rarely the best search query. A query rewriter transforms it before or after the first retrieval. Techniques include HyDE — generating a hypothetical answer and embedding that instead — step-back prompting, which generalizes the question to retrieve broader context, and query decomposition, which splits a complex question into sub-queries. Rewriting adds latency — fifty to two hundred milliseconds if it calls a language model — so production systems apply it selectively, only when initial retrieval scores fall below a confidence threshold.
