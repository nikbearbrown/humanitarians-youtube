One Week of Fellows: What Humanitarians AI Shipped, Oct 25–31, 2026

A weekly progress update from a Humanitarians AI fellow. Between October 25 and 31, 2026, the fellows
merged 30 pull requests into their shared YouTube repository (29 merge commits plus one squash merge);
Thursday, October 29 was the busiest day, with 12. The git log shows 37 author names, which is 27 people
once the obvious duplicates are merged (same email or same GitHub account); 23 of them wrote the work.
They added 84 new work folders from 22 fellows (by a rough sort: 42 STEM explainer videos, 30 progress
videos, 7 renewal requests, 3 hours logs, 2 written/code pieces) and 72 frictional logs. My own two videos
from last week (Brutalist, Shared and Deep Hedging, each with a Short, all 4K) are submitted to Drive; my
GitHub pull request is still pending. Every number comes from a small script run on the git history.

The one idea: small weekly evidence adds up. A good weekly folder holds a README with the result, a fact
check, a frictional log, and the source that rebuilds the video.
