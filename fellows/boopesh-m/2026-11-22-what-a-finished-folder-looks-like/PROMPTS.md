# PROMPTS — What a Finished Folder Looks Like

No slot in this reel is open: every beat is rendered by the pipeline (Manim or Remotion), so
there are no pantry or generation prompts to fill. This file records the prompts that were
actually used or shown.

## B00 — the ask shown in the Claude composer (on screen)

```
claude "check every new fellows folder from Nov 15-21 for the nine pieces of paperwork"
```
Its answer lines on screen are the results of `code/week_stats.py`, not model output.

## B80 — Your turn (on screen and read aloud)

```
List every file in this folder. Check it against these nine: README.md, FACTCHECK.md,
FRICTIONAL.md, PROOF.md, SHOTLIST.md, PROMPTS.md, beat_sheet.json, code/, description.txt.
Tell me which are missing, then draft the shortest missing one.
```
What it produces: a list of the pieces your own folder has and lacks, and a first draft of
one missing file. It is a starting point to edit, not a finished document.
