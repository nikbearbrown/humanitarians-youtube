What a Finished Folder Looks Like

Every week, Humanitarians AI fellows add a dated work folder for each piece of work. From Nov 15 to 21, 2026, 18 pull requests merged into main and 54 new work folders landed from 19 fellows. I checked every one for nine pieces of paperwork: README, FACTCHECK, FRICTIONAL log, PROOF, SHOTLIST, PROMPTS, beat sheet, code and description. The beat sheet was in 51 of 54; the proof self-review in just 4. No folder had all nine; eight folders had eight, and every one of them was missing only the proof. The takeaway is a nine-name checklist to run before you open a pull request, and a prompt to paste into Claude that checks your own folder.

All numbers come from code I ran on the repository's git history (code/week_stats.py → code/results.json). The narration is an AI voice (Kokoro am_onyx) reading my script.
