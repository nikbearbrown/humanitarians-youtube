# FACTCHECK — Every Tool, Every Week.

## The governing constraint

This reel reports **a real person's real week**. Every claim traces to the human's own
account, given 2026-08-21. Nothing else is asserted. That is a stricter bar than the
previous reel's "no invented statistics", because here an invented *fact* — a tool count, a
date, a description of a tool — would be a false statement about someone's actual work,
published under their own name and handle.

Three enforcement layers, same as before:

1. **Structural.** The scenes cannot express what wasn't stated. `YtwWeeks` renders ONE
   named week plus an open-ended run of unnamed ones, so it cannot imply a schedule length
   or a tool count. `YtwStatus` renders a fixed done/not-done pair, so it cannot imply a
   publish date. `YtwLoop` takes labelled steps only — no throughput, no timing.
2. **Editorial.** The verdict card repeats the unfinished item rather than rounding it up
   to a win: "the first article is written — and it is not posted yet."
3. **Accent semantics.** Terracotta marks only the broken or open thing (the down step, the
   unposted draft), so the one visual emphasis per beat lands on the honest part.

### The one inference, flagged

**Claim 6.** The human said she "audited all the tools, made sure they are working fine
without errors". She did not enumerate the checks. The reel expands that into three
questions — does it load, does it run without erroring, does it return something usable.

This is an *elaboration of method*, not an invented result: it claims nothing about what was
found, how many tools there were, or what was fixed. It is included because a beat that
just said "I audited the tools" would be a card of words, which `nopunt` classifies as a
PUNT. If the actual audit used different criteria, this beat should be reworded — it is the
one place the reel goes beyond the literal account.

## What the reel deliberately does NOT say

- **How many tools exist or were audited.** Not supplied. No grid, no count, no "all N".
- **What the Ogilvy tool does.** Not supplied. The beat names it and reports the article's
  status; it does not characterise the tool. If a description is provided, B06 can carry it.
- **Any date, deadline, or "this week" timestamp on screen.** The narration says "the week";
  no calendar dates are rendered.
- **Any engagement, traffic or performance figure** for LinkedIn or Substack.
- **That anything is published.** The article is written and unposted, said twice.

## Dating risk

The composer chrome renders a model chip ("Fable 5") on B00/B03/B08 — shipped component
chrome, never referenced by narration, same caveat as the other reels in this series. The
body carries no version numbers or dates.

## Register check

Could this have been read off a status update? No. The Teardown move is that the reel
refuses to present maintenance as a triumph: the cold open admits the page was broken, the
verdict repeats that the article is still unposted, and the closing judgment is that the
unglamorous week is what makes the writing worth reading. A progress report that only
listed wins would have failed this law.
