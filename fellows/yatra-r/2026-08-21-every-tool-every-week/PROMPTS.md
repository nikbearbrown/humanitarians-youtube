# PROMPTS — Every Tool, Every Week.

Every prompt shown on screen, verbatim. GATE F paperwork set.

## B00 — cold open (on screen)

**Greeting:** `Sawubona, Yatra` · **runningText:** `ordering the week…`

> I market the Humanitarians AI tools: I make graphics, post them on LinkedIn, and write a
> Substack piece on how I actually used each tool myself. Problem — the tools page has been
> broken for a long time. Where do I start: the writing, or the thing underneath it?

**Result lines (the ask lands answered):**

1. `start underneath — a broken page makes every post a promise you can't keep`
2. `audit every tool first, then schedule the writing`
3. `one tool a week beats one big launch`

## B03 — the ask micro-beat (on screen) · RESULT is B04

**Spark line:** `The audit.` · **runningText:** `auditing…`

> Go through every tool on this page one at a time. For each: does it load, does it run
> without throwing an error, and does it return something a real user could actually use?
> Don't grade generously — I have to write about these publicly.

The last clause is the beat's point: the audit standard is set by the fact that the writing
is public. See `FACTCHECK.md` claim 6 — the three questions are an elaboration of method,
the one place the reel goes beyond the literal account.

## B08 — the handoff (on screen, READ ALOUD VERBATIM)

**Greeting:** `Your turn.` · **runningText:** `paste this into Claude…`

> Audit the thing I maintain the way I'd audit it before writing about it publicly: what's
> actually broken, what's merely embarrassing, and what I'd have to admit if I published
> today. Rank it by what a brand-new user hits first.

**Rubric shown beneath (HANDOFF LAW — scaffolded):**

1. `grade it: does it separate broken from embarrassing?`
2. `grade it: does it rank by what a new user hits FIRST?`
3. `grade it: does it name the thing you were avoiding?`

This generalises the reel's own week into a task any maintainer can run, and the third
rubric item is the uncomfortable one that makes it worth doing.
