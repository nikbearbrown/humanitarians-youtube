## Nothing is claimed as a result

There is no accuracy figure, no benchmark, no user count, no "it found X" claim,
and no screenshot of a working system anywhere in this reel. The two places that
could be misread as output are both explicitly captioned:

- **B07** — `slideMeta`: *"illustrative example — not a produced result"*
- **B08** — file tab: *"planned output schema — a design target, not produced"*,
  plus a closing comment in the code block itself: `// NOT OUTPUT. This is the
  shape I am building toward.`

And **B10 exists solely to say so out loud**, including two deliberately negative
chips — "build not started" and "no results yet" — so the status board cannot be
read as a progress brag.

## Deliberately excluded (would date the video or overclaim)

No model names or versions. No named competitor products. No timeline or ship
date. No accuracy or reliability claim. No assertion that archetype analysis
"works" — the reel argues what a *useful* output would be, and says plainly that
producing one is not done.
