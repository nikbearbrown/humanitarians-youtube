# PROMPTS — What It Promised, And What It Shipped

**There are no open generation slots in this reel.** Every beat is either a
registered Remotion composition rendered from props in `beat_sheet.json`, or a
still composed locally by `make_plates.py` from the author's own screen
captures. Nothing is pending an image model, a stock purchase, a Higgsfield clip
or any other external generation. No paid API is called anywhere in this build.

This file exists because GATE F requires it, and because three beats carry
prompts that matter — just not generation prompts.

---

## B00 — the on-screen typed ask

The `command` prop of `ClaudeComposerAsk`. **Typed on screen and not spoken;**
the spoken words are `narration_text`, which differs.

> Last week there was a prediction sheet and a promise — precision and recall
> from the model itself, before the meeting. This week there is an application.
> Open the bundle, read the model card it ships with, and tell me whether the
> promise was kept or only moved.

---

## B07 — the handoff prompt the viewer can paste

The `command` prop of the second `ClaudeComposerAsk`. Both typed on screen
**and** discussed in narration, as the handoff beat requires. Written to be
useful to someone who has a model working in a notebook and has not yet had to
put it in someone else's hands.

> Take a model that currently only runs in my notebook. Package it so a
> colleague opens it like any other application — no terminal, no account, no
> server. Then make the build write a model card into the bundle: architecture,
> training run, precision, recall, thresholds, licence. Tell me which of those
> fields I cannot honestly fill in yet.

The last sentence is the point of the beat: the prompt is designed to surface
the fields you *cannot* fill, which is where the next week's work usually is.

---

## B04 — the math expressions (not a prompt, a source)

Not generated by a model. Three expressions are set locally by
`runtime/scripts/typeset_math.py` (matplotlib mathtext → outlined SVG,
`svg.fonttype=path`, STIX) and embedded as base64 by `build_beats.py`:

```
P = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FP}} = 0.930
R = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FN}} = 0.800
F_1 = \frac{2PR}{P + R} = 0.860
```

Change one of these in `build_beats.py`, re-run it, then
`remotion_scenes.py --force --only B04` for **both** aspects. There is no
text-card fallback: if the typesetter raises, B04 is BLOCKED, not downgraded.

---

## What was deliberately NOT prompted for

- **No photograph of a loon was generated or purchased.** The only bird on
  screen is inside the author's own capture of the app's result screen.
- **No screenshot was generated.** Under `EXECUTABLE-EVIDENCE.md` the app was
  *run* — mounted, started, queried — and its recorded output is typeset on B03
  and quoted on B06 rather than photographed.
- **No terminal mock-up.** B03's figures come from the shipped model card; the
  timing and provider claims come from the backend's own startup log.
