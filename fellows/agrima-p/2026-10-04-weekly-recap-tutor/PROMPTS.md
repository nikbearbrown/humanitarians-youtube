# PROMPTS — weekly-recap-tutor

No pantry/archival assets used. Every non-composer beat is a from-scratch
Manim scene; every composer beat's on-screen content IS the prompt.

## B00 — the cold open ask

```
claude "help me build an honest log of what I did this week"
```

## B02 — the first ask

```
claude "write weekly_recap_v1.py -- log this week:
  the article, the videos, the lecture"
```

## B05 — the revision ask

```
claude "update weekly_recap_v1.py -> weekly_recap_v2.py:
  -> split into DONE THIS WEEK vs NEXT"
```

## B09 — the handoff (HANDOFF LAW — read aloud and discussed)

```
claude "write me a weekly_recap.py that logs my actual
  week, split into what's done and what's next"
```
