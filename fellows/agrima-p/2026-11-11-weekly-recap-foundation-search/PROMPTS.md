# PROMPTS — weekly-recap-foundation-search

No pantry/archival assets used. Every non-composer beat is a from-scratch Manim
scene; every composer beat's on-screen content IS the prompt.

## B00 — the cold open ask

```
claude "help me write a short, honest log of what I did this week"
```

## B02 — the first ask

```
claude "write weekly_recap_v1.py -- log this week
  in four parts: writing, video, Homes of Hope, files"
```

## B08 — the change

```
claude "update weekly_recap_v1.py -> weekly_recap_v2.py:
  -> add a status to each part, print a count"
```

## B12 — the handoff (HANDOFF LAW — read aloud and discussed)

```
claude "write me a weekly_recap.py that logs my actual
  week, with a status on each item and a count of what's done"
```
