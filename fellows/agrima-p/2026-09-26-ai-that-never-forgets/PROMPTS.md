# PROMPTS — ai-that-never-forgets

No pantry/archival assets used — every non-composer beat is a from-scratch
Manim scene in scenes.py; every composer beat's on-screen content IS the
prompt (see beat_sheet.json `shot.remotion.props.command`).

## B00 — the cold open ask

```
claude "help me understand how AI memory is changing
  what marketing personalization actually means"
```

## B07 — the handoff (HANDOFF LAW — read aloud and discussed)

```
claude "help me check what an AI assistant has memorized
  about me, and how to view, edit, or clear it"
```

## Generated visuals (per the user's explicit request — no dedicated footage)

- **Old-system card** (B01): a person icon, a cookie tag, and three site
  cards (Instagram / YouTube / News Site) each showing the same shoe icon —
  the "old way" half of the requested comparison graphic.
- **Old-vs-new split card** (B02): left card "guesses from what you clicked"
  (cursor icon), right card "remembers what you actually said" (chat-bubble
  icon) — the "new way" half of the requested comparison graphic, plus
  Gemini/ChatGPT chips and the market-size stat.
- **Assistant-profile card** (B03): three conversation-fragment chips
  assembling into one profile card, plus the productivity stat.
- **Personalization-vs-identity-model card** (B04): two comparison cards plus
  three open-question chips (who sees it / corrected / deleted).
- **Memory settings panel** (B05): the requested memory/settings visual —
  a card titled "Memory" with View / Edit / Clear controls, all visible at
  once (not buried in a menu).

If the user later wants more literal proof for any of these, a screen
recording of an actual AI assistant's memory settings (e.g. ChatGPT's "Manage
Memories" panel, or Gemini's "Personal context" settings under Settings →
Apps → Gemini) would slot directly into B05's card in place of the generated
panel. To capture it: open the assistant's memory/settings screen, record a
short clip (10-15s) scrolling through the view/edit/delete controls, no
personal data visible on screen. Nothing else in the reel needs footage.
