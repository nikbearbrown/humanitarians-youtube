# Serving the panel over MCP and freezing the signal contract

**Runtime target:** 3:00 · **Spoken words:** ~480 · **Figures:** 4

Every number spoken below is read from `docs/_figdata_week1011.json`, which is generated by
querying the live database and the live signal at build time. No figure carries a hand-typed
value.

---

## [0:00] Opening — camera

Hi I'm Om Mali. This video is about making the dataset usable by something other than me: a
server an AI assistant can query directly, and a frozen contract another system can parse
without guessing.

Up to now everything here has been a script I run and a document I read. Fine for building it,
useless to anyone else. So: two new pieces. One lets an assistant query the data directly. The
other publishes the quarter's numbers in a shape promised not to change.

## [0:35] The hard part isn't the protocol — `w10-bounding.png`

Writing a server that speaks the protocol took an afternoon. The real constraint is size.

Ask for Databricks' full price history and you get two thousand one hundred and fifty one rows
— about a hundred and forty three thousand tokens. Larger than most context windows, and
useless even where it fits, because a model handed two thousand rows will not read them.

So every answer has three parts: a summary describing the whole result set, one bounded page,
and a cursor. Same query, eighteen thousand characters instead of five hundred and seventy five
thousand.

Two bounds, not one — a row limit and a character ceiling, because row widths aren't uniform.

## [1:15] Six tools, none of which writes — `w10-tools.png`

Six tools: list the companies, get one company's marks, compare managers on a date, get
propagation, get a fund's exposure, and list what's still unresolved.

Nothing writes. No tool records a decision, clears a gate, or changes a mark. Earlier I
established that a resolution decision needs a named human, and a tool a model can call is the
opposite of that. A model here reads every judgment already made, and sees what's still open.
It can't make one.

## [1:50] A contract that refuses things — `w11-contract.png`

The other piece is the signal: a JSON file another system parses, frozen at version one point
zero and validated before it's ever written to disk.

It refuses ten field names outright — valuation, market cap, shares outstanding, return. Not
style; structure. These filings give a fund's share count, never the company's total shares, so
there's no arithmetic here to a company's value. A field for it would invite someone to fill it
from elsewhere and inherit that error.

And where a figure is withheld, the reason is a value, not a missing key.

## [2:30] Four checks on generated prose — `w11-guards.png`

The quarterly note is the only prose a model writes here, and it gets the computed figures and
nothing else — no database, no tools.

I expected one check to be enough: no number that isn't in the figures. It wasn't. A draft
passed cleanly and still claimed one company had the fewest marks, one sentence before claiming
a different company had the fewest. Every number was real. The ranking was invented.

Four checks now, and a failed draft goes back with the specific complaint.

## [2:55] Close — camera

The last lesson was cheaper to learn than to admit. Three setup bugs in a row, all invisible
from inside the server, all because my test supplied what a real client doesn't. Thanks for
watching.
