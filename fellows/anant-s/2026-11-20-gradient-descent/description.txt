Gradient Descent, One Step at a Time

How does a neural network actually learn? One rule: measure the slope, take a small step the other way, repeat.

Worked on real numbers, then broken twice: a step size that runs away, and a valley that is not the lowest one. Then how the same rule scales to billions of settings.

THE PROMPT FROM THIS EPISODE

Write a short Python script, no ML libraries, that runs gradient descent on loss = theta squared, starting at theta = 3, for 10 steps, with step sizes 0.01, 0.1, 0.9 and 1.1. Print theta after every step. Then, using only the printed numbers, tell me which runs converge, which oscillate, which blow up, and predict the largest step size that still converges.

Sources: Cauchy (1847), Méthode générale pour la résolution des systèmes d'équations simultanées; Goodfellow, Bengio & Courville, Deep Learning (MIT Press, 2016), §4.3 and §8.1.3; Rumelhart, Hinton & Williams (1986), "Learning representations by back-propagating errors", Nature 323.
