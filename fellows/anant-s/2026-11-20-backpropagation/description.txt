Backpropagation, One Error at a Time

Gradient descent needs a slope for every weight. Backpropagation gets all of them in one backward pass: the chain rule, run from the loss back to the input.

A two-weight network, forward and backward on real numbers, checked against finite differences, then ten sigmoid layers where the gradient all but vanishes.

THE PROMPT FROM THIS EPISODE

Write a short Python script, no ML libraries, for y = w2 * tanh(w1 * x) with loss (y - t)^2, using x = 1, t = 0.2, w1 = 0.5, w2 = 2. Compute dL/dw1 and dL/dw2 with the chain rule, then check both with central finite differences using a step of 0.00001. Print each pair and their difference. Then set w1 = 5 and explain, from the numbers, which factor in the chain shrinks dL/dw1.

Sources: Rumelhart, Hinton & Williams (1986), "Learning representations by back-propagating errors", Nature 323; Goodfellow, Bengio & Courville, Deep Learning (MIT Press, 2016), §6.5.
