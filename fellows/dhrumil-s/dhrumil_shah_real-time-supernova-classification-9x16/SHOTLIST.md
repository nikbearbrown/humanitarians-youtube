# SHOTLIST — Seven Million Alerts a Night

Typed work order, one block per beat. **Every shot in this film is a pipeline shot.** There are no
archival stills, no stock, no screen recordings, no AI-generated imagery and no human-supply slots.
Astronomical imagery is generated by `assets/gen_sky.py`; everything else is drawn in the Remotion
component. If a frame ever looks like a placeholder, it is a render bug, not a request for media.

**Canvas** 2160 × 3840 (9:16) · **30 fps** · **4,914 frames / 163.80 s** · **16 beats**
**Clock** measured Kokoro `am_onyx` narration — `audio/timings.json`, imported by the composition.
Exact frame in/out for every beat is recorded in `beat_sheet.json` and `storyboard/STORYBOARD.md`;
this document gives the measured narration length, which is what drives each beat.

---

## Standing rules (every beat)

- **Ground:** `#04060C` deep-sky gradient, faint `#121C29` coordinate grid, parallaxed starfield.
- **Safe area:** left 140 · right 150 · top 250 · **bottom 640** px. The bottom reserve clears the
  Shorts / Reels / TikTok caption and CTA strip; the right reserve clears the action buttons.
- **Band plan:** chrome rail y=250 · pipeline rail y=392 · title y=560 · stage y=960–2610 ·
  captions y=2700–3030 · source line y=3150. Below y≈3300 is deliberately empty.
- **One accent per frame.** Amber `#FFB454` = the candidate (or, in B00, the summary's key phrase).
  Cyan `#4FD8EC` = instrument/detection. Crimson `#FF6B7C` = rejected. Green `#63E8A4` appears only
  from B13, once confirmation exists as a concept.
- **Entrances:** one spring (damping 24, stiffness 110, mass 0.9) — fade plus 34 px lift.
- **Type:** Georgia for headlines, Segoe UI for captions/body, Consolas for chrome and numerals.
- **Every beat carries** the chrome rail (presenter · title · NN/16) and a SOURCE line.
- **Transitions:** hard cut on the measured beat boundary. The 0.32 s narration gap is the transition.
