# ASSETS — Seven Million Alerts a Night

**Every asset in this film is original and generated locally. Nothing was downloaded, licensed,
purchased, sampled, or lifted.** There is no third-party media in the picture or on the soundtrack,
so there is no rights question to resolve and nothing to clear before use.

Total spend: **$0.00.**

## 1. Generated astronomical imagery

Produced by [`assets/gen_sky.py`](assets/gen_sky.py). Deterministic and seeded — re-running the
script reproduces every PNG byte-for-byte (verified during this build: 25 of 25 identical to the
previously staged set).

| File | Size | Used by | What it is | Seed |
|---|---|---|---|---|
| `template_256.png` / `template_512.png` | 256 / 512 | B04, B05, B07, B09 | Deep reference stack: seeded starfield + an inclined exponential-profile galaxy, its bulge, and a neighbour | 7001 |
| `science_256.png` / `science_512.png` | 256 / 512 | B04, B05, B09 | The same field plus one new PSF source and an independent noise realisation | 7001 |
| `difference_256.png` / `difference_512.png` | 256 / 512 | B05, B07, B09, B12 | science − template, zero-is-mid-grey | 7001 |
| `difference_zoom.png` | 420 | B05 | ×3 nearest-neighbour crop on the transient | derived |
| `imp_supernova` (+`_zoom`) | 256 / 340 | B06 | Residual offset from a galaxy | 7001 |
| `imp_variable` (+`_zoom`) | 256 / 340 | B06 | Residual on a catalogued star | 7101 |
| `imp_asteroid` (+`_zoom`) | 256 / 340 | B06 | Trailed source, present in science only | 7102 |
| `imp_agn` (+`_zoom`) | 256 / 340 | B06 | Residual on the galaxy nucleus | 7103 |
| `imp_cosmic_ray` (+`_zoom`) | 256 / 340 | B06 | Single-pixel streak, no PSF wings | 7104 |
| `imp_bogus` (+`_zoom`) | 256 / 340 | B06 | Positive/negative dipole from misregistration | 7105 |
| `sheet_6x10` (+`_dark`) | 1870×3110 | spare | 60-stamp contact sheet, one true burst | 9301 |
| `sheet_10x18` (+`_dark`) | 1888×3392 | spare | 180-stamp contact sheet | 9302 |
| `sheet_14x26` (+`_dark`) | 2050×3802 | B02 | 364-stamp contact sheet, burst at index 201 | 9303 |
| `MANIFEST.json` | — | — | Every recipe, seed and feature position | — |

**Physical conventions.** Point sources are Gaussian PSFs at a common FWHM; the galaxy is an inclined
exponential profile; science images are template + new source + an *independent* noise realisation,
so subtraction leaves real residual noise. Difference images use the astronomical convention — **zero
is mid grey, positive flux white, negative flux black**.

The `_dark` sheet variants map |residual| onto a black-to-white ramp. The physics shown is unchanged,
but a mid-grey sheet enlarged behind a deep-sky frame reads as fog, so B02 uses the dark variant while
every frame that asks the viewer to judge a residual's *sign* keeps the grey convention.

**On-screen labelling.** Every beat showing this imagery carries
`SYNTHETIC DATA · GENERATED BY assets/gen_sky.py`.

## 3. Music

Produced by [`assets/gen_audio.py`](assets/gen_audio.py) — **original composition, synthesised from
scratch.** No samples, loops, library tracks or licensed cues.

| File | Detail |
|---|---|
| `assets/music/score.wav` | full film length · 48 kHz mono · −18 dBFS nominal |
| `assets/music/CUE-SHEET.md` | section-by-section record with measured in/out times |

**Method:** additive pads (five partials per voice, two detuned stacks), a sine sub an octave below
the chord root, and a decaying 2 Hz pulse in the two high-energy sections. Seven sections in D minor,
**defined by the beats they span** rather than by absolute time, so the music moved with the picture
when the introduction was added:

| Section | Beats | Chord | Intensity | Pulse |
|---|---|---|---|---|
| welcome | B00 | D3 · A3 · D4 | 0.40 | — |
| curiosity | B01–B02 | D3 · A3 · F4 | 0.55 | — |
| the problem | B03–B05 | D3 · F3 · A3 · D4 | 0.72 | — |
| mechanism | B06–B08 | B♭2 · F3 · D4 | 0.86 | 2 Hz |
| classify | B09–B11 | F2 · C3 · A3 · C4 | 0.58 | — |
| the rise | B12–B13 | D3 · A3 · D4 · F4 | 0.92 | 2 Hz |
| resolve | B14–end | D2 · A2 · D3 · F3 | 0.62 | — |

The shape follows the brief: a quiet welcome, curiosity at the open, energy through the alert-stream
sequence, intensity dropped for classification, built again for follow-up, resolved at the close.
Measured in/out seconds are in `CUE-SHEET.md`.

Every effect is positioned relative to a **measured** beat start. Nothing is louder than the
narration.

## 5. Narration

| File | Detail |
|---|---|
| `audio/beat_01.wav` … `beat_16.wav` | per-beat narration in play order (`beat_01` = B00 intro), 48 kHz mono, peak-normalised |
| `audio/beat-B00.mp3` … `beat-B15.mp3` | same beats by beat ID, 192 kbps, for the Remotion public dir |
| `audio/narration_master.wav` | concatenated master with 0.32 s gaps |
| `audio/timings.json` | **measured** durations — imported directly by the composition |
| `audio/mixdown.wav` | narration + score + effects, ducked and limited |

**Engine:** Kokoro-82M via `kokoro-onnx`, local, voice `am_onyx`, speed 1.0. No API key, no network,
no cost. Kokoro is deterministic: regenerating the film's fifteen original beats reproduced their
durations exactly. The presenter's name is respelled for the synthesiser (`Dhrumil` → `Dhroomil`) in
`generate_narration.py`; the captions and on-screen text use the correct spelling.

## 9. Deliberately absent

| Not used | Why |
|---|---|
| Real Rubin / ZTF / NOIRLab imagery | Excluded so no frame could be mistaken for an observation and no credit line must be reproduced exactly. |
| Stock footage, stock music, sound libraries | Licence-encumbered and unnecessary. |
| AI-generated stills or video | No beat needs a photographic scene; paid generation was never on the path. |
| A photograph or video of the presenter | The intro is a typographic and diagrammatic card; no likeness was supplied, and none is needed to carry the greeting. |
| Photographs of named researchers | No beat depends on a likeness. |
| Screen recordings of broker interfaces | Would date immediately and misrepresent one UI as the general case. |

## 10. Reproducing every asset

```bash
python scripts/generate_narration.py   # Kokoro narration + measured timings
python assets/gen_sky.py               # astronomical imagery
python assets/gen_audio.py             # score, sound design, final mix
python assets/gen_thumbnail.py         # cover art
python scripts/build_beat_sheet.py     # beat_sheet.json from the measured clock
python scripts/build_captions.py       # captions from the component
python scripts/render_4k.py            # sync + Remotion render
python scripts/export_masters.py       # mux soundtrack, four cuts
python scripts/build_storyboard.py     # storyboard + QC frames
python scripts/final_qc.py             # automated checks
```

Every step is local and free.
