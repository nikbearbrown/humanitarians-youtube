# ASSETS — Seven Million Alerts a Night (16:9)

**Every asset in this film is original and generated locally. Nothing was downloaded, licensed,
purchased, sampled, or lifted.** There is no third-party media in the picture or on the soundtrack.

Total spend: **$0.00.**

This is the landscape cut. It shares its narration, soundtrack, captions and 25 of its 26 images
**byte-for-byte** with the 9:16 cut in `../real-time-supernova-classification-9x16/` (copied and
verified with `cmp`). What is new here is the composition, one landscape candidate sheet, and the
16:9 cover art.

---

## 1. Generated astronomical imagery

[`assets/gen_sky.py`](assets/gen_sky.py) — deterministic and seeded. Adding the landscape sheet was
verified not to change any existing image (25 of 25 unchanged).

| File | Size | Used by (16:9) | What it is | Seed |
|---|---|---|---|---|
| `template_256.png` / `template_512.png` | 256 / 512 | B04, B05, B07, B09 | Deep reference stack: starfield + inclined exponential galaxy, bulge, neighbour | 7001 |
| `science_256.png` / `science_512.png` | 256 / 512 | B04, B05, B09 | Same field + one new PSF source + independent noise | 7001 |
| `difference_256.png` / `difference_512.png` | 256 / 512 | B05, B07, B09, B12 | science − template, zero-is-mid-grey | 7001 |
| `difference_zoom.png` | 420 | B05 | ×3 nearest-neighbour crop on the transient | derived |
| `imp_*` (+`_zoom`) × 6 | 256 / 340 | B06 | supernova · variable star · asteroid · AGN · cosmic ray · subtraction artifact | 7001, 7101–7105 |
| **`sheet_26x14` (+`_dark`)** | **3802×2050** | **B02** | **New for 16:9.** 364-stamp landscape contact sheet, one true burst | **9304** |
| `sheet_6x10`, `sheet_10x18`, `sheet_14x26` (+`_dark`) | portrait | — (9:16 cut) | Portrait contact sheets, kept so both cuts regenerate from one script | 9301–9303 |
| `MANIFEST.json` | — | — | every recipe, seed and feature position | — |

**Physical conventions.** Gaussian PSFs at a common FWHM; inclined exponential galaxy profile;
science = template + new source + independent noise, so subtraction leaves real residual noise.
Difference images use the astronomical convention — zero is mid grey, positive white, negative
black. The `_dark` sheets map |residual| onto a black ramp so an enlarged sheet reads as a field of
stamps rather than fog behind the deep-sky frame.

Every beat showing this imagery carries `SYNTHETIC DATA · GENERATED BY assets/gen_sky.py`.

## 10. Deliberately absent

| Not used | Why |
|---|---|
| Real Rubin / ZTF / NOIRLab imagery | no frame can be mistaken for an observation; no credit line to reproduce |
| Stock footage, stock music, sound libraries | licence-encumbered and unnecessary |
| AI-generated stills or video | no beat needs a photographic scene |
| A photograph or video of the presenter | the intro is a typographic and diagrammatic card; no likeness is needed |
| Screen recordings of broker interfaces | would date immediately and misrepresent one UI as the general case |

## 11. Reproducing every asset

```bash
python scripts/generate_narration.py   # Kokoro narration + measured timings (identical to 9:16)
python assets/gen_sky.py               # astronomical imagery, incl. the landscape sheet
python assets/gen_audio.py             # score, sound design, final mix (identical to 9:16)
python assets/gen_thumbnail.py         # 16:9 cover art
python scripts/build_beat_sheet.py     # beat_sheet.json from the measured clock
python scripts/build_captions.py       # captions from the component
python scripts/render_4k.py            # sync + Remotion render at 3840x2160
python scripts/export_masters.py       # mux soundtrack, four landscape cuts
python scripts/build_storyboard.py     # storyboard + QC frames
python scripts/final_qc.py             # automated checks
```
