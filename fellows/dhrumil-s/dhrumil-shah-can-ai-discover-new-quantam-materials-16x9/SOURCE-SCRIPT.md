## Notes on wording

"L K ninety-nine" is written with spaces in `beat_sheet.json` so Kokoro
pronounces the letters individually rather than attempting a word.

Numbers are spelled out in the narration source ("twenty eighteen", "nine and
a half kelvin") for the same reason. The on-screen text uses numerals.

The narration never says "we discovered", "AI found", or any phrasing that
would imply a result this project did not produce.
