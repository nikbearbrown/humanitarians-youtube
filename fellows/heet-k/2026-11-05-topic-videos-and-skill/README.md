### 2. A skill to generate more videos of this type — capability

Rather than making these one-off, I am building a **skill** that encodes the
video type so future ones are generated rather than hand-assembled. Built in
Week 23 and extended in Week 24. **Still in progress**, self-reviewed, not
shared or validated — its real test is whether it actually produces good videos
of the type in use, which has not happened yet.

This is the week's durable contribution, and it is the same move as
[`sri-explainer`](../2026-08-24-sri-explainer-skill/) in August: when a format
is going to repeat, the generator outlasts the instances. Unlike
[`logo-motion`](../2026-10-01-intro-outro-brutalist-pass/#attribution--correcting-the-weekly-reports),
which I used but did not write, this skill is authored by me.

## Why a skill rather than only videos

Five videos prove the topic works. A skill makes the type repeatable without me,
which is the difference between output and capability. Both count; only one
compounds. The [twenty Shorts in Week 21](../2026-10-22-twenty-shorts-upload/)
are what that compounding looks like once it arrives — they were possible
because the branding had already been moved behind a tool.
