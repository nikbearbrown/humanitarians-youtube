# Causal Couture — Week 1: From Four Sources to One Prototype

- Presenter: Ushasvi Rachel
- Organization: Humanitarians.ai
- Project/topic: Phase 3 analytical prototype integration
- Summary: Integration of sales, inventory, social, and web inputs into a unified fashion-business analytical workflow, scorecard, recommendation layer, API, and frontend prototype.
- Aspect ratios produced: 16:9 (3840×2160 master)
- Main source files: `beat_sheet.json`; `remotion/scenes/CausalCoutureWeek1.tsx`; `remotion/tokens/{claude,layout}.ts`

Created with Brutalist: the beat sheet defined narration, timing, and visual intent; the Remotion scene rendered the branded analytical graphics, and the local assembly pipeline combined beat video and narration.

## Rebuild

From the repository root, copy the scene and token files into `runtime/remotion/src/` (preserving `scenes/` and `tokens/`), register/use the `CausalCoutureWeek1` composition in the existing Remotion entry point, and use the beat sheet/audio workflow to assemble the master. Keep the original `work/` project available for rendered media; this folder intentionally contains source/support files only.

Final MP4/MP3 deliverables are stored separately in Google Drive and are intentionally excluded from GitHub.
