# Train, Validation, Test: Why We Split Machine-Learning Data

- **Presenter:** Ushasvi Rachel
- **Organization:** Humanitarians.ai
- **Type:** Standalone STEM/AI education
- **Formats:** 16:9 master source and portrait-native 9:16 source

An explainer about the distinct roles of training data, validation or cross-validation, and a protected final test set, including time-series and grouped-data splitting concerns.

The root beat sheet is the horizontal master. Horizontal and vertical Remotion components are separated under `remotion/`, with the vertical beat sheet preserved beside its source.

**Educational boundary:** No split percentage is universally correct. Cross-validation does not solve every evaluation problem, and a protected test score does not guarantee future production performance.
