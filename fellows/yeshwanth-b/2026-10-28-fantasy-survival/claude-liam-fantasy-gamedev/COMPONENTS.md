# COMPONENTS — Fantasy Survival Crafting: Inside the Godot Code

Every project file (except `.godot/`, `.uid`, `builds/` and `submission/`) is assigned a component in `gamedev-evidence.json`. Components:

- scenes
- world-builder
- model-repair
- player
- crafting
- objectives
- trees
- rabbits
- campfire
- inventory
- day-night
- stats
- save-load
- menus
- rendering
- audio
- tools-and-tests
- config
- art-assets

**Excluded:**

- `builds/`: exports, boot-tested separately.
- `submission/`: the GDD, screenshots and logs. The GDD is the subject of the GDD film.
