# RIFF — Gino: Knife Throw, Inside the Godot Code

- **The combo (B09–B10).** The code that chains four swings is real; the takes never reach the fourth. The result beat says why instead of cutting around it.
- **One line too late (B25–B26).** The same pattern as the Stage Runner restart bug: a handler changes the scene, then touches the viewport.
- **Driver vs game (B08).** The long jump past the walker is a driver rule; the physics shown are the game's.
