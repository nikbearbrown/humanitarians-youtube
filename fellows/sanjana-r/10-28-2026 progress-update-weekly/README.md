## What's in the video (stats only — no names)

of October 25th…"* Then:

2. **Where the time went** — review→approval 8h · uploads & QC 7h · progress sheet & revisions 4h · pre-review pipeline 3h.
3. **Two review stages** — 22 reviewed and sent for professor approval; 25 taken all the way to publish.
4. **Quality exceptions flagged** — 8 videos below 4K; 4 missing the @HumanitariansAI watermark; code-on-GitHub tracked per project.
5. **Coordination** — pre-review pipeline with the dev team; the weekly progress sheet; revisions communicated to each creator.
6. **Next week** — push the 4K + watermark checks upstream into the pre-review pipeline.

Every video count is exact from the week's task log (see `../FACTCHECK.md`); the 22-hour figure
is a self-reported allocation (≥ the 21h logged).
