# PROMPTS — The Numbers Aren't Final Yet

Beat-prefixed prompts for open slots. **There are no open slots** — all nine
beats render from registered Remotion compositions.

- **B00** — composer content (on screen):
  "I'm comparing yesterday's channel numbers against last week's. Before I
  report a trend — were both of those numbers actually final?"
- **B07** — the viewer handoff prompt (on screen, meant to be pasted):
  "Help me add a data-age column to this report and set a maturity threshold,
  so nothing gets reported before it has stopped changing."

No image generation, no stock, no AI video. Free path throughout.
