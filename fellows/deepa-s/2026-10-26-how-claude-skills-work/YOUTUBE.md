## Title

How Claude Skills Work: Automation vs. AI Judgment

## Description

How do Claude Skills make repeatable tasks easier—and where does human judgment still matter?

Deepa S. introduces four practical examples: Web Artifacts Builder, Webapp Testing, XLSX, and Slack GIF Creator. Learn how reusable instructions and supporting tools can structure a workflow, and why successful execution is not a guarantee of accessibility, accuracy, sound assumptions, or clear communication.

In this video:
• What SKILL.md does
• Web artifacts: building an interface versus testing its quality
• Webapp testing: passing checks versus complete coverage
• Spreadsheets: working formulas versus correct assumptions
• GIFs: technical compliance versus effective communication
• Why meaningful validation and human judgment remain essential

Try it: choose a familiar task. Write down one result an automated check can verify and one question a person still needs to evaluate.
