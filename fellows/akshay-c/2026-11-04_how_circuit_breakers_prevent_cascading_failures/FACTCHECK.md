# FACTCHECK - How Circuit Breakers Prevent Cascading Failures in Distributed Systems

| Claim | Source / Technical Standard | Verdict | Implementation Note |
|---|---|---|---|
| Unchecked downstream latency causes thread pool exhaustion and cascading failures | Michael Nygard, *Release It! Design and Deploy Production-Ready Software* (Ch. 5: Stability Patterns); Martin Fowler, "CircuitBreaker" (2014) | TRUE | Synchronous network calls block worker threads until timeouts elapse; saturated thread pools block incoming requests across upstream tiers, causing cascading cluster failure. |
| Circuit breakers intercept calls and wrap remote dependencies | Netflix Hystrix Architecture Guide; Resilience4j Specification; Envoy Proxy Circuit Breaking Documentation | TRUE | The circuit breaker acts as a proxy or client filter around remote procedure calls (RPC/HTTP), tracking success and failure rates. |
| Closed state forwards requests and maintains a rolling metric window | Resilience4j Core Concepts; Martin Fowler, "CircuitBreaker" | TRUE | In the Closed state, requests pass through unimpeded; metrics are tracked in a ring buffer or sliding time window. |
| Exceeding error thresholds immediately trips the breaker to Open | Netflix TechBlog, "Fault Tolerance in a High Volume, Distributed System"; IEEE Software Standards on Resilience | TRUE | When the percentage of failed requests or consecutive timeouts exceeds configured thresholds (e.g. 50%), the breaker trips to Open. |
| Open state fails fast in zero milliseconds and returns fallback responses | Michael Nygard, *Release It!*; AWS Well-Architected Framework: Reliability Pillar | TRUE | The breaker short-circuits calls locally, throwing an exception or returning cached/default responses without making network calls, preventing downstream hammering. |
| Half-Open state sends canary probe requests to verify service recovery | Martin Fowler, "CircuitBreaker"; Resilience4j Half-Open State Machine | TRUE | After a sleep window (e.g. 10–30s), a limited number of test requests are permitted through to evaluate downstream health. |
| Successful probes reset to Closed; failed probes retrip to Open | Netflix Hystrix Documentation; Istio Service Mesh Fault Injection & Recovery | TRUE | If all probe requests succeed, the breaker resets to Closed and clears metrics. If any probe fails, it trips back to Open for another sleep interval. |
| Pairing circuit breakers with bulkheads and timeouts isolates failure domains | Google Site Reliability Engineering (SRE) Book (Ch. 22: Addressing Cascading Failures); Martin Fowler | TRUE | Circuit breakers work together with thread/semaphore bulkheads and bounded timeouts to isolate failure domains and preserve core service availability. |
