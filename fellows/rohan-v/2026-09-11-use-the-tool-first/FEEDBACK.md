## How to leave feedback

Point at a beat by its ID. Narration durations are the master clock, so a note
that changes narration forces regenerating that beat's audio, re-rendering its
scene to the new duration, and recompiling both cuts.

| Beat | Act | What it does |
|---|---|---|
| B00 | ASK | Cold open — the week in one line |
| B01 | SHIPPED | Six parts, 18:59, all 4K |
| B02 | CORRECTION | The five overturned assumptions |
| B03 | KIT | 23 components, named |
| B04 | NEXT | Signup docs open; both tools next |
| B05 | OUTRO | Sign-off |

If a **number** is disputed, check [FACTCHECK.md](./FACTCHECK.md) first — every
figure on screen has a row there, and two upstream document inconsistencies
(capture count, and 18:58 vs 18:59) are already resolved in it.
