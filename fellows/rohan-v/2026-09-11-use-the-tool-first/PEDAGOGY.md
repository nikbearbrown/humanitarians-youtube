# PEDAGOGY — "Use the Tool First."

Narration sign-off. This is the project-progress half of the weekly
submission, so the test is not "did they learn a concept" but "can they say
what changed this week and what it cost."

## The one thing this reel has to land

**Using the tool is what corrected the plan.** Not "I made six videos" — that
is output, and output alone does not justify a slot on a public channel. The
reportable thing is that a plan built from research was wrong in five specific
ways, that using the product exposed it, and that fixing it left behind
something reusable.

## Register — Pragmatist, per `brands/hai.md`

- **Leads with the constraint.** B02 names the error before the remedy. ✓
- **Admits fault without performing it.** "Five things in my plan turned out to
  be wrong" is stated flatly, once, and then itemised. No apology, no
  self-flagellation. ✓
- **No marketing language.** Six shipped videos are reported, not celebrated. ✓
- **Every number checkable.** ✓

## Deliberate decisions

**The reel argues against its own headline output.** B00 says the videos are
not the useful part. That is unusual for a progress report and it is the point:
a week of video production is not interesting; a week where research-based
assumptions met reality and lost is.

**"Cost a week" is stated, not hidden.** B03 opens with "the correction cost a
week and bought something durable." Framing the rework as a cost that bought an
asset is honest in both directions — it does not pretend the week was free, and
it does not pretend the rework was wasted.

**All 23 component names are on screen.** A count is a claim; a list is
evidence. It also makes the beat useful to a future fellow who can search for
`MjL4Panel` and find the thing.

**The plan document was not deferred to.** It says 23 captures in one place and
29 in another, and 18:58 where the measurement rounds to 18:59. The reel
measured. This is the second consecutive week a planning document has been
stale — recorded in FACTCHECK and SOURCES so the pattern is on the record.

**Nobody is named but the presenter.** Consistent with every reel on this
channel.

## Vocabulary discipline

| Term | How it is handled |
|---|---|
| component | used plainly and immediately explained by consequence: "I edit a component instead of re-recording six videos" |
| rebuilt in code | the durability claim, always paired with what it buys |
| beat check | named once in B01 as an automated check; not explained, because the viewer only needs to know one exists |
| capture / screenshot | "screenshots" in narration, "captures" only in on-screen labels where space is tight |
| UI spec | described by size and purpose ("so the next person doesn't have to guess") rather than by name |
| Midjourney surfaces (Style Creator, Moodboards) | **cut from narration entirely** — named only in the B02 corrections column, where a viewer can read them without needing them explained |
