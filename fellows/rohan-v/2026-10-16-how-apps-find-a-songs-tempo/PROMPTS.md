# PROMPTS — "How Apps Find a Song's Tempo"

Design intent per visual. Nothing here was generated by an image or video model: every beat is a
deterministic Remotion render of recorded data, so these are **component briefs**, not generation
prompts. The listening clip is the run's own WAV file.

## The library-first gate

`./art scenes` was run before anything was authored (misses are logged to `TEMPLATE-MISSES.md`):

| Need searched | Closest candidate | Verdict |
|---|---|---|
| a waveform with beat marks | `ShazamPeaks` (last week: spectrogram peaks) | miss: no waveform, no beats |
| an onset / novelty curve | `LossySpectrumCut` (noise spectrum) | miss |
| autocorrelation with a sliding copy | none | miss |
| a results grid of right / half / double | `ShazamNoiseSweep` (squares per clip) | near-miss: its idea, rebuilt for four outcomes |
| a typeset equation | the house renderer `typeset_math.py` | **hit**, used for B03 |

`ClaudeComposerAsk`, `HaiApplyCard` (`phoneType` on the phone) and `HaiTitleOutro` are reused as-is.

## Shared kit — `scenes/tempo/`

- `tempoData.ts`, **generated** by `export_tempo_data.py` from `evidence/scene.json` and
  `evidence/results.json`: the example groove's envelope, true beats, onset curve, autocorrelation and
  prior; the 40-groove results; the drift run; the typeset equations; the librosa logo path.
- `public/tempo/bands.png`: the example's 40 mel bands (4 s), ink on transparent, louder = darker.
- `public/tempo/librosa-01.svg`: librosa's own mark (LOGO LAW), copied from `icons/logos/librosa/`.
- `tmpKit.tsx`: `prior()` (librosa's default bell), `seriesPath`, `Waveform`, `TimeAxis`, `Caps`;
  `Chip`, `listening`, `Stat`, `PhoneBaseline` reused from last weeks' kits.

## Per beat

| Beat | Component | Brief |
|---|---|---|
| B01 | `TempoBeats` | The example groove's waveform; true beats drop in as terracotta ticks, then fade to grey dashes ("the app gets only the sound"); the clip plays with a playhead. |
| B02 | `TempoOnsets` | The 40 bands as an image; the onset curve drawn under it from the start as a ghost, then in ink on "add those jumps up"; the tallest spikes marked. |
| B03 | `TempoAutocorr` | The curve and a terracotta copy sliding right (off the beat, onto one beat, onto two); the match score drawn as the copy slides; both peaks marked; rule and divisions typeset. |
| B04 | `TempoPrior` | The same match re-plotted against BPM (log scale): the highest point is 60; the bell centred at 120 is drawn and the curve multiplied by it: 120 wins. Test-set counts beside it; librosa's mark. |
| B05 | `TempoGrid` | One square per groove, coloured by outcome; the named rows fill first; totals and the librosa cross-check with its mark. |
| B06 | `TempoDrift` | Milliseconds off each true beat over 30 s: one fixed tempo (ink) wanders to 140 ms; the tracker (terracotta) stays in the ±50 ms band. |
