# PEDAGOGY — "How Pitch Correction Works"

How the reel is built to teach someone who has used a tuning plug-in, or heard Auto-Tune,
but never been told what it does.

## The register

The standing corrections still apply: *no assumed knowledge* and *the viewer has to learn
something*. So a background beat (what pitch is) comes before any mechanism, there is exactly
one equation, and the reel ends on two decisions the viewer can make tomorrow.

## The shape

| Beat | Job | What the viewer can do after it |
|---|---|---|
| B00 ASK | the question: how does software hear that a note is off? | name the answer's shape: measure, snap, pull |
| B01 BACKGROUND | a note is a vibration that repeats; 440 Hz; octaves; cents | read "−39 cents" as "a bit under half a semitone flat" |
| B02 MECHANISM | find the period by sliding the sound along itself | explain how a computer gets a frequency from a wave |
| B03 MATH | hertz to cents, and the nearest note becomes the target | work out how far off a note is |
| B04 MEASURED | a real detector and corrector, re-measured, and heard | believe it: the before and after are measured and audible |
| B05 RETUNE SPEED | instant = robotic, slow = human, both measured and heard | choose a speed on purpose |
| B06 THE CATCH | nearest note ≠ right note; the key fixes it | set the key before tuning |
| B07 WHAT TO DO | key first, speed second, ears last | tune a Lyrical Literacy vocal without wrecking it |
| B08 OUTRO | sign-off | — |

## Choices worth defending

- **Hearing, not only seeing.** A pitch video with no sound asks the viewer to trust curves.
  The two listening moments let the ear confirm what the plot says.
- **A synthesised voice.** It makes every number exact and reproducible, and keeps a real
  person's voice out of a teardown. It is labelled TEST SIGNAL wherever it appears.
- **The wrong-note beat.** The most useful thing a beginner can learn about pitch correction
  is that it is confidently wrong when the key is not set. It earns a whole beat.
