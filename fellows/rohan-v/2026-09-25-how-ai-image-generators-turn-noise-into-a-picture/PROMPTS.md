# PROMPTS — "How AI Image Generators Turn Noise Into a Picture"

Design intent per visual. Nothing here was generated by an image or video
model — every beat is a deterministic Remotion render of recorded data, so these
are **component briefs**, not generation prompts.

## The library-first gate

`./art scenes` was run before anything was authored:

| Need searched | Closest candidate | Verdict |
|---|---|---|
| "diffusion model noise to image denoising steps" | `BitGapNoise` (week-04, audio noise) | miss — no pictures, no steps |
| "particle cloud points converge into shape" | `CadencesFig4Compute` | miss — a scatter chart |
| "typeset equation math reveal" | **`TypesetMath`** | **hit** — the house renderer. Its SVG pipeline (`typeset_math.py`) is used; the scene is extended rather than reused so the term brackets can sit on measured spans |
| "four image grid variations seed" | `AlgArtSeedGrid` | near-miss — 3×3 seeds of a generative algorithm, but hard-coded art, not model output |
| "tv static noise field" | `BitGapNoise` | miss |

`ClaudeComposerAsk`, `HaiApplyCard` and `HaiTitleOutro` are reused as-is.
`ClaudeComposerAsk` gained one opt-in prop, `disclosure`, off by default, for the
submission guide's AI-narration disclosure.

## Shared kit — `scenes/diffusion/`

- `toyData.ts` — **generated** by `export_toy_data.py`; every pixel and number.
- `diffusionKit.tsx` — `PixelTile` (a 16×16 picture as rounded squares on a dark
  screen, cross-fading between two recorded snapshots), `snapshotAt` (step →
  bracketing snapshots), `forwardMix` + `ABAR` (the exact forward process and
  schedule, re-computed in JS and checked against the exporter), `StaticField`
  (decorative full-frame static, the only non-data pixels, B01 opening only).

## Per beat

**B01 `DiffuseSeedStatic`** — a television, cream page. Full-frame static until
"called a seed"; then the static coarsens into the seed's real 16×16 field, and
from "removes a little of the noise" it walks back through the recorded run to a
heart, framed in spark at step 0. Quote card with the key phrase highlighted on
"static on an old TV". A turning loop glyph: look, remove a little, repeat.

**B02 `DiffuseRainForward`** — a real training picture under falling rain; the
forward process runs 0 → 1000 (squared ramp so the first drops show) with two
multiplier bars. Six-panel strip labelled NO MODEL INVOLVED, a spark arrow
running right-to-left for "going backwards", and SHOWN THIS / GUESS THIS rings
on the 500 → 300 pair.

**B03 `DiffuseMixEquation`** — the typeset forward equation, three brackets on
measured term spans ("the noisy picture", "part picture", "part noise"); a live
readout at step 0 from the start that sweeps to 1000 on "shrinks"; the
√ᾱ₁₀₀₀ ≈ 0.0064 row; the loss row with a plain-language gloss.

**B04 `DiffuseReverseRun`** — left: 16 real training pictures, TOY MODEL and CPU
ONLY badges, three stats. Right: the reverse run with a step bar, and a smaller
tile of the model's running guess of the clean picture.

**B05 `DiffuseSeedPrompt`** — left: seed 38's static forking into "heart" and
"music note". Right: one prompt, four seeds (101/202/303/404) resolving in
parallel, framed in spark on "four different starting points".

**Portrait.** Every new scene lays itself out natively for 1080×1920 inside the
y 230–1440 safe band (THE ONDA CHECK) and is registered as `<Pattern>916`. The
916 files are thin re-exports; the layout branch lives in the component so the
two orientations can never drift apart.
