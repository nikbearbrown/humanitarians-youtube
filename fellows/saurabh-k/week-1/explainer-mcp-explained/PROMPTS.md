# PROMPTS — hai-mcp-explained

**No open slots.** Every beat renders from a registered composition, so there are no
request cards for supplied media. This file records the two prompts that appear *inside*
the film, which are content rather than production instructions.

## B00 — the opening ask (shown in the Claude composer)

> A language model can only produce text. So how does it end up reading my files, driving
> my browser, and querying an API? Explain what MCP actually is, and why it had to be
> invented.

## B09 — Your Turn (the handoff prompt, read aloud and discussed)

> List every MCP tool this app currently has access to. For each one, show me its name,
> its description, and the arguments it accepts — and tell me plainly what it is allowed
> to do on my machine.

The spoken handoff asks the viewer to **read** their existing tool list before adding
anything — the HAI spine question applied to this topic.
