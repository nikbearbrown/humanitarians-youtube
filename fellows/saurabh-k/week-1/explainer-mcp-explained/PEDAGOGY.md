# PEDAGOGY — hai-mcp-explained

## The one thing a viewer should leave with

*A model on its own cannot reach outside its box, and MCP is the plug that lets it — in a
form you can read and switch off.*

The reel is built so that the last clause carries the weight. Most MCP explanations stop at
"it connects AI to tools," which tells a viewer nothing they can act on. This one is
arranged so that by the end the viewer knows the connection is a file they can open, a
schema they can read, and a list they can audit.

## Structure

The order builds the argument rather than following the spec:

1. **Why this exists** (B00-B01) — the sealed box, stated before any terminology.
2. **Two sides and the gap** (B02) — the mechanism, in plain words, before the names.
3. **A hundred integrations become ten** (B03) — why a shared protocol is worth having.
   Deliberately placed before the vocabulary, so the terms arrive with a reason attached.
4. **Host, client, server, tool** (B04) — the four words, now that they have somewhere to land.
5. **Evidence** (B05-B07) — a real config file, a real schema, a real call. Three beats of
   first-party material in a row, which is where the reel earns its claims.
6. **Where to be careful** (B08) — a server runs with your permissions.
7. **Your turn** (B09) — the transfer.

## The transferable move

Evidence beats illustration. The reel never shows a diagram standing in for a fact it has
not checked. The config file is real, the schema is real, the call is real, and the three
SPEC-ASSERTED beats are marked as such rather than dressed up. A viewer learning to ask
"is this a measurement or a description?" has taken the method, not just the content.

## What the viewer is asked to do

Open whatever AI app they already use, find its MCP or connectors settings, and read the
list of tools it has been given. Add nothing. For each one, ask: *do I understand what this
is allowed to do.*

It is deliberately an audit rather than a build. The action is small, takes two minutes,
requires no setup, and produces the exact realisation the video is for.
