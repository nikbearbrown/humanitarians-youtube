# Agents, On Their Own — where the limits have to come from

**Group:** Brutalist team · **Built:** 2026-10-18 · **Vertical cut:** 2026-10-20

## Executive Summary

An agent is not a smarter model. It is the same model put inside a loop and given the ability
to act between the turns. Nothing about that loop knows when to stop, and this report argues
that the stopping condition is ours to write down. It covers what changes when the pause
disappears, the four words carrying the weight (tool, loop, autonomy, guardrail), and two real
limits taken from the fellow's own machine: a guardrail that tells an agent its own echo is not
a person speaking, and a toolkit that refused the previous video six separate times for things
a human had already decided mattered. The honest test offered for letting an agent run: the
work is checkable, a mistake is cheap to undo, and a rule can be written ahead of time.
Runtime 2:14 across 10 beats.
