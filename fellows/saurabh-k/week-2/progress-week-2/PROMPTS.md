# PROMPTS — hai-brutalist-week-2

Beat-prefixed prompts for open slots. **This reel has no open slots** — every beat is
generated from a Remotion pattern already in the toolkit, so nothing needs sourcing,
generating or dropping into a pantry. The entries below record what each beat says and
which pattern carries it.
