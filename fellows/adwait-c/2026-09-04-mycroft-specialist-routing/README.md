## What the video does

Turns a single finance agent into a supervised team. Before anything is delegated, a lineage specialist verifies the whole source chain. Outstanding evidence gaps are then ranked by cumulative adverse impact and routed to the specialist scoped to chase them, with every delegation capped and every result fingerprinted. The honest finding is at the top of the queue: every ranked gap ends up blocked on a human, because the evidence each one needs is an owner's causal explanation that no agent in the system can write.
