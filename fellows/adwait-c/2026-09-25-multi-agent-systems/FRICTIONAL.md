# Frictional Log — Multi-Agent Systems

**Week of 2026-09-25** · Adwait Changan · Agentic AI playlist (Episode 8)
Topic: more agents buys parallelism and specialisation, and charges coordination and reliability.

**What I built this week**
- Priced the second agent instead of assuming it helps.
- Showed reliability compounding downward: 8 agents at 95% each finish the chain only 66% of the time — and nobody failed individually.

**The one idea it teaches**
- Most "multi-agent wins" are really one agent with better tools. To merely match one agent at 95%, eight chained agents each need 99.36%.

**Where it pushed back (and what I did)**
- Named the honest exception rather than overselling the point: if the work genuinely parallelises, or the agents vote, the arithmetic flips in favour of more agents.

**What I learned**
- Every step that *must* succeed multiplies the failure risk. Topology isn't free.
