# PEDAGOGY — Gate P (Short derivative cut)

9:16 Short derived from *When the Reviewer Disagrees*, 2026-10-02.

## What this cut is

A derivative, not a re-edit. Kept beats carry the parent's narration text unchanged,
regenerated locally from the same voice, so their durations match the long cut frame for
frame. Only the outro is new.

## What was cut, and why by hand

The auto-plan drops BVDT and BHTF, which removes the verdict and the viewer task. Rejected:
that fails PROOF's active-task criterion outright.

Dropped instead: **B03, B04, B06, B07, B08** — the act-two framing card, the code beat, and the beats that
restate a point the kept beats already carry.

**The code beat is dropped on purpose, and it is the real loss.** Portrait is 1080 pixels
wide. These functions run 70 to 86 characters per line, and code cannot reflow, so mono type
sized to the longest line lands near 21px. That is not readable on a phone, and a wrapped
code line is worse than a missing one. The long cut carries the code, and this cut's outro
says so and points at it.

Kept: the intro line, the three things a disagreement needs, the recorded entry, the honesty card, the verdict, and the viewer task.

The spine the PROOF rubric scores survives the cut: a framework before any example, a worked
example that is real printed output rather than a claim, a falsifiability beat that names the
limit, and a task the viewer can run.
