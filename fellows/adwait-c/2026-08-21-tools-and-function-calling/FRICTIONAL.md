# Frictional Log — Tools and Function Calling

**Week of 2026-08-21** · Adwait Changan · Agentic AI playlist (Episode 3)
Topic: a tool is a contract you write in English, not a function you expose.

**What I built this week**
- Extended the running agent to call tools, and showed where the model actually "reads" the tool.
- Demonstrated that the description — not the signature — is the part that decides whether the tool gets used correctly.

**The one idea it teaches**
- The model never sees your implementation. It sees your description, so the description *is* the interface.

**Where it pushed back (and what I did)**
- Focused the episode on writing the contract well, rather than on the mechanics of wiring a function in.

**What I learned**
- Good tool use is a writing problem as much as a coding problem — the English contract carries the weight.
