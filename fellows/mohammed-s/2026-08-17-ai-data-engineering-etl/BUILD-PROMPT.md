# BUILD-PROMPT — `ai-data-engineering-etl`

Paste-ready. Rebuilds both masters end to end from this folder. Free/local: Kokoro
TTS, Remotion, ffmpeg. No API keys, no paid services, no publishing.

Run from the **brutalist.art toolkit root**
(`Brut/brutalist.art`). `PY` is the toolkit venv, which is the only interpreter
here that has `kokoro-onnx` installed:

```bash
PY=./venv/Scripts/python.exe        # Windows;  ./venv/bin/python on macOS/Linux
REEL="../mycroft-videos/youtube/ai-data-engineering-etl"
```

---

## The prompt

> Rebuild the reel at `../mycroft-videos/youtube/ai-data-engineering-etl` — both
> masters, 16:9 at 3840×2160 and native-portrait 9:16 at 2160×3840 — end to end.
>
> 1. **Check the gate.** `PEDAGOGY.md` must read `## VERDICT: PASS`. If it does
>    not, stop: no audio is generated against an unsigned narration.
> 2. **Author is a script, not a hand edit.** `beat_sheet.json` is generated by
>    `_build_sheet.py`; edit that file and re-run it, never the JSON. It carries
>    forward `actual_duration_s` for any beat whose narration text is unchanged,
>    so re-running it never destroys a measurement.
> 3. **Audio is the clock.** Regenerate narration for any beat whose words
>    changed, then re-stamp the durations.
> 4. **Wire the clock into the scenes.** The five `Etl*` compositions take a
>    `durationSeconds` prop that `Root.tsx` turns into `durationInFrames`, so each
>    animation spans exactly its beat. Re-stamp it after any audio change.
> 5. **Derive the portrait cut** with `_build_916.py` — never with
>    `runtime/scripts/shorts.py`, which would centre-cut and drop beats.
> 6. **Render Remotion via `remotion_scenes.py` only.** Never hand-roll
>    `npx remotion render`.
> 7. **Compile both masters**, then do the frame-level VISUAL QC pass on each —
>    sample frames, actually LOOK at them, audit the 9-point rubric, and log to
>    `_qc/REPORT.md`. The mp4 probe is a file check and never counts as QC.
> 8. **Never publish.** The masters stay in this folder.

---

## The commands

```bash
# 1 — GATE P must already read "VERDICT: PASS"
grep -m1 '^## VERDICT' "$REEL/PEDAGOGY.md"

# 2 — beat sheet (edit _build_sheet.py, not the JSON)
(cd "$REEL" && python _build_sheet.py)

# 3 — audio: the master clock. --only <ids> to re-voice just what changed.
PYTHONIOENCODING=utf-8 $PY runtime/scripts/generate_audio_kokoro.py "$REEL"

# 4 — wire measured audio into the Etl* composition durations
(cd "$REEL" && python - <<'EOF'
import json, pathlib
ETL = {"EtlGlueTax","EtlStages","EtlSchemaMapping","EtlWhereAiHelps","EtlSilentFailure"}
p = pathlib.Path("beat_sheet.json"); d = json.loads(p.read_text(encoding="utf-8"))
for b in d["beats"]:
    rem = (b.get("shot") or {}).get("remotion") or {}
    if (rem.get("pattern") or "").replace("916","") in ETL:
        rem["props"]["durationSeconds"] = round(float(b["actual_duration_s"]), 2)
p.write_text(json.dumps(d, indent=1, ensure_ascii=False), encoding="utf-8")
EOF
)

# 5 — derive the portrait sibling (reflow, never a crop)
(cd "$REEL" && python _build_916.py)

# 6 — render every beat (foreground; skips slots already filled, --force to redo)
PYTHONIOENCODING=utf-8 $PY runtime/scripts/remotion_scenes.py "$REEL"
PYTHONIOENCODING=utf-8 $PY runtime/scripts/remotion_scenes.py "$REEL/916"

# 7 — the two masters
PYTHONIOENCODING=utf-8 $PY runtime/scripts/compile.py "$REEL"     --height 2160
PYTHONIOENCODING=utf-8 $PY runtime/scripts/compile.py "$REEL/916" --height 3840

# 8 — frame-level visual QC on BOTH cuts (then READ the PNGs)
PYTHONIOENCODING=utf-8 $PY runtime/qc/final_frame_check.py "$REEL"
PYTHONIOENCODING=utf-8 $PY runtime/qc/final_frame_check.py "$REEL/916"
```

## Gotchas learned building this

- **`python` vs the venv.** The system `python` on this machine has no
  `kokoro-onnx`. Audio must run through `./venv/Scripts/python.exe`.
- **`PYTHONIOENCODING=utf-8`.** The toolkit's own content contains em dashes,
  arrows and middle dots; the Windows console defaults to cp1252 and will raise
  `UnicodeEncodeError` mid-run without this.
- **Run `_build_sheet.py` with the reel folder as cwd** — it writes
  `beat_sheet.json` relative to the working directory.
- **Monospace column alignment needs `whiteSpace: 'pre'`.** `'nowrap'` collapses
  runs of spaces, which silently destroys the aligned type columns in
  `EtlSchemaMapping`.
- **The stock Claude compositions have fixed, generous comp durations**, so they
  render far more frames than the beat needs and `remotion_scenes.py` then
  truncates. Measured here: `ClaudeComposerAsk` 900f/30s, `ClaudeVerdictArtifact`
  1020f/34s, `ClaudeCodeBeat` 300f/10s, `ClaudeTitleOutro` 180f/6s. That is the
  single biggest cost in this build — B07 renders 34s of 4K to keep 11.97s. The
  five `Etl*` compositions avoid it via `durationSeconds` + `calculateMetadata`.
  Do NOT "fix" it by shrinking the shared compositions in `Root.tsx`: other reels
  in the toolkit depend on those durations.
- **Two beats freeze-hold rather than truncate**, because their audio slightly
  exceeds the comp: 9:16 B00 (15.59s audio vs a 15s comp, 0.59s hold) and B04
  (10.24s vs 10s, 0.24s hold). Both land on a static end state, so the hold is
  invisible. Anything larger should be fixed by shortening the narration, never
  by stretching the clip.
- **Never kill a render mid-beat.** `extend_clip_to_duration()` writes
  `media/_ext_<BID>.mp4` and then moves it over the target; interrupting between
  those two steps leaves the RAW composition render in the slot (full comp
  length, not the beat length) and a broken `_ext_` file beside it. A re-run
  SKIPS that slot because the file exists, so the wrong-length clip survives into
  the cut. Recovery: delete both and re-render, or re-apply the conform by hand.
