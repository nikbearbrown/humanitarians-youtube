model prompts to record. GATE F requires this file; its honest content is that
nothing was generated.

## The on-screen prompts that ARE in the reel

Written, not generated, and shown to the viewer as content inside the composer:

**B00** — the week's ask

    claude "does _MANIFEST.md actually cover the repository, or just the parts
            I wrote?"

**B03** — the ask, expanded

    claude "classify every top-level path - and mark what has been listed but
            not reviewed"

**B10** — the scaffolded task handed to the viewer

    claude "diff my project's index against the actual top-level tree - what
            exists but is never mentioned?"

The B10 prompt is a set difference, which is the whole episode in one
operation: everything in the tree and not in the index is invisible to anyone
following the index. The GOOD/BAD discriminator names the belief that caused
this — "the docs are accurate" was true the entire time, and accurate is a
different claim from complete.
