# PROMPTS — The Constraint Isn't Speed

## Open slots: none

## The ask that made this more than a pros-and-cons list

"Pros and cons of 6G in IoT" invites two bullet lists. The ask that turned it
into an argument was:

```
claude "what actually decides whether an IoT deployment happens? Rank the real
constraints — then check whether the new generation's headline numbers are on
that list at all."
```

They are not. That mismatch became the framework, and once the framework
existed, the pros and the cons could be scored on the *same* three axes instead
of sitting in two unrelated columns.

## The ask that found the falsifiability beat

```
claude "find the forecast that would embarrass this technology's marketing —
from a named source, about the year it launches."
```

Ericsson's own 2030 forecast: 40% of cellular IoT connections still NB-IoT and
LTE-M, technologies introduced 2015–2017. A vendor with every reason to sell
the next generation, projecting that four in ten connections will not use it.

## Handling a forward-looking topic

6G coverage is mostly projection, so the rule applied here — reusable for any
"emerging technology" brief:

1. **Only named standards bodies or named forecasts.** No trade-press numbers.
2. **Speak forecasts as forecasts.** "Projects", never "will be".
3. **Cut the most quotable number if it is not load-bearing.** The peak-rate
   and latency targets were available and were dropped: they would have
   undercut the thesis and dated the reel.

## Reusable spine for an evidence-based topic explainer

```
claude "author an ai-explainer beat sheet: BLUF, then a FRAMEWORK of 2-4 axes
shown as a structure BEFORE any claim, one beat per axis, the downsides scored
on the SAME axes, then a falsifiability beat the framework PREDICTS, verdict,
scaffolded task. Every number carries its source on screen."
```
