# PROMPTS — The Status Is A Claim

No image or video generation was used. The reel is Manim + Remotion only, so
there are no model prompts to record. This file exists because GATE F requires
it, and its honest content is: nothing was generated.

## Stills

None. No archival fetch, no `pantry/`, no Ken Burns beats. Every frame is drawn.

## Higgsfield

Not used, not installed, not offered. This is a Fellow Tier build and ran
entirely free: Kokoro for narration, Manim and Remotion for picture.

## The on-screen prompts that ARE in the reel

These are prompts shown to the viewer as content, inside the Claude composer
chrome. They are written, not generated, and they are the real asks:

**B00** - the week's ask

    claude "write the attestation for v0.2.0, then set the status it earns"

**B03** - the ask, expanded

    claude "attest v0.2.0 in the SNICKERDOODLE format - tested, did-not-test,
            defects - then set status"

**B10** - the scaffolded task handed to the viewer

    claude "for this status field: list the evidence it asserts, and find
            anything in the logs that recorded a refusal"

The B10 prompt is the one that has to work on someone else's repository, so it
names an artifact class (`logs`) rather than a path, and it asks for two things
that can be checked independently: what the word asserts, and whether anything
said no.
