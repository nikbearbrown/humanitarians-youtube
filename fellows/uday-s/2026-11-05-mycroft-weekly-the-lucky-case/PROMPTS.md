# PROMPTS - The Lucky Case

No image or video generation was used. Manim + Remotion only, so there are no
model prompts to record. GATE F requires this file; its honest content is that
nothing was generated.

## Stills

None. No archival fetch, no pantry/, no Ken Burns beats. Every frame is drawn.

## Higgsfield

## The on-screen prompts that ARE in the reel

Written, not generated, and shown to the viewer as content inside the composer:

**B00** - the week's ask

    claude "run failed on --sample. is the Flags column documentation, or is
            it executed?"

**B03** - the ask, expanded

    claude "reconcile every Flags cell with the flags its script actually
            implements"

**B10** - the scaffolded task handed to the viewer

    claude "which fields here are written by a human and parsed by a program -
            and what happens to each when it is wrong?"

The B10 prompt asks for a list and then a failure mode per entry, which is the
whole episode in one operation. The GOOD/BAD discriminator names the belief that
caused this: "it is only documentation" is exactly what the Flags column looked
like, right up until a run passed it to a script.
