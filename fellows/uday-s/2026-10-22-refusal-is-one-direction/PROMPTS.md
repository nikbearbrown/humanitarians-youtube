# PROMPTS — Refusal Is One Direction

No image or video generation was used. Manim + Remotion only, so there are no
model prompts to record. GATE F requires this file; its honest content is that
nothing was generated.

## Stills

None. No archival fetch, no `pantry/`, no Ken Burns beats. Every frame is drawn.
The funnel in B04 is a drawn schematic of an argument, not a diagram of an
architecture, and is not presented as one.

## Higgsfield

## The on-screen prompts that ARE in the reel

Written, not generated, and shown to the viewer as content inside the composer.
Both are about READING a claim or EVALUATING a model. Neither performs or
describes the intervention.

**B00** — the topic question

    claude "what does abliteration actually remove, and what does the paper
            behind it claim?"

**B09** — the scaffolded task handed to the viewer

    claude "for this third-party model: name the base, the claimed edit,
            whether the weights are signed or hashed, and what tool access it
            would have here"

The B09 prompt is four checkable facts and deliberately ends on tool access,
because that is the one that decides how much the other three matter. A model
with no shell or network access is a much smaller problem than the same weights
driving an agent. The GOOD/BAD discriminator makes the same point from the other
side: "it benchmarks fine" is the answer the security source showed to be
worthless.

## What is NOT in this reel, by design

No prompt, frame, or narration line describes how to locate a refusal direction,
which layers to touch, what data to contrast, or where to obtain an already
edited model. The published finding is explained; the procedure is not. The
practical guidance runs the other way — toward checking a model before you run
it.
