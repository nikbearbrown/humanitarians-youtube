# GATE P — What Actually Crosses

**The one idea.** An integration is not a synchronisation. Exactly one thing
crosses from Canvas into the hub, it crosses only when someone clicks, and the
two services that would make it a real sync were never requested.

| Beat | The viewer should be able to say afterwards |
|---|---|
| B00 | this is about what moves between Canvas and the hub |
| B01 | connected does not mean kept in step, and that was a choice |
| B02 | one token, on click, left to right, and nothing on a schedule |
| B03 | the link tables fill up as people arrive, they are not a copy of Canvas |
| B04 | roster reading and grade writing are permissions, and this tool holds neither |
| B05 | one message goes the other way, and it carries a content pointer |
| B06 | a quiz score is graded and stored, and has nowhere to go |
| B07 | turning on grade passback is a scope decision, not a bug fix |
| B08 | one token, per click, one direction, one pointer back, nothing else |

**Register check.** Second person, plain English. NRPS and AGS are named and then
explained in the same sentence. `scopes: []` is shown as the live configuration
rather than described. No term is used before it is introduced.

**Honesty check.** Nine claims, nine fact-check rows, all traced to source files
or the operator's own documents. The reel does not claim a sync mechanism exists
that does not. B06 names the gap out loud rather than leaving it implied, and B07
presents the decision without recommending either side. Two code findings turned
up by the research are deliberately kept off camera and recorded in
`FACTCHECK.md` instead.

**Weakest beat.** B04. It carries four moves in one beat: what NRPS does, what AGS
does, that both are registration-time permissions, and that neither was requested.
The narration is the longest in the reel at 19.8 seconds. It holds together
because the two struck cards stay on screen while the narration finishes, but if
a beat loses someone it is this one.

**Gate status.** Narration is the operator's own script text, written and reviewed
before the build. Kokoro synthesis is free, so audio was generated with
`--no-gate`. This file is not self-signed.
