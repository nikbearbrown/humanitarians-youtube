# Four Documents

Brutalist 4K explainer on the security and data-handling paperwork a university
asks for before it will hand out a Canvas developer key, and what each document
has to answer.

| | |
|---|---|
| Master | 3840x2160, 24 fps, 157.5 s (2:37.5) |
| Beats | 9, all filled |
