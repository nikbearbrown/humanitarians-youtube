# PEDAGOGY.md — crumple-zones (Chapter 9, Impulse and Collisions)

## Concept
Both passengers undergo the same change in momentum (same mass, same speed
to rest). By the impulse-momentum theorem, J = F̄ Δt = Δp, so stretching the
stopping time Δt (crumpling) reduces the average force F̄ = Δp / Δt.

## Physics check (against the textbook, 9.2)
- Impulse-momentum theorem J = Δp, and J = F̄ Δt for an average force: B03.
- Example 9.x (car into a building, airbag/seatbelt): "The change of momentum
  in a crash is the same, with or without an airbag; the force, however, is
  vastly different." B02/B04 state the same logic for crumple zones.
- Narration says "average force" throughout (the theorem fixes only the
  average). The F–t graphs use rectangles (constant average force), drawn
  on identical scales: rigid Δt = 0.5, F̄ = 4.0; crumple Δt = 2.5, F̄ = 0.8 —
  equal areas (2.0) exactly. The two force arrows have the same 5:1 length
  ratio and the two clock sectors the same 1:5 time ratio.
- Force arrows point backward (opposite the motion), since the stopping
  force on the passenger opposes the velocity — the storyboard's upward
  arrow was corrected.
- "The only way to reduce the average force is to extend the stopping time"
  follows from F̄ = Δp/Δt with Δp fixed by the crash.
